Build Your Own Personal Portfolio Website

Project Overview

In this final project, you will create a personal portfolio website using HTML concepts learned in this course. Your website will introduce you, showcase your skills, display your projects and provide contact information.

Project Level: Beginner to Intermediate
Project Type: Practical Website Development
Estimated Time: 2–3 Hours
Tools: VS Code and Web Browser

Learning Objectives

  • Create a complete HTML document.
  • Use headings, paragraphs and text formatting.
  • Add images, hyperlinks and navigation.
  • Create lists and tables.
  • Build a contact form.
  • Use semantic HTML elements.

Website Requirements

1. Header and Navigation

Create a header with your name or portfolio title. Add navigation links for Home, About, Skills, Projects and Contact.

2. About Me Section

Write a short introduction about yourself, your education and your career goals.

3. Profile Image

Add a suitable profile image using the HTML image tag. Include alternative text.

4. Skills Section

Display at least five technical or personal skills using an unordered list.

5. Education Section

Create a table showing your qualification, institution and passing year.

6. Projects Section

Showcase at least two projects with their titles and short descriptions.

7. Contact Section

Create a form with Name, Email and Message fields and a Submit button.

8. Footer

Add your copyright text and at least one useful external link.

Practical Tasks

Task 1: Create an HTML file named index.html.

Task 5: Add your education table and skills list.
Task 6: Create a contact form with appropriate input types.
Task 7: Use semantic HTML elements wherever appropriate.
Task 8: Test all links, forms and sections in your browser.
