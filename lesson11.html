LESSON 11 · HTML BASICS

Let's Learn HTML Accessibility! ♿

Learn how to make websites accessible, user-friendly and professional for everyone.

🎯 What You Will Learn

  • What is HTML Accessibility?
  • How to use image alt text
  • Proper heading structure
  • Accessible forms and labels
  • Semantic HTML elements
  • Keyboard accessibility
  • HTML coding best practices

📖 1. What is HTML Accessibility?

HTML Accessibility means creating websites that everyone can use, including people with disabilities.

Accessible websites are easier to understand, navigate and use.

🖼️ 2. Use Alt Text for Images

The alt attribute describes an image. Screen readers can read this description to users who cannot see the image. 

<img src="flower.jpg"
     alt="A beautiful pink flower">

Tip: Write meaningful descriptions for informative images.

📝 3. Use Proper Heading Structure

Use headings from h1 to h6 in a logical order. A page should normally have one main h1 heading. 

<h1>My Website</h1>
<h2>About Us</h2>
<h3>Our Team</h3>

🏷️ 4. Accessible Forms and Labels

Every form input should have a clear label. The for attribute connects a label to its input. 

<label for="email">Email Address:</label>
<input type="email" id="email">

🧩 5. Use Semantic HTML

Semantic elements explain the purpose of different parts of a webpage. 

<header>Website Header</header>
<nav>Navigation Links</nav>
<main>Main Content</main>
<footer>Website Footer</footer>

⌨️ 6. Keyboard Accessibility

Users should be able to navigate interactive website elements using a keyboard.

  • Use the Tab key to move between interactive elements.
  • Use Enter or Space to activate appropriate controls.
  • Keep buttons and links keyboard accessible.

⭐ 7. HTML Best Practices

  • Always write clean and readable code.
  • Use meaningful element names and attributes.
  • Close HTML tags properly.
  • Use descriptive link text.
  • Keep your website responsive.
  • Test your website with a keyboard.
