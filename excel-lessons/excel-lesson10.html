Data Validation and Drop-Down Lists

Control what users can enter into a worksheet and create useful drop-down menus for accurate data entry.

🎯 What You Will Learn

  • Understand Data Validation.
  • Restrict entries to specific values or ranges.
  • Create drop-down lists.
  • Set number, date and text-length restrictions.
  • Add input messages and error alerts.
  • Create custom validation rules using formulas.
  • Remove Data Validation when required.

1. What Is Data Validation?

Data Validation is an Excel feature that controls what type of information users can enter into selected cells.

It helps reduce mistakes and keeps data consistent.

Example: In a student registration form, you can allow only a specific list of courses to be entered instead of accepting any random text.

Why Use Data Validation?

  • Reduce incorrect entries.
  • Maintain consistent records.
  • Restrict numbers and dates.
  • Create easy-to-use forms.
  • Make data entry faster and more reliable.

2. Where to Find Data Validation

  1. Select the cell or range where you want to apply a rule.
  2. Open the Data tab.
  3. Find the Data Tools section.
  4. Click Data Validation.
  5. Choose the required settings.

The Data Validation window generally contains Settings, Input Message and Error Alert tabs.

3. Understanding Validation Criteria

The Allow dropdown provides different types of validation.

  • Any Value: Allows any entry.
  • Whole Number: Allows only whole numbers within a specified condition.
  • Decimal: Allows decimal numbers within a specified condition.
  • List: Allows users to select from a drop-down list.
  • Date: Restricts entries to valid dates within a condition.
  • Time: Restricts entries to specified time values.
  • Text Length: Controls the number of characters.
  • Custom: Uses a formula to determine whether an entry is allowed.

4. Create a Drop-Down List

A drop-down list allows users to select an option from a predefined list.

Example: Department Selection

Suppose you want employees to select one department from HR, IT, Sales and Finance.

Steps

  1. Select the cell where the drop-down should appear.
  2. Open Data → Data Validation.
  3. Under Allow, select List.
  4. In the Source box, type the options separated by commas.
  5. For example, enter HR,IT,Sales,Finance.
  6. Make sure In-cell dropdown is enabled.
  7. Click OK.
💡 You can also use a cell range as the source of your list. For example, if A2:A5 contains department names, use =$A$2:$A$5 as the source.

5. Whole Number and Decimal Validation

Use Whole Number validation when users should enter only integers.

Example: Student Age

  1. Select the Age column.
  2. Open Data Validation.
  3. Choose Whole Number.
  4. Select Between.
  5. Enter minimum age as 5 and maximum age as 100.
  6. Click OK.

Now entries outside the selected range will be restricted according to the error-alert settings.

Decimal Validation Example

Suppose an employee's attendance percentage must be between 0 and 100.

Choose Decimal, select Between, and enter 0 and 100.

6. Date and Time Validation

Date validation helps restrict entries to a specific date range.

Example: For a project registration sheet, allow dates between 1 January 2026 and 31 December 2026.

Steps

  1. Select the date entry cells.
  2. Open Data Validation.
  3. Choose Date under Allow.
  4. Select Between.
  5. Enter the start and end dates.
  6. Click OK.

Time validation works similarly and can restrict entries to a specified time range.

7. Text Length Validation

Text Length validation controls how many characters a user can enter.

Example: You want a student ID to contain exactly 6 characters.
  1. Select the Student ID cells.
  2. Open Data Validation.
  3. Choose Text Length.
  4. Select Equal To.
  5. Enter 6.
  6. Click OK.
Note: If an ID can contain leading zeros, such as 001234, consider storing it as text so Excel does not remove those zeros.

8. Input Messages

An Input Message displays a helpful instruction when a user selects a validated cell.

Example

For an Age field, you can show:

Title: Enter Your Age
Input Message: Please enter a whole number between 5 and 100.

Steps

  1. Open Data Validation.
  2. Select the Input Message tab.
  3. Enable Show input message when cell is selected.
  4. Enter a title and instruction.
  5. Click OK.

9. Error Alerts

Error Alerts help prevent invalid entries by showing a message when someone enters data that does not follow the validation rule.

Types of Error Alerts

  • Stop: Prevents invalid entries from being accepted.
  • Warning: Shows a warning but allows the user to continue.
  • Information: Displays an informational message and allows the entry.

How to Set an Error Alert

  1. Open Data Validation.
  2. Select the Error Alert tab.
  3. Enable Show error alert after invalid data is entered.
  4. Choose the alert style.
  5. Enter a title and error message.
  6. Click OK.

10. Custom Validation Using a Formula

Custom validation allows you to use a formula to decide which entries are accepted.

Example: Allow Only Unique Student IDs

Suppose student IDs are entered in cells A2 to A100. Select A2:A100 and use this formula in Custom validation:

=COUNTIF($A$2:$A$100,A2)=1

This checks that the entered ID appears only once in the specified range.

Important: Apply the rule to the correct range and test it carefully. Data Validation can be bypassed by some actions such as pasting data into cells.

11. Remove Data Validation

If you no longer need a validation rule:

  1. Select the validated cells.
  2. Go to Data → Data Validation.
  3. Click Clear All.
  4. Click OK.

The validation rule will be removed from the selected cells. Existing cell values will not automatically be deleted.
