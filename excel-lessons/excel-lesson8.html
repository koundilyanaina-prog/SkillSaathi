Conditional Formatting in Excel

Make important data stand out automatically using colours, bars, scales and visual indicators.

🎯 What You Will Learn

  • Highlight cells based on conditions.
  • Use Highlight Cells Rules.
  • Apply Top and Bottom Rules.
  • Use Data Bars and Color Scales.
  • Understand Icon Sets.
  • Find duplicate and unique values.
  • Create custom conditional formatting rules.

1. What Is Conditional Formatting?

Conditional Formatting is an Excel feature that automatically changes the appearance of cells based on specified conditions.

It helps users identify important information, unusual values and performance trends quickly.

Example

StudentMarksVisual Result
Riya90High Score
Aman35Low Score
Neha75Good Score

You can automatically highlight marks below 40 in red and marks above 80 in another colour.

2. How to Apply Conditional Formatting

  1. Select the cells you want to format.
  2. Open the Home tab.
  3. Click Conditional Formatting.
  4. Choose a formatting rule.
  5. Set the required condition.
  6. Select a formatting style.
  7. Click OK.
💡 Conditional Formatting is available under the Home tab in Excel.

3. Highlight Cells Rules

Highlight Cells Rules allow you to highlight cells based on specific conditions.

Available Rules

  • Greater Than
  • Less Than
  • Between
  • Equal To
  • Text That Contains
  • A Date Occurring
  • Duplicate Values

Example: Highlight Low Marks

  1. Select the Marks column.
  2. Go to Home → Conditional Formatting.
  3. Choose Highlight Cells Rules → Less Than.
  4. Enter 40.
  5. Choose a formatting style.
  6. Click OK.
Now all marks below 40 will automatically receive the selected formatting.

4. Top and Bottom Rules

These rules help identify the highest and lowest values in a dataset.

  • Top 10 Items: Highlights the highest 10 values.
  • Top 10%: Highlights the top 10 percent of values.
  • Bottom 10 Items: Highlights the lowest 10 values.
  • Above Average: Highlights values above the average.
  • Below Average: Highlights values below the average.

Example

Use Top 10 Items to identify the ten highest sales amounts in a sales report.

5. Data Bars

Data Bars display horizontal bars inside cells according to their numerical values.

Longer bars represent higher values, while shorter bars represent lower values.

  1. Select the numerical data.
  2. Open Conditional Formatting.
  3. Choose Data Bars.
  4. Select a bar style.

6. Color Scales

Color Scales apply different colours to cells based on their values.

  • Two-Color Scale uses two colours to show lower and higher values.
  • Three-Color Scale uses three colours to show low, middle and high values.
Example: In a student marksheet, lower marks can appear in one colour, medium marks in another and higher marks in a third colour.

To apply it, select your data and choose Conditional Formatting → Color Scales.

7. Icon Sets

Icon Sets display visual symbols based on cell values.

Common examples include:

  • Traffic lights
  • Arrows pointing up, sideways or down
  • Check marks and warning symbols
  • Stars and rating indicators
Example: In a sales report, green upward arrows can indicate strong performance and downward arrows can indicate low performance.

To apply them, select your data and choose Conditional Formatting → Icon Sets.

8. Highlight Duplicate Values

Duplicate Values rules help identify repeated information in a selected range.

Steps

  1. Select the data range.
  2. Open Conditional Formatting.
  3. Choose Highlight Cells Rules → Duplicate Values.
  4. Select a formatting style.
  5. Click OK.

You can also select Unique to highlight values that appear only once in the selected range.

9. Manage Conditional Formatting Rules

Excel allows you to edit, delete and manage existing formatting rules.

  1. Go to Home → Conditional Formatting.
  2. Select Manage Rules.
  3. Choose the rule you want to edit.
  4. Click Edit Rule to change its condition.
  5. Use Delete Rule to remove it.
  6. Click Apply or OK.
Remember: You can create more than one conditional formatting rule for the same range. Check the rule order if different rules affect the same cells.

10. Create a Custom Rule with a Formula

Excel also allows you to create conditional formatting rules using formulas.

Example: Highlight Complete Rows for Low Marks

Suppose student names are in column A and marks are in column B, starting from row 2.

=$B2<40
  1. Select the complete range A2:B10.
  2. Open Conditional Formatting → New Rule.
  3. Choose Use a formula to determine which cells to format.
  4. Enter the formula shown above.
  5. Choose a format and click OK.

Excel will highlight the complete row whenever the marks in column B are below 40.
