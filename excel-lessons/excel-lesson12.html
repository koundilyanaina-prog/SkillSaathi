EXCEL & OFFICE · LESSON 12

Sorting, Filtering & Data Management

Learn how to organize large datasets, find information quickly, remove duplicates and manage records professionally in Excel.

⏱ 30–40 Minutes   |   Intermediate Level   |   5 Questions Quiz

1. What is Data Management?

Data management means organizing, arranging, checking and maintaining information so that it becomes easy to understand and use.

For example, an office may have hundreds of employee records. Excel helps arrange these records by name, department, salary or joining date.

Common uses:
  • Organizing student marksheets.
  • Managing employee records.
  • Preparing sales reports.
  • Finding pending payments.
  • Maintaining customer lists.

2. Sorting Data

Sorting means arranging data in a particular order.

Two common sorting orders

  • Ascending: A to Z, smallest to largest, oldest to newest.
  • Descending: Z to A, largest to smallest, newest to oldest.

How to sort marks from highest to lowest

  1. Select any cell inside your dataset.
  2. Open the Data tab.
  3. Click Sort.
  4. Select the Marks column.
  5. Choose Largest to Smallest.
  6. Click OK.
Important: Select the complete dataset or use Excel's Sort feature carefully. Sorting only one column can mix up student names and their marks.

3. Filtering Data

Filtering displays only the records that match your selected conditions. Other records are temporarily hidden, not deleted.

Example

Suppose you want to see only students from Ranchi.

  1. Select your data including the headings.
  2. Go to the Data tab.
  3. Click Filter.
  4. Click the dropdown arrow in the City heading.
  5. Uncheck Select All and select Ranchi.
  6. Click OK.
Result: Only Riya and Rahul will be displayed because their city is Ranchi.
To show all records again, open the filter dropdown and choose Clear Filter, or turn Filter off.

5. Remove Duplicate Records

Duplicate records are repeated entries in a dataset. Excel can identify and remove them.

Steps

  1. Select the complete dataset.
  2. Open the Data tab.
  3. Click Remove Duplicates.
  4. Select the columns you want Excel to check.
  5. Click OK.
  6. Excel will display how many duplicate values were removed.
Always keep a backup before removing duplicates. If you select multiple columns, Excel checks the combination of those selected columns.

6. Freeze Panes

Freeze Panes keeps selected rows or columns visible while you scroll through a large worksheet.

Useful options

  • Freeze Top Row: Keeps the first row visible.
  • Freeze First Column: Keeps the first column visible.
  • Freeze Panes: Keeps rows above and columns to the left of the selected cell visible.

Example

If you want to keep the first row and first column visible, select cell B2 and go to View → Freeze Panes → Freeze Panes.

7. Excel Tables for Better Data Management

Converting a normal dataset into an Excel Table makes sorting, filtering and formatting easier.

Steps to create a table

  1. Select your complete dataset.
  2. Press Ctrl + T.
  3. Check My table has headers.
  4. Click OK.

Excel Tables automatically provide filter buttons and can expand when you add new records below the table.

Shortcut: Ctrl + T
