Conditional Functions in Excel

Learn to calculate totals, count records and handle errors using conditions. These functions are essential for reports, office records and MIS work.

⏱ 35–45 Minutes | Intermediate Level | 5 Questions Quiz

1. What are Conditional Functions?

Conditional functions perform calculations only when specific conditions are satisfied.

For example, an office may want to calculate only HR department expenses or count employees whose salary is above ₹30,000.

Common office uses:
  • Calculate sales for a particular city.
  • Count employees in a department.
  • Calculate expenses above a specific amount.
  • Prepare monthly performance reports.

2. SUMIF – Sum with One Condition

SUMIF adds numbers when one specified condition is satisfied.

=SUMIF(range, criteria, [sum_range])
  • range: Cells where Excel checks the condition.
  • criteria: The condition to match.
  • sum_range: Cells containing the numbers to add.

Example: Department-wise expenses

DepartmentExpense
HR5000
Sales8000
HR3000
IT7000
=SUMIF(A2:A5,"HR",B2:B5)

Result: 8000

Excel adds only the expenses belonging to HR.

3. SUMIFS – Sum with Multiple Conditions

SUMIFS adds values only when multiple conditions are satisfied.

=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2)

Example

Suppose you have sales records with City, Product and Amount columns. You want total sales of Laptop in Patna.

=SUMIFS(C2:C10,A2:A10,"Patna",B2:B10,"Laptop")

Excel adds the amounts where both conditions match: City is Patna AND Product is Laptop.

Remember: SUMIF has one condition; SUMIFS can handle multiple conditions. In SUMIFS, the sum range comes first.

4. COUNTIF – Count with One Condition

COUNTIF counts the number of cells that satisfy one condition.

=COUNTIF(range, criteria)

Example

Count how many employees belong to the HR department:

=COUNTIF(B2:B20,"HR")

Count how many students scored 60 or more:

=COUNTIF(C2:C30,">=60")

Count how many employees have salary greater than ₹30,000:

=COUNTIF(D2:D20,">30000")

5. COUNTIFS – Count with Multiple Conditions

COUNTIFS counts records that satisfy all specified conditions.

=COUNTIFS(criteria_range1,criteria1,criteria_range2,criteria2)

Example

Count employees who belong to HR and earn more than ₹25,000:

=COUNTIFS(B2:B20,"HR",C2:C20,">25000")

Both conditions must be true for a record to be counted.

6. Using Cell References as Conditions

Instead of typing conditions directly inside formulas, you can refer to cells.

Suppose E2 contains the department name HR.

=SUMIF(A2:A20,E2,B2:B20)

Suppose F2 contains a salary limit of 30000.

=COUNTIF(C2:C20,">"&F2)
Use quotation marks around comparison operators when joining them with a cell reference, such as ">"&F2.

7. IFERROR – Handle Formula Errors

IFERROR displays a helpful result when a formula returns an error.

=IFERROR(value, value_if_error)

Example

Suppose A2 contains 100 and B2 contains 0. Dividing by zero creates a #DIV/0! error.

=IFERROR(A2/B2,"Cannot Divide")

Result: Cannot Divide

Another example using VLOOKUP:

=IFERROR(VLOOKUP(F2,A2:D10,2,FALSE),"Not Found")
IFERROR can handle errors such as #N/A, #DIV/0!, #VALUE! and #REF!. It does not correct the underlying problem; it changes what is displayed.
