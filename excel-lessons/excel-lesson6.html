Sorting and Filtering Data

Learn how to organize large datasets, arrange records and find specific information quickly using Excel Sort and Filter tools.

🎯 What You Will Learn

By the end of this lesson, you will be able to:

  • Understand sorting and filtering in Excel.
  • Sort text alphabetically from A to Z or Z to A.
  • Sort numbers from smallest to largest.
  • Apply and remove filters.
  • Filter text, numbers and dates.
  • Sort data using multiple columns.

1. What Is Sorting?

Sorting means arranging data in a particular order. Excel allows you to organize text, numbers and dates.

Types of Sorting

  • A to Z: Arranges text alphabetically.
  • Z to A: Arranges text in reverse alphabetical order.
  • Smallest to Largest: Arranges numbers in ascending order.
  • Largest to Smallest: Arranges numbers in descending order.
  • Oldest to Newest: Arranges dates chronologically.
  • Newest to Oldest: Shows the latest dates first.

Example: Sorting Student Names

Before Sorting After A to Z
Rahul Aman
Neha Neha
Aman Rahul

How to Sort Data

  1. Select any cell inside your dataset.
  2. Open the Data tab.
  3. Find the Sort & Filter section.
  4. Choose Sort A to Z or Sort Z to A.
  5. Excel will arrange the complete rows based on that column.
💡 Important: Select a cell inside the dataset and check that Excel includes all related columns. Do not sort only one column when the rows contain related student or employee information.

3. What Is Filtering?

Filtering helps you display only the records that match specific conditions while temporarily hiding other rows.

Example

Suppose you have a list of 100 students and want to see only students who have passed.

Instead of searching each row manually, you can apply a filter to the Result column and select Pass.

How to Apply Filter

  1. Select a cell inside your dataset.
  2. Go to the Data tab.
  3. Click Filter.
  4. Small dropdown arrows will appear in the header row.
  5. Click the dropdown arrow of the column you want to filter.
  6. Select the values you want to display.
  7. Click OK.
💡 Shortcut: Press Ctrl + Shift + L to turn filters on or off in a selected data range.

4. Types of Filters

A. Text Filters

Text filters help you find records based on words or letters.

  • Begins With
  • Ends With
  • Contains
  • Does Not Contain
  • Equals
Example: Use Contains to display employee names that contain the letters "an".

B. Number Filters

Number filters help you find records based on numerical conditions.

  • Greater Than
  • Less Than
  • Between
  • Equal To
  • Top 10
Example: Use Greater Than 70 to display students who scored more than 70 marks.

C. Date Filters

Date filters help you display records based on dates.

  • Today
  • Yesterday
  • This Week
  • This Month
  • Last Month
  • Between Two Dates
Example: Use This Month to display records entered during the current month.

5. Custom Sorting with Multiple Columns

Sometimes you need to sort data using more than one column. Excel provides the Custom Sort option for this purpose.

Example

First arrange students by Class and then arrange their Marks from highest to lowest within each class.

Steps

  1. Select your complete dataset.
  2. Open the Data tab.
  3. Click Sort.
  4. Choose Class under Sort by.
  5. Choose A to Z under Order.
  6. Click Add Level.
  7. Choose Marks under Then by.
  8. Select Largest to Smallest.
  9. Click OK.
💡 Custom Sort is useful for managing employee lists, student records, sales reports and office databases.

6. How to Clear or Remove Filters

After filtering data, you may want to display all records again.

To Clear a Filter

  1. Click the dropdown arrow in the filtered column.
  2. Choose Clear Filter From...
  3. All records will become visible again.

To Turn Off Filters

Go to the Data tab and click Filter again, or use Ctrl + Shift + L.
