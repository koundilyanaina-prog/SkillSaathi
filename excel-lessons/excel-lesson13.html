VLOOKUP, XLOOKUP & Lookup Functions

Learn how to search for information in large Excel datasets and automatically retrieve matching results.

⏱ 35–45 Minutes | Intermediate Level | 5 Questions Quiz

1. What are Lookup Functions?

Lookup functions help you find a particular value in a table and return related information from another column or row.

For example, an office has an employee database. If you enter an Employee ID, Excel can automatically display that employee's name, department or salary.

Real-world uses:
  • Finding employee details using Employee ID.
  • Searching product prices using Product Codes.
  • Finding student marks using Roll Numbers.
  • Retrieving customer information from a database.

2. Understanding VLOOKUP

VLOOKUP stands for Vertical Lookup. It searches for a value in the first column of a selected table and returns information from another column in the same row.

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

Meaning of each argument

  • lookup_value: The value you want to search.
  • table_array: The range containing your data.
  • col_index_num: The column number from which you want the result.
  • range_lookup: FALSE for exact match, TRUE for approximate match.

3. VLOOKUP Practical Example

Consider this employee database:

Employee IDNameDepartmentSalary
101AmanSales22000
102RiyaHR28000
103NehaIT35000
104RahulFinance30000

Suppose you enter Employee ID 103 in cell F2 and want to find the employee's name.

=VLOOKUP(F2,A2:D5,2,FALSE)

Result: Neha

To find the salary instead:

=VLOOKUP(F2,A2:D5,4,FALSE)

Result: 35000

Remember: VLOOKUP searches only in the first column of the selected table range and returns a result from a column to its right.

4. Exact Match vs Approximate Match

OptionMeaningUse
FALSE or 0Exact matchEmployee ID, Roll Number, Product Code
TRUE or 1Approximate matchGrade slabs, commission ranges, tax bands
For approximate VLOOKUP, the first column should generally be sorted in ascending order. For IDs and codes, use FALSE to avoid incorrect matches.

5. Understanding XLOOKUP

XLOOKUP is a modern lookup function available in Microsoft 365 and newer Excel versions. It can search in one column and return a result from another column, including columns on either side.

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])

Example

Search Employee ID in A2:A5 and return the employee's name from B2:B5.

=XLOOKUP(F2,A2:A5,B2:B5,"Not Found")

If F2 contains 103, the result is Neha.

Advantages of XLOOKUP

  • Can search both left and right.
  • Uses exact match by default.
  • Can display a custom message if no match is found.
  • Does not require a column index number.
XLOOKUP is not available in some older Excel versions, such as Excel 2016 and Excel 2019. In those versions, VLOOKUP or INDEX and MATCH can be used.

6. Understanding HLOOKUP

HLOOKUP stands for Horizontal Lookup. It searches for a value in the first row of a table and returns information from another row.

=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])

For example, if months are arranged horizontally in the first row and sales figures in the second row, HLOOKUP can find the sales for a selected month.

VLOOKUP searches vertically through columns. HLOOKUP searches horizontally through rows.

7. Handling Lookup Errors

Sometimes a lookup formula returns an error because the searched value does not exist or the formula is incorrect.

Common errors

  • #N/A: The searched value was not found.
  • #REF!: An invalid column or row reference was used.
  • #VALUE!: An argument has an incorrect value or type.

Using IFERROR

=IFERROR(VLOOKUP(F2,A2:D5,2,FALSE),"Not Found")

This formula displays "Not Found" instead of an error if the lookup fails.

Create the following employee database in Excel:

Your tasks
