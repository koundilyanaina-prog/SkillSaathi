Text & Date Functions

Learn to clean text, extract information, combine names and work with dates. These functions are useful for employee records, customer lists and office reports.

⏱ 35–45 Minutes | Intermediate Level | 5 Questions Quiz

1. What are Text Functions?

Text functions help you modify, clean, extract and combine text stored in Excel cells.

For example, an employee database may contain full names, email addresses, codes and department names. Text functions help organize this information.

Common uses:
  • Extract first names or last names.
  • Remove unwanted spaces.
  • Convert text into uppercase or lowercase.
  • Combine first name and last name.
  • Clean imported customer records.

2. LEFT – Extract Characters from the Beginning

LEFT returns a specified number of characters from the left side of a text string.

=LEFT(text, [num_chars])

Example

If A2 contains SKILLSAATHI:

=LEFT(A2,5)

Result: SKILL

Useful for extracting prefixes from employee IDs and product codes.

3. RIGHT – Extract Characters from the End

RIGHT returns characters from the right side of a text string.

=RIGHT(text, [num_chars])

Example

If A2 contains EMP2026105:

=RIGHT(A2,3)

Result: 105

4. MID – Extract Characters from the Middle

MID extracts characters from a specified starting position.

=MID(text, start_num, num_chars)

Example

If A2 contains EMP2026105:

=MID(A2,4,4)

Result: 2026

Here, Excel starts at the fourth character and extracts four characters.

5. LEN – Count Characters

LEN returns the total number of characters in a text string, including spaces.

=LEN(A2)

If A2 contains Nainsi, the result is 6.

LEN is useful for checking whether IDs, phone-number entries or codes have the expected number of characters.

6. TRIM – Remove Extra Spaces

TRIM removes unnecessary spaces from text, leaving single spaces between words.

=TRIM(A2)

Example: If a cell contains " Nainsi Kumari ", TRIM returns "Nainsi Kumari".

TRIM is especially useful when cleaning data copied from websites, forms or external systems. It does not remove every possible non-breaking space.

7. UPPER, LOWER and PROPER

These functions change the capitalization of text.

FunctionExample InputResult
UPPERNainsi KumariNAINSI KUMARI
LOWERNAINSI@MAIL.COMnainsi@mail.com
PROPERnainsi kumariNainsi Kumari
=UPPER(A2)
=LOWER(A2)
=PROPER(A2)

8. CONCAT and TEXTJOIN – Combine Text

CONCAT combines text from multiple cells.

=CONCAT(A2," ",B2)

If A2 contains Nainsi and B2 contains Kumari, the result is Nainsi Kumari.

TEXTJOIN

TEXTJOIN combines multiple text values using a separator. It can also ignore empty cells.

=TEXTJOIN(" ",TRUE,A2:C2)

This combines values from A2 to C2 with spaces between them and ignores blank cells.

CONCAT and TEXTJOIN are available in modern Excel versions. Older versions may use CONCATENATE.

9. Introduction to Date Functions

Date functions help calculate, extract and manage dates in Excel.

TODAY

Returns the current date.

=TODAY()

NOW

Returns the current date and time.

=NOW()

DATE

Creates a date from year, month and day values.

=DATE(2026,11,12)

Result: 12-Nov-2026, depending on cell formatting.

10. DAY, MONTH and YEAR

These functions extract individual parts of a valid Excel date.

Suppose A2 contains 12-Nov-2026.

=DAY(A2)

Result: 12

=MONTH(A2)

Result: 11

=YEAR(A2)

Result: 2026

11. EOMONTH and NETWORKDAYS

EOMONTH

Returns the last day of a month, a specified number of months before or after a date.

=EOMONTH(A2,0)

Returns the last day of the same month as A2.

=EOMONTH(A2,1)

Returns the last day of the following month.

NETWORKDAYS

Counts working days between two dates, excluding Saturdays and Sundays by default. You can also provide a holiday list.

=NETWORKDAYS(A2,B2)
=NETWORKDAYS(A2,B2,D2:D10)

The second formula also excludes holidays listed in D2:D10.

NETWORKDAYS assumes Saturday and Sunday are weekends. For different weekend days, Excel provides NETWORKDAYS.INTL.

12. DATEDIF – Calculate Date Difference

DATEDIF calculates the difference between two dates in years, months or days.

=DATEDIF(A2,B2,"Y")

Returns the number of complete years between the dates.

=DATEDIF(A2,B2,"M")

Returns the number of complete months.

=DATEDIF(A2,B2,"D")

Returns the total number of days.

The start date must be earlier than or equal to the end date. DATEDIF is an older compatibility function and may not appear in Excel's formula suggestions.
