Project 3: Monthly MIS Dashboard

SkillSaathi · Excel & Office · Advanced Practical Project

Project Overview

In this project, you will create a professional Monthly Sales MIS Dashboard using Microsoft Excel.

A sales MIS dashboard helps managers understand sales performance, compare departments, track targets and make business decisions.

Skills used:

  • Data Entry and Excel Tables
  • SUM, AVERAGE and COUNT
  • SUMIF, COUNTIF and IFERROR
  • Percentage and KPI calculations
  • PivotTables and PivotCharts
  • Charts, Filters and Slicers
  • Dashboard formatting and PDF export

Step 1: Create Your Workbook

  1. Open Microsoft Excel.
  2. Create a Blank Workbook.
  3. Rename Sheet1 as Raw Data.
  4. Create two more sheets: Summary and Dashboard.
  5. Save the file as Monthly_MIS_Dashboard.xlsx.
Keep raw data, calculations and dashboard in separate worksheets. This makes the workbook easier to manage.

Step 3: Format Raw Data

  1. Select the complete dataset.
  2. Press Ctrl + T.
  3. Tick My Table Has Headers.
  4. Choose a suitable table style.
  5. Format Sales Amount and Target as Currency or Number.
  6. Check that dates are recognised as dates.

Rename the Excel Table to SalesData from Table Design → Table Name.

Use consistent headings and avoid blank rows inside your data table. This helps PivotTables and formulas work correctly.

Step 7: Create a PivotTable

PivotTables help you summarise large datasets quickly.

  1. Open Raw Data.
  2. Click any cell inside the SalesData table.
  3. Go to Insert → PivotTable.
  4. Choose New Worksheet and click OK.
  5. Drag Department to Rows.
  6. Drag Sales Amount to Values.
  7. Make sure the Values field is set to Sum.

You now have a department-wise sales report using a PivotTable.

You can add Employee to Rows and Product to Columns to explore other report layouts.

Step 8: Create a PivotChart

  1. Click inside your PivotTable.
  2. Open PivotTable Analyze → PivotChart.
  3. Choose a Column Chart.
  4. Add the title Department-wise Sales Performance.
  5. Adjust labels and formatting.

Use a chart that makes department comparisons easy to understand.

Step 9: Add a Slicer

A Slicer lets users filter a PivotTable by clicking buttons.

  1. Select the PivotTable.
  2. Go to PivotTable Analyze → Insert Slicer.
  3. Select Department or Product.
  4. Click OK.
  5. Try clicking different departments to filter the report.

When you add more records to the source table, use Refresh on the PivotTable to update the report.

Step 10: Design Your Dashboard

Open the Dashboard sheet and arrange the following sections:

  1. Heading: MONTHLY SALES PERFORMANCE DASHBOARD.
  2. Reporting period: November 2026 (sample project data).
  3. KPI cards: Total Sales, Total Target, Achievement %, Total Units.
  4. Chart 1: Department-wise Sales.
  5. Chart 2: Employee-wise Sales.
  6. Chart 3: Product-wise Sales.
  7. Filters: Department or Product Slicer, connected to relevant PivotTables.
Suggested layout:
Top row: Dashboard title and reporting period.
Second row: Four KPI cards.
Middle: Department and employee charts.
Bottom: Product report and slicers.
You can copy KPI values from Summary and paste them into Dashboard. Use cell references if you want the dashboard values to update automatically.

Step 11: Final Formatting

  • Use clear titles and consistent fonts.
  • Keep KPI values large and easy to read.
  • Use consistent number formats.
  • Remove unnecessary gridlines from the Dashboard sheet using View → Gridlines.
  • Align charts and summary cards neatly.
  • Check all formulas and PivotTable totals.
  • Refresh PivotTables before sharing the report.

Step 12: Export Dashboard as PDF

  1. Open the Dashboard sheet.
  2. Set the Print Area around the dashboard.
  3. Choose Landscape orientation if needed.
  4. Set scaling to fit the dashboard on one page if readable.
  5. Open Print Preview and check the layout.
  6. Choose File → Export or Save As → PDF.
  7. Save as Monthly_Sales_Dashboard.pdf.
