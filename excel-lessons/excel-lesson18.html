Lesson 18: Printing, Protection & Final Excel Revision

SkillSaathi · Excel & Office · Final Lesson

1. Page Setup in Excel

Page Setup helps you prepare a worksheet for printing or sharing as a PDF.

Important settings:

  • Orientation: Portrait or Landscape.
  • Paper Size: A4, Letter and other supported sizes.
  • Margins: Normal, Narrow or Custom.
  • Scaling: Fit the sheet to a selected number of pages.
  • Print Titles: Repeat selected rows or columns on printed pages.
For a wide sales report, Landscape orientation may make the data easier to read.

2. Set Print Area

Print Area allows you to print only a selected part of a worksheet.

  1. Select the cells you want to print.
  2. Open the Page Layout tab.
  3. Click Print Area.
  4. Select Set Print Area.
  5. Open Print Preview to check the result.

To remove it, use Page Layout → Print Area → Clear Print Area.

Example: If your worksheet contains raw data and a separate summary, select only the summary before setting the Print Area.

3. Page Breaks

Page Breaks control where one printed page ends and the next begins.

  • Open View → Page Break Preview.
  • Review the page boundaries.
  • Adjust the page breaks where required.
  • Use Page Layout → Breaks to insert or reset breaks.

This is especially useful for long reports that need to be printed neatly.

4. Print Preview and PDF Export

Always check your report before printing or sharing.

  1. Press Ctrl + P to open Print settings.
  2. Check the selected printer and page range.
  3. Review margins, orientation and scaling.
  4. Check that important columns are not cut off.
  5. To create a PDF, choose Microsoft Print to PDF where available, or use File → Export / Save As → PDF.
PDF is useful when you want to share a report while keeping its page layout consistent.

5. Protect a Worksheet

Worksheet protection helps prevent accidental changes to selected cells or formulas.

  1. Select cells that users should be allowed to edit.
  2. Press Ctrl + 1 and open the Protection tab.
  3. Untick Locked for those editable cells.
  4. Go to Review → Protect Sheet.
  5. Choose the allowed actions and optionally set a password.
By default, cells are marked as Locked, but this setting takes effect only after sheet protection is enabled.

6. Protect Workbook Structure

Workbook protection can help prevent users from adding, deleting, moving, hiding or renaming worksheets.

  1. Open the Review tab.
  2. Select Protect Workbook.
  3. Enable protection for the workbook structure.
  4. Set a password if required and confirm it.

Important: Worksheet protection and workbook structure protection are different features.

7. Lock Formula Cells

In reports, you may want users to enter data but not overwrite formulas.

  1. Select the cells where users will enter information.
  2. Open Format Cells → Protection.
  3. Untick Locked for the input cells.
  4. Keep formula cells locked.
  5. Protect the worksheet from the Review tab.
Example: In a marksheet, students' marks may be entered in unlocked cells while Total and Percentage formula cells remain protected.

9. Final Excel Revision Checklist

Before completing the course, make sure you understand these topics:

  • Workbook, worksheets, rows, columns and cells
  • Data entry, formatting and number formats
  • Basic formulas and cell references
  • SUM, AVERAGE, MIN, MAX and COUNT
  • IF, AND, OR and conditional formatting
  • Sorting, filtering and Excel Tables
  • VLOOKUP, XLOOKUP and lookup functions
  • SUMIF, SUMIFS, COUNTIF and COUNTIFS
  • Text and Date functions
  • Data cleaning and validation
  • Charts, PivotTables and dashboards
  • Printing, PDF export and worksheet protection
If any topic feels difficult, revisit its lesson and practise it in Excel before moving to the projects.

10. Final Practical Assignment

Complete these three projects to apply what you have learned.

Project 1: Monthly Expense Tracker

  • Create Date, Category, Description and Amount columns.
  • Calculate total monthly expenses.
  • Use SUMIF to calculate category-wise spending.
  • Add a chart to show expense distribution.

Project 2: Student Marksheet

  • Create student names and subject-wise marks.
  • Calculate Total and Percentage.
  • Use IF to assign Pass or Fail.
  • Use conditional formatting to highlight results.
  • Protect formula cells.

Project 3: Monthly MIS Dashboard

  • Prepare a clean sales dataset.
  • Calculate total sales and target achievement.
  • Create a department-wise summary.
  • Use PivotTables and charts.
  • Arrange the results into a professional dashboard.
  • Check and export the final report as PDF.
