Formatting Cells in Excel

Learn how to make your spreadsheets clean, readable and professional using fonts, colours, borders, alignment and number formats.

◷ 25–30 Minutes Beginner Level 5 Questions Quiz

🎯 What You Will Learn

  • Change font style and font size.
  • Use Bold, Italic and Underline.
  • Apply font colour and cell fill colour.
  • Add borders to cells.
  • Align text inside cells.
  • Use basic number formats.
  • Adjust column width and row height.

1. What is Cell Formatting?

Cell formatting means changing the appearance of data in an Excel worksheet without changing the actual data.

Formatting helps make information easier to read, understand and present.

Why is formatting important?

  • Makes headings easy to identify.
  • Highlights important information.
  • Improves readability.
  • Makes reports look professional.

2. Font Style and Font Size

You can change the font style and size of text in a cell. First select the cell or range of cells you want to format.

Common Font Options

Bold: Makes text darker and thicker.

Italic: Makes text slanted.

Underline: Adds a line below text.

You can also choose a font family such as Arial or Calibri and adjust its size.

Useful Keyboard Shortcuts

Ctrl + B Bold Ctrl + I Italic Ctrl + U Underline

3. Font Colour and Fill Colour

Excel allows you to change the colour of text and the background of a cell.

Font Colour

Changes the colour of the text inside a cell.

Fill Colour

Changes the background colour of a selected cell.

For example, you can use a dark fill colour with light text to highlight your table headings.

4. Adding Borders

Borders are lines around cells. They help separate information and organize tables.

Name Department Salary
Asha HR 25000
Ravi Accounts 30000
Meena Sales 28000

You can apply outside borders, all borders, top borders and bottom borders from the Borders option.

5. Text Alignment

Alignment controls the position of text inside a cell.

  • Left Align: Places text towards the left.
  • Center: Places text in the middle.
  • Right Align: Places text towards the right.
  • Top Align: Places content at the top.
  • Middle Align: Places content vertically in the middle.
  • Bottom Align: Places content at the bottom.

6. Number Formats

Number formatting changes how numerical values are displayed. It does not necessarily change the stored value.

Common Number Formats

  • General: Default format in Excel.
  • Number: Displays numerical values.
  • Currency: Displays a currency symbol.
  • Percentage: Displays values with a % sign.
  • Date: Displays dates in a selected format.
  • Accounting: Aligns currency symbols and values neatly.
Format Example Display
Number 1500
Currency ₹1,500.00
Percentage 75%
Date 07-Nov-2026

7. Adjusting Row Height and Column Width

Sometimes text does not fit properly inside a cell. You can increase the row height or column width.

  • Drag the boundary between column letters to change column width.
  • Drag the boundary between row numbers to change row height.
  • Double-click a boundary to use AutoFit for the content.
