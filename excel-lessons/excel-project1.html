Project 1: Monthly Expense Tracker

SkillSaathi · Excel & Office · Practical Project

Project Overview

In this project, you will create a Monthly Expense Tracker using Microsoft Excel.

You will learn how to record daily expenses, calculate total spending, compare expenses by category and understand monthly savings.

Skills used:

  • Data Entry and Formatting
  • SUM and SUMIF Functions
  • AVERAGE Function
  • IF Function
  • Sorting and Filtering
  • Charts and Data Visualisation

Step 1: Create Your Workbook

  1. Open Microsoft Excel.
  2. Create a Blank Workbook.
  3. Rename Sheet1 as Expense Data.
  4. Save the workbook as Monthly_Expense_Tracker.xlsx.

Step 3: Format Your Data

  1. Select your complete dataset.
  2. Press Ctrl + T to create an Excel Table.
  3. Tick My Table Has Headers.
  4. Apply a suitable table style.
  5. Format the Amount column as Currency or Number.
  6. Adjust column widths and make headings bold.

Step 4: Create a Summary Sheet

Add a new worksheet and rename it Monthly Summary.

Enter these labels and values:

CellEnter
A1MONTHLY EXPENSE SUMMARY
A3Monthly Budget
B325000
A4Total Expenses
A5Remaining Budget
A6Average Expense
A7Total Transactions

Now enter these formulas:

B4: =SUM('Expense Data'!E2:E13)
B5: =B3-B4
B6: =AVERAGE('Expense Data'!E2:E13)
B7: =COUNTA('Expense Data'!A2:A13)

Step 5: Calculate Category-wise Expenses

In A10:B15 of Monthly Summary, create this table:

CategoryTotal Expense
FoodFormula
TransportFormula
EducationFormula
UtilitiesFormula
ShoppingFormula
HealthFormula

Enter this formula in B11 and drag it down:

=SUMIF('Expense Data'!$B$2:$B$13,A11,'Expense Data'!$E$2:$E$13)

This formula calculates the total expenses for each category.

Step 6: Check Your Budget Status

In A17, type Budget Status. In B17, enter:

=IF(B5>=0,"Within Budget","Over Budget")

This formula checks whether your remaining budget is positive or negative.

You can use conditional formatting to show "Within Budget" in green and "Over Budget" in red.

Step 7: Create an Expense Chart

  1. Select the category-wise summary table.
  2. Go to Insert → Charts.
  3. Choose a Doughnut or Pie Chart.
  4. Add the chart title: Category-wise Monthly Expenses.
  5. Show data labels or percentages.

You can also create a Column Chart to compare spending across categories.

Step 8: Final Project Checklist

  • Expense Data sheet created.
  • At least 12 expense records entered.
  • Data converted into an Excel Table.
  • Monthly budget and total expenses calculated.
  • Remaining budget and average expense calculated.
  • Category-wise expenses calculated with SUMIF.
  • Budget status calculated with IF.
  • Chart created and formatted.
  • Workbook saved correctly.
Before sharing your workbook, check your formulas, dates, amounts and chart labels.

What You Have Learned

After completing this project, you should be able to:

  • Maintain a daily expense record.
  • Calculate monthly spending automatically.
  • Compare expenses by category.
  • Track your remaining budget.
  • Present financial information using charts.
