Pivot Tables and Pivot Charts

Learn how to summarize large amounts of data, create reports and discover useful insights with Pivot Tables.

1. What is a Pivot Table?

A Pivot Table is an Excel tool used to summarize, organize and analyze large datasets quickly.

Instead of manually calculating totals or preparing separate reports, a Pivot Table can summarize information automatically.

Example:

Imagine a company has 500 sales records. It wants to know:

  • Total sales by each employee.
  • Total sales by each city.
  • Which product generated the highest sales?
  • How much sales happened in each month?
A Pivot Table can help answer these questions quickly.

2. Why Use Pivot Tables?

  • Save time: Summarize large datasets quickly.
  • Easy analysis: Compare different categories.
  • Flexible reports: Rearrange data without changing the original dataset.
  • Automatic calculations: Calculate Sum, Count, Average and more.
  • Better decisions: Identify patterns and trends.

4. How to Create a Pivot Table

Follow these steps in Microsoft Excel:

  1. Open your Excel workbook.
  2. Select any cell inside your dataset.
  3. Go to the Insert tab.
  4. Click PivotTable.
  5. Check the selected table or data range.
  6. Choose New Worksheet or Existing Worksheet.
  7. Click OK.
  8. A blank Pivot Table and PivotTable Fields panel will appear.
Remember: You can also convert your source data into an Excel Table using Ctrl + T before creating a Pivot Table.

5. Understanding Pivot Table Fields

Pivot Tables have four important areas:

Rows

Displays categories vertically, such as Employee names or City names.

Columns

Displays categories horizontally to help compare information.

Values

Contains numerical calculations such as Sum, Count and Average.

Filters

Allows you to display data for selected categories only.

Example: Total Sales by Employee
  • Rows → Employee
  • Values → Sales
  • Columns → Leave empty
  • Filters → City (optional)

7. What is a Pivot Chart?

A Pivot Chart is a chart connected to a Pivot Table. It helps present summarized information visually.

You can create different types of charts, such as:

  • Column Chart – Compare sales between employees.
  • Bar Chart – Compare different categories.
  • Line Chart – Show changes over time.
  • Pie Chart – Show proportions of a total.

Steps to Create a Pivot Chart

  1. Click anywhere inside your Pivot Table.
  2. Go to Insert or PivotTable Analyze tab.
  3. Select PivotChart.
  4. Choose a chart type.
  5. Click OK.
  6. Customize the chart title, colours and labels.

8. Refresh a Pivot Table

If you add or change information in the source data, your Pivot Table may need to be refreshed.

  1. Click anywhere inside the Pivot Table.
  2. Right-click and select Refresh.
  3. Alternatively, use PivotTable Analyze → Refresh.
💡 Tip: Refresh updates the Pivot Table using its current source range. If new records are outside that range, you may need to change the data source or use an Excel Table that expands automatically.
