Project 2: Student Marksheet

SkillSaathi · Excel & Office · Practical Project

Project Overview

In this project, you will create a Student Marksheet using Microsoft Excel.

The marksheet will automatically calculate total marks, percentage, grades and pass/fail results.

Skills used:

  • Data Entry and Formatting
  • SUM and AVERAGE
  • IF, AND and COUNTIF
  • MAX and MIN
  • Conditional Formatting
  • Sorting and Filtering
  • Charts and Data Analysis

Step 1: Create Your Workbook

  1. Open Microsoft Excel.
  2. Create a Blank Workbook.
  3. Rename Sheet1 as Student Marks.
  4. Save it as Student_Marksheet.xlsx.

Step 4: Calculate Total Marks

In cell H2, enter:

=SUM(C2:G2)

Press Enter and drag the formula down to H9.

This calculates the total marks obtained by each student out of 500.

Step 5: Calculate Percentage

In cell I2, enter:

=H2/500*100

Drag the formula down to I9.

Format the percentage column with two decimal places.

Example: If a student scores 400 out of 500, their percentage is 80%.

Step 6: Assign Grades Automatically

Use the following grading system:

PercentageGrade
90 and aboveA+
80 to below 90A
70 to below 80B
60 to below 70C
50 to below 60D
Below 50E

In J2, enter:

=IF(I2>=90,"A+",IF(I2>=80,"A",IF(I2>=70,"B",IF(I2>=60,"C",IF(I2>=50,"D","E")))))

Drag down to J9.

Step 7: Calculate Pass or Fail

A student must score at least 35 marks in every subject to pass.

In K2, enter:

=IF(MIN(C2:G2)>=35,"PASS","FAIL")

Drag the formula down to K9.

This is more accurate than checking only the total marks. A student can have a high total but still fail one subject.

Step 8: Create a Result Summary

Below the main table, create a small summary:

MetricFormula
Total Students=COUNTA(B2:B9)
Passed Students=COUNTIF(K2:K9,"PASS")
Failed Students=COUNTIF(K2:K9,"FAIL")
Class Average=AVERAGE(I2:I9)
Highest Percentage=MAX(I2:I9)
Lowest Percentage=MIN(I2:I9)

Step 9: Apply Conditional Formatting

Make your marksheet easier to read.

  1. Select the Result column.
  2. Open Home → Conditional Formatting.
  3. Highlight cells containing PASS in green.
  4. Highlight cells containing FAIL in red.
  5. You can also apply Colour Scales to the Percentage column.

Step 10: Sort and Filter Results

  1. Select your complete marksheet.
  2. Press Ctrl + T and confirm My Table Has Headers.
  3. Use the filter in the Percentage column to sort from Largest to Smallest.
  4. Filter the Result column to view only PASS or FAIL students.
  5. Check which student has the highest percentage.

Step 11: Create a Class Performance Chart

  1. Select Student Name and Percentage columns.
  2. Go to Insert → Column Chart.
  3. Add the chart title: Student Performance.
  4. Show data labels if useful.
  5. Place the chart below or beside your marksheet.

Step 12: Final Project Checklist

  • Student Marks sheet created.
  • At least 8 student records entered.
  • Total marks calculated.
  • Percentage calculated.
  • Automatic grades assigned.
  • Pass/Fail calculated subject-wise.
  • Result summary created.
  • Conditional formatting applied.
  • Sorting and filtering tested.
  • Performance chart created.
  • Workbook saved correctly.
Always verify the maximum marks, passing criteria and grading rules before using a marksheet for actual school results.

What You Have Learned

After completing this project, you should be able to:

  • Create an automated student marksheet.
  • Calculate totals and percentages.
  • Assign grades using nested IF.
  • Check results using MIN and IF.
  • Prepare class performance summaries.
  • Present student data using charts.
