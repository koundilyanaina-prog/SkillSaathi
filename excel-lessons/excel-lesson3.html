EXCEL BASICS · LESSON 03

Basic Formulas & Operators

Learn how to perform calculations in Excel using formulas, cell references and mathematical operators.

  • What formulas are in Excel.
  • Why formulas begin with an equals sign.
  • How to use cell references.
  • Addition, subtraction, multiplication and division.
  • How to use brackets in calculations.
  • How to copy formulas into other cells.
  • How to use the SUM function.

1. What is a Formula?

A formula is an expression used to perform calculations in Excel. It can contain numbers, mathematical operators, cell references and functions.

Important Rule

Every Excel formula must begin with an equals sign (=).

=10+20

When you enter this formula into a cell and press Enter, Excel displays the result 30.

2. Understanding Cell References

Instead of typing numbers directly into formulas, you can use cell addresses.

Cell Value
A1 100
A2 50
A3 =A1+A2

The formula in cell A3 uses the values from A1 and A2. Its result will be 150.

Why use cell references?

  • Formulas can update automatically when input values change.
  • You can reuse the same formula with different data.
  • It makes calculations easier to manage.

3. Mathematical Operators in Excel

Excel uses mathematical operators to perform different calculations.

Operation Operator Example Result
Addition + =10+5 15
Subtraction - =10-5 5
Multiplication * =10*5 50
Division / =10/5 2
Power ^ =2^3 8
Percentage % =50% 0.5

4. Creating Formulas with Cell References

Suppose you have the following monthly expense records:

Cell Expense Amount
A1 / B1 Rent 5000
A2 / B2 Food 3000
A3 / B3 Travel 1000

You can calculate the total in cell B4 using:

=B1+B2+B3

Result: 9000

If any expense changes, Excel recalculates the result automatically.

5. Understanding Brackets in Formulas

Brackets help control the order in which calculations are performed.

Example 1

=10+5*2

Result: 20, because multiplication is performed first.

Example 2

=(10+5)*2

Result: 30, because the calculation inside brackets happens first.

Remember: Excel follows mathematical order of operations. Brackets are evaluated before multiplication and division, which are evaluated before addition and subtraction.

6. Introduction to the SUM Function

SUM is an Excel function used to add numbers together. It is especially useful when working with large lists of values.

Formula

=SUM(B1:B5)

This adds all the values from cell B1 to cell B5.

Another Example

=SUM(10,20,30)

Result: 60

The colon (:) represents a range of cells. For example, B1:B5 means all cells from B1 through B5.

7. Copying Formulas

You do not need to write the same formula again and again. Excel allows you to copy formulas using the Fill Handle.

  1. Enter a formula in a cell.
  2. Select that cell.
  3. Move to the small square at its bottom-right corner.
  4. Drag it down or across to copy the formula.

Excel normally adjusts relative cell references automatically when a formula is copied.
