Logical Functions in Excel

Make Excel think and take decisions automatically using IF, AND, OR and NOT functions.

🎯 What You Will Learn

By the end of this lesson, you will be able to:

  • Understand logical functions in Excel.
  • Use the IF function to make decisions.
  • Check multiple conditions with AND.
  • Check alternative conditions with OR.
  • Reverse a logical result using NOT.
  • Combine logical functions in practical worksheets.

1. What Are Logical Functions?

Logical functions help Excel check conditions and return results based on whether those conditions are TRUE or FALSE.

For example, a teacher can use Excel to automatically decide whether a student has passed or failed an examination.

Example:

If a student scores 40 or more marks, show "Pass". Otherwise, show "Fail".

2. IF Function

The IF function checks a condition and returns one result if the condition is TRUE and another result if it is FALSE.

Syntax

=IF(logical_test, value_if_true, value_if_false)

Example: Pass or Fail

Suppose cell B2 contains a student's marks.

=IF(B2>=40,"Pass","Fail")

Excel checks whether B2 is greater than or equal to 40.

  • If the condition is TRUE, Excel displays Pass.
  • If the condition is FALSE, Excel displays Fail.

3. AND Function

AND checks multiple conditions. It returns TRUE only when all conditions are TRUE.

Syntax

=AND(condition1, condition2, ...)

Example

A student must score at least 40 in both Maths and English.

=AND(B2>=40,C2>=40)

The result will be TRUE only when both subjects have marks of 40 or more.

Remember: AND means ALL conditions must be TRUE.

4. OR Function

OR checks multiple conditions. It returns TRUE when at least one condition is TRUE.

Syntax

=OR(condition1, condition2, ...)

Example

A student receives an award if they score 90 or more in Maths or English.

=OR(B2>=90,C2>=90)

If either subject has 90 or more marks, the result will be TRUE.

Remember: OR means ANY ONE condition can be TRUE.

5. NOT Function

NOT reverses a logical result. TRUE becomes FALSE and FALSE becomes TRUE.

Syntax

=NOT(logical_test)

Example

=NOT(B2>=40)

If B2 is 50, the condition B2>=40 is TRUE. NOT reverses it and returns FALSE.

6. Combining IF with AND and OR

You can combine logical functions to create more useful decision-making formulas.

IF with AND

A student must pass both Maths and English.

=IF(AND(B2>=40,C2>=40),"Pass","Fail")

IF with OR

A student gets an award if either subject score is 90 or more.

=IF(OR(B2>=90,C2>=90),"Award","No Award")
💡 Important Tip: Text values such as "Pass", "Fail" and "Award" must be written inside double quotation marks.

7. Quick Comparison

Function Purpose
IF Returns a result based on a condition.
AND TRUE when all conditions are TRUE.
OR TRUE when at least one condition is TRUE.
NOT Reverses TRUE and FALSE.
