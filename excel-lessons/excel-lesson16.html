Lesson 16: Data Cleaning & Advanced Data Management

SkillSaathi · Excel & Office · Intermediate Level

1. What is Data Cleaning?

Data cleaning means finding and correcting errors in a dataset so that information becomes accurate, consistent and useful.

Common data problems include:

  • Duplicate records
  • Blank or missing values
  • Extra spaces in names or text
  • Different spellings or formats
  • Incorrect dates and numbers
  • Inconsistent entries such as Delhi, delhi and DELHI
Why it matters: Incorrect data can produce incorrect reports, calculations and business decisions.

2. Remove Duplicate Records

Duplicate records are repeated rows or entries. Excel can identify and remove them.

  1. Select your dataset.
  2. Open the Data tab.
  3. Click Remove Duplicates.
  4. Select the columns to check.
  5. Click OK and review the result.
Always keep a backup before removing duplicates. Check whether the entire row or only selected columns should be treated as duplicate.

3. Find & Replace

Find & Replace helps locate specific text or values and replace them quickly.

  • Ctrl + F: Find data.
  • Ctrl + H: Replace data.
Example: Replace the department name "HR Dept" with "Human Resources". Press Ctrl + H, enter both values and choose Replace All only after checking the matches.

4. Handle Blank Cells

Blank cells may affect totals, averages and reports. First understand why the value is missing.

  • Use filters to locate blank cells.
  • Fill missing values only when the correct value is known.
  • Use a clear label such as "Not Provided" when appropriate.
  • Do not replace every blank with zero automatically. Zero and missing data are different.
Example: If an employee's phone number is missing, do not enter 0 as a phone number. Keep it blank or use an agreed label.

5. TRIM and CLEAN Functions

TRIM removes unnecessary spaces from text. CLEAN removes many non-printable characters.

=TRIM(A2)

Removes extra spaces from the text in A2.

=CLEAN(A2)

Removes non-printable characters.

=TRIM(CLEAN(A2))

Combines both cleaning operations.

6. Text to Columns

Text to Columns splits information stored in one column into multiple columns.

Before: Nainsi,Kumari,Ranchi
After: Nainsi | Kumari | Ranchi
  1. Select the column containing combined text.
  2. Go to Data → Text to Columns.
  3. Choose Delimited or Fixed Width.
  4. Select the delimiter, such as comma or space.
  5. Preview the result and click Finish.

7. Data Validation

Data Validation controls what users can enter in a cell. It helps prevent incorrect entries.

  1. Select the required cells.
  2. Open Data → Data Validation.
  3. Choose a rule such as Whole Number, Date or List.
  4. Set the allowed values and save.
Dropdown example: Create a list of departments: HR, Sales, Accounts and IT. Users can select a department instead of typing it manually.

8. Flash Fill

Flash Fill recognises a pattern and fills the remaining values automatically.

Shortcut: Ctrl + E

If column A contains full names, type the first name in column B for the first row. Press Ctrl + E to fill the pattern for the remaining rows.

Imagine you receive this employee data:

  2. Use TRIM to remove extra spaces.
  3. Standardise city names consistently.
  4. Review the blank city value instead of guessing it.
  5. Create a department dropdown using Data Validation.
A good data-cleaning process protects the original data, checks each issue and records important changes.
