Lesson 14: Events and Event Listeners

Learn how JavaScript responds to clicks, keyboard actions, mouse movements, and other user interactions.

Part 2 – Core JavaScript

1. What are JavaScript Events?

An event is an action or occurrence that happens in the browser or on a webpage.

Events can be triggered by users or by the browser itself.

Examples of Events

  • Clicking a button.
  • Moving the mouse over an element.
  • Pressing a keyboard key.
  • Typing inside an input field.
  • Submitting a form.
  • Loading a webpage.
<button onclick="alert('Hello!')">
  Click Me
</button>

Here, clicking the button triggers a click event.

Events make webpages interactive by allowing JavaScript to respond to actions.

2. Common HTML Events

JavaScript supports many types of events.

Common Events

  • click – When an element is clicked.
  • dblclick – When an element is double-clicked.
  • mouseover – When the pointer moves over an element.
  • mouseout – When the pointer leaves an element.
  • keydown – When a key is pressed.
  • keyup – When a key is released.
  • input – When an input value changes.
  • change – When a form control's value is committed.
  • submit – When a form is submitted.
  • load – When a resource has finished loading.
const button = document.getElementById("myButton");

button.addEventListener("click", function() {
  console.log("Button clicked!");
});

3. What is an Event Listener?

An event listener is a function that waits for a particular event to happen on an element.

When that event occurs, the attached function executes.

Basic Syntax

element.addEventListener("event", function() {
  // Code to execute
});

Example

<button id="clickBtn">Click Me</button>

<script>
  const button = document.getElementById("clickBtn");

  button.addEventListener("click", function() {
    console.log("You clicked the button!");
  });
</script>

Whenever the button is clicked, the message appears in the browser console.

addEventListener() is the recommended way to attach event handlers because it keeps JavaScript behavior separate from HTML markup.

4. addEventListener() Method

The addEventListener() method attaches an event handler to an HTML element.

Syntax

element.addEventListener(event, function, useCapture);

Parameters:

  • event: The name of the event, such as "click".
  • function: The function that runs when the event occurs.
  • useCapture: An optional setting that controls the event propagation phase. Its default value is false.

Example

const heading = document.getElementById("title");

heading.addEventListener("click", function() {
  console.log("Heading clicked!");
});

You can also use an arrow function:

heading.addEventListener("click", () => {
  console.log("Heading clicked!");
});

5. Click Events

A click event occurs when a user clicks an element.

Example

<button id="myButton">Click Here</button>

<script>
  const button = document.getElementById("myButton");

  button.addEventListener("click", function() {
    alert("Welcome to SkillSaathi!");
  });
</script>

Double Click Event

button.addEventListener("dblclick", function() {
  console.log("Button double-clicked!");
});
A single click triggers the click event. A double-click can trigger click events as well as a dblclick event.

6. Mouse Events

Mouse events occur when a user interacts with an element using a mouse or pointer.

Common Mouse Events

  • mouseover – Pointer enters an element or one of its descendants.
  • mouseout – Pointer leaves an element or one of its descendants.
  • mousedown – Mouse button is pressed.
  • mouseup – Mouse button is released.
  • mousemove – Pointer moves over an element.

Example

const box = document.getElementById("myBox");

box.addEventListener("mouseover", function() {
  console.log("Mouse entered the box");
});

box.addEventListener("mouseout", function() {
  console.log("Mouse left the box");
});
Mouse events are useful for interactive cards, hover effects, games, and visual feedback.

7. Keyboard Events

Keyboard events occur when a user presses or releases a key.

Important Keyboard Events

  • keydown – Fires when a key is pressed.
  • keyup – Fires when a key is released.

Example

document.addEventListener("keydown", function(event) {
  console.log("Key pressed:", event.key);
});

If the user presses the letter A, the console displays:

Key pressed: a

You can also check for a specific key:

document.addEventListener("keydown", function(event) {
  if(event.key === "Enter") {
    console.log("Enter key pressed!");
  }
});

8. Input Events

The input event occurs whenever the value of an input or textarea changes due to user interaction.

Example

<input type="text" id="username" placeholder="Enter your name">

<script>
  const input = document.getElementById("username");

  input.addEventListener("input", function() {
    console.log(input.value);
  });
</script>

As the user types, the current input value is displayed.

Change Event

The change event fires when a value is committed. For text inputs, this generally happens after the value changes and the field loses focus.

input.addEventListener("change", function() {
  console.log("Final value:", input.value);
});
input is useful for live feedback. change is useful when you want to respond after a value has been committed.

9. Event Object

When an event occurs, the browser provides an event object containing information about that event.

We can receive it as a parameter in the event handler function.

Example

const button = document.getElementById("myButton");

button.addEventListener("click", function(event) {
  console.log(event.type);
  console.log(event.target);
});

Some useful event object properties:

  • event.type – The event's name.
  • event.target – The element that triggered the event.
  • event.currentTarget – The element whose listener is currently running.
  • event.key – The key involved in a keyboard event.
  • event.clientX – Horizontal mouse position relative to the viewport.
  • event.clientY – Vertical mouse position relative to the viewport.
The event object helps us understand what happened and which element was involved.

10. Removing Event Listeners

The removeEventListener() method removes an event listener that was previously attached to an element.

To remove a listener, we must use the same event name and the same function reference that was originally registered.

Example

const button = document.getElementById("myButton");

function showMessage() {
  console.log("Button clicked!");
}

button.addEventListener("click", showMessage);

// Remove the listener
button.removeEventListener("click", showMessage);
An anonymous function cannot be removed by writing another identical-looking anonymous function. Use a named function or keep the original function reference.

11. Practical Examples

Example 1: Button Click Counter

<button id="countBtn">Click Me</button>
<p id="countText">Clicks: 0</p>

<script>
  let count = 0;

  const button = document.getElementById("countBtn");
  const text = document.getElementById("countText");

  button.addEventListener("click", function() {
    count++;
    text.textContent = "Clicks: " + count;
  });
</script>

Example 2: Mouse Hover

<div id="hoverBox">Move your mouse here</div>

<script>
  const box = document.getElementById("hoverBox");

  box.addEventListener("mouseover", function() {
    console.log("Mouse entered!");
  });

  box.addEventListener("mouseout", function() {
    console.log("Mouse left!");
  });
</script>

Example 3: Live Input Display

<input id="nameInput" placeholder="Your name">
<p id="preview"></p>

<script>
  const input = document.getElementById("nameInput");
  const preview = document.getElementById("preview");

  input.addEventListener("input", function() {
    preview.textContent = input.value;
  });
</script>
