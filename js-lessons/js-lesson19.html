1. Introduction to Errors

An error is a problem in a program that prevents the code from working as expected.

Errors can occur for many reasons:

  • Incorrect JavaScript syntax.
  • Using a variable that does not exist.
  • Calling a method that is not available.
  • Using an incorrect calculation or condition.
  • Receiving unexpected data from an external source.

Example

console.log("Program started");

console.log(userName);

console.log("Program finished");

If userName has not been declared, JavaScript throws a ReferenceError. The last statement will not execute in this example.

Understanding errors helps developers find problems and write reliable programs.

2. Types of JavaScript Errors

JavaScript programs commonly encounter three broad categories of problems:

1. Syntax Errors

These occur when code does not follow JavaScript grammar rules.

2. Runtime Errors

These occur while the program is executing.

3. Logical Errors

The program runs, but produces an incorrect result because the logic is wrong.

Syntax and runtime errors can be reported by JavaScript. Logical errors often require testing and careful debugging to discover.

3. Syntax Errors

A syntax error occurs when JavaScript cannot understand the structure of the code.

Missing Closing Bracket

if (10 > 5 {
  console.log("Greater");
}

The closing parenthesis is missing. Correct code:

if (10 > 5) {
  console.log("Greater");
}

Missing Quotes

console.log("Hello World);

Correct code:

console.log("Hello World");

Missing Comma in an Object

const student = {
  name: "Aman"
  age: 21
};

Correct code:

const student = {
  name: "Aman",
  age: 21
};
Always check brackets, parentheses, quotes and commas when a syntax error appears.

4. Runtime Errors

A runtime error occurs while JavaScript is executing a program.

Example: Undefined Variable

console.log(studentName);

// ReferenceError:
// studentName is not defined

Example: Calling a Non-Function

const number = 10;

number();

This produces a TypeError because a number cannot be called like a function.

Example: Accessing null

const user = null;

console.log(user.name);

JavaScript cannot read the name property of null.

5. Logical Errors

A logical error occurs when code runs without crashing but gives the wrong result.

Example: Incorrect Calculation

const price = 100;
const quantity = 3;

// Incorrect calculation
const total = price + quantity;

console.log(total); // 103

The correct calculation should multiply price by quantity.

const price = 100;
const quantity = 3;

const total = price * quantity;

console.log(total); // 300

Example: Incorrect Condition

const marks = 75;

if (marks > 90) {
  console.log("Passed");
} else {
  console.log("Not Passed");
}

If the passing mark is 40, the condition is incorrect. Correct version:

const marks = 75;

if (marks >= 40) {
  console.log("Passed");
} else {
  console.log("Not Passed");
}
Logical errors are often difficult to identify because the program may run normally.

6. Understanding Error Messages

JavaScript error messages usually provide useful information about what went wrong.

Example

console.log(studentName);

Possible error:

ReferenceError: studentName is not defined

Understand the message:

  • ReferenceError: The type of error.
  • studentName: The variable involved.
  • is not defined: The problem detected by JavaScript.

Common Error Names

  • SyntaxError: Invalid JavaScript syntax.
  • ReferenceError: Invalid or unavailable variable reference.
  • TypeError: An operation is performed on an unsuitable value or type.
  • RangeError: A value is outside an allowed range.
  • URIError: Incorrect use of certain URI handling functions.

7. Introduction to Debugging

Debugging is the process of finding, understanding and fixing errors in a program.

Basic Debugging Steps

  1. Run your program.
  2. Observe the output and error messages.
  3. Identify the line where the problem occurs.
  4. Check the variables and conditions.
  5. Fix the problem.
  6. Run the program again to verify the result.
Debugging is not just about fixing errors. It also helps you understand how your program works.

8. Using console.log()

console.log() is one of the simplest debugging tools in JavaScript. It helps us inspect variable values and program execution.

Checking Variable Values

const price = 500;
const quantity = 3;

console.log("Price:", price);
console.log("Quantity:", quantity);

const total = price * quantity;

console.log("Total:", total);

Checking Conditions

const age = 20;

console.log("Age:", age);
console.log("Is adult:", age >= 18);

if (age >= 18) {
  console.log("Eligible");
}

Other Console Methods

console.warn("This is a warning");

console.error("This is an error");

console.info("Information message");

console.table([
  {name: "Aman", age: 21},
  {name: "Riya", age: 22}
]);

9. Browser Developer Tools

Browser Developer Tools help developers inspect web pages, debug JavaScript and examine errors.

How to Open Developer Tools

  • Press F12 on your keyboard.
  • Or press Ctrl + Shift + I.
  • Or right-click the webpage and select Inspect.

Important Tabs

  • Elements: Inspect and modify HTML and CSS.
  • Console: View JavaScript output and errors.
  • Sources: View source files and use breakpoints.
  • Network: Inspect network requests and responses.
For JavaScript debugging, the Console and Sources tabs are especially useful.

10. Breakpoints and Step-by-Step Debugging

A breakpoint pauses JavaScript execution at a selected line so you can inspect what is happening.

How to Set a Breakpoint

  1. Open Developer Tools using F12.
  2. Select the Sources tab.
  3. Open your JavaScript file.
  4. Click the line number where you want execution to pause.
  5. Reload or run the page.

Useful Debugging Controls

  • Resume: Continue program execution.
  • Step Over: Execute the current line and move to the next line.
  • Step Into: Enter a function call.
  • Step Out: Finish the current function and return to its caller.
  • Watch: Track selected variable values.

Using debugger Statement

const price = 100;
const quantity = 5;

debugger;

const total = price * quantity;

console.log(total);

When Developer Tools are open, the debugger statement can pause execution at that point.

11. try...catch

The try...catch statement allows us to handle certain runtime errors without immediately stopping the rest of the program.

Basic Syntax

try {
  // Code that may cause an error
} catch (error) {
  // Handle the error
}

Example

try {
  console.log(userName);
} catch (error) {
  console.log("Something went wrong");
}

console.log("Program continues");

The error is handled by the catch block, so the next statement can execute.

Accessing the Error Message

try {
  const result = unknownFunction();
} catch (error) {
  console.log(error.message);
}
try...catch handles runtime exceptions. It does not catch ordinary syntax errors in the same script before execution begins.

12. The finally Block

The finally block executes after the try and catch flow, whether an error occurred or not.

Syntax

try {
  // Try code
} catch (error) {
  // Error handling
} finally {
  // Cleanup code
}

Example with an Error

try {
  console.log("Starting operation");

  throw new Error("Something went wrong");

} catch (error) {
  console.log("Error:", error.message);

} finally {
  console.log("Operation finished");
}

Example without an Error

try {
  console.log("Everything is working");
} catch (error) {
  console.log("Error occurred");
} finally {
  console.log("This block still runs");
}
The finally block is commonly used for cleanup tasks, such as closing resources or resetting a loading indicator.

13. Throwing Custom Errors

The throw statement allows developers to create their own errors when a condition is not valid.

Basic Example

const age = 15;

if (age < 18) {
  throw new Error("You must be 18 or older");
}

Using throw with try...catch

function checkAge(age) {
  if (age < 18) {
    throw new Error("Age must be 18 or above");
  }

  return "Access granted";
}

try {
  console.log(checkAge(15));
} catch (error) {
  console.log(error.message);
}

Validate a Price

function calculateDiscount(price) {
  if (price < 0) {
    throw new Error("Price cannot be negative");
  }

  return price * 0.10;
}

try {
  console.log(calculateDiscount(-100));
} catch (error) {
  console.log("Validation Error:", error.message);
}

14. Error Objects

JavaScript provides the built-in Error object to represent errors.

Creating an Error Object

const error = new Error("Something went wrong");

console.log(error.name);
console.log(error.message);

Important Properties

  • name: The name or type of the error.
  • message: A description of the problem.
  • stack: A stack trace that helps identify where an error occurred. Its format can vary by browser.
try {
  throw new Error("Invalid user data");
} catch (error) {
  console.log("Name:", error.name);
  console.log("Message:", error.message);
  console.log("Stack:", error.stack);
}

Built-in Error Types

new Error("General error");
new TypeError("Invalid type");
new ReferenceError("Invalid reference");
new RangeError("Value out of range");

15. Practical Error Handling Examples

Example 1: Safe Division

function divide(a, b) {
  if (b === 0) {
    throw new Error("Cannot divide by zero");
  }

  return a / b;
}

try {
  console.log(divide(20, 0));
} catch (error) {
  console.log("Error:", error.message);
}

Example 2: Student Marks Validation

function checkMarks(marks) {
  if (typeof marks !== "number") {
    throw new TypeError("Marks must be a number");
  }

  if (marks < 0 || marks > 100) {
    throw new RangeError("Marks must be between 0 and 100");
  }

  return "Valid marks: " + marks;
}

try {
  console.log(checkMarks(85));
} catch (error) {
  console.log(error.name + ": " + error.message);
}

Example 3: Safe JSON Parsing

const data = '{"name":"Aman","age":21}';

try {
  const student = JSON.parse(data);
  console.log(student.name);
} catch (error) {
  console.log("Invalid JSON:", error.message);
}

Example 4: Handling Missing User Data

function getUserName(user) {
  try {
    if (!user || !user.name) {
      throw new Error("User name is missing");
    }

    return user.name;

  } catch (error) {
    return "Error: " + error.message;
  }
}

console.log(getUserName({name: "Riya"}));
console.log(getUserName({}));
