Lesson 16: ES6 Features and Template Literals

Explore modern JavaScript features introduced with ECMAScript 2015 (ES6) and learn how they make code cleaner and easier to write.

Part 3 – Advanced JavaScript

1. Introduction to ES6

ES6 stands for ECMAScript 2015. It introduced many useful features that made JavaScript more powerful, readable, and easier to maintain.

Why was ES6 introduced?

  • To improve JavaScript syntax.
  • To make code shorter and easier to understand.
  • To support modern application development.
  • To introduce better ways of working with functions, objects, and strings.

Some Important ES6 Features

  • let and const
  • Arrow functions
  • Template literals
  • Default parameters
  • Destructuring
  • Spread and rest syntax
  • Classes and modules
  • Promises
In this lesson, we will focus on selected ES6 features. Destructuring and spread syntax will be studied in detail in Lesson 17.

2. What is ECMAScript?

ECMAScript is the standard specification that defines how JavaScript should work.

JavaScript is an implementation of the ECMAScript standard, along with additional environment-specific features provided by browsers and other runtimes.

Important Versions

  • ES5 (2009): Introduced features such as strict mode and JSON support.
  • ES6 / ES2015: Introduced let, const, arrow functions, template literals, classes, and more.
  • Modern ECMAScript: Continues to add new language features every year.
ES6 was a major update to JavaScript and is still an important foundation for modern JavaScript development.

3. let and const (ES6 Recap)

ES6 introduced let and const as improved ways to declare variables.

Using let

let age = 20;

age = 21;

console.log(age);

Output: 21

Using const

const country = "India";

console.log(country);

A const variable cannot be reassigned after initialization.

Difference Between let and const

  • let allows reassignment.
  • const does not allow reassignment.
  • Both are block-scoped.
  • Both cannot be accessed before their declaration is initialized.
let score = 50;
score = 75;

const pi = 3.14;

// pi = 3.14159; // TypeError
Use const by default when reassignment is not needed. Use let when a variable's value must change.

4. Arrow Functions

Arrow functions provide a shorter syntax for writing function expressions.

Traditional Function

function greet() {
  return "Hello!";
}

console.log(greet());

Arrow Function

const greet = () => {
  return "Hello!";
};

console.log(greet());

Shorter Syntax

const greet = () => "Hello!";

console.log(greet());

Arrow Function with Parameters

const add = (a, b) => {
  return a + b;
};

console.log(add(10, 5));

Output: 15

Single Parameter

const square = number => number * number;

console.log(square(4));

Output: 16

Arrow functions do not have their own this value. They inherit this from the surrounding scope, so they are not a direct replacement for every traditional function.

5. Template Literals

Template literals provide an easier way to create strings using backticks instead of single or double quotation marks.

Traditional String Concatenation

const name = "Nainsi";
const message = "Hello " + name + "!";

console.log(message);

Using Template Literals

const name = "Nainsi";
const message = `Hello ${name}!`;

console.log(message);

Output: Hello Nainsi!

Important Points

  • Template literals use backticks ( ` ).
  • Variables can be inserted using ${}.
  • Expressions can also be inserted inside ${}.
  • They support multi-line strings.
Template literals make dynamic strings easier to read and maintain.

6. String Interpolation

String interpolation means inserting variables or expressions directly inside a string.

Example with Variables

const firstName = "Nainsi";
const course = "JavaScript";

const message = `Hello ${firstName}, welcome to ${course}!`;

console.log(message);

Example with Expressions

const a = 10;
const b = 20;

console.log(`Total: ${a + b}`);
console.log(`Double of a: ${a * 2}`);

Output:

Total: 30
Double of a: 20

Calling a Function Inside a Template Literal

function getName() {
  return "SkillSaathi";
}

console.log(`Welcome to ${getName()}!`);

7. Multi-line Strings

Before template literals, developers often used special newline characters or concatenation to create multi-line strings.

Older Approach

const message = "Hello!\n" +
                "Welcome to SkillSaathi.\n" +
                "Keep learning!";

console.log(message);

Using Template Literals

const message = `Hello!
Welcome to SkillSaathi.
Keep learning!`;

console.log(message);

Template literals preserve line breaks and make long strings easier to write.

8. Default Parameters

Default parameters allow a function to use a predefined value when an argument is not provided or is undefined.

Example

function greet(name = "Student") {
  return `Hello, ${name}!`;
}

console.log(greet("Nainsi"));
console.log(greet());

Output:

Hello, Nainsi!
Hello, Student!

Default Parameters with Multiple Values

function calculateTotal(price, quantity = 1) {
  return price * quantity;
}

console.log(calculateTotal(100, 3));
console.log(calculateTotal(100));

Output:

300
100
A default parameter is used when the argument is missing or undefined. Passing null does not activate the default value.

9. Enhanced Object Literals

ES6 introduced shorter and more convenient ways to define object properties and methods.

Property Shorthand

const name = "Nainsi";
const age = 25;

const student = {
  name,
  age
};

console.log(student);

When the property name and variable name are the same, we can write the property only once.

Method Shorthand

const student = {
  name: "Nainsi",

  greet() {
    return `Hello, I am ${this.name}`;
  }
};

console.log(student.greet());

Computed Property Names

const property = "course";

const student = {
  name: "Nainsi",
  [property]: "JavaScript"
};

console.log(student.course);
Enhanced object literals help us write shorter and cleaner object definitions.

10. for...of Loop

The for...of loop is used to iterate over iterable values such as arrays and strings.

Loop Through an Array

const subjects = ["HTML", "CSS", "JavaScript"];

for(const subject of subjects) {
  console.log(subject);
}

Loop Through a String

const word = "CODE";

for(const letter of word) {
  console.log(letter);
}

Using let

const numbers = [10, 20, 30];

for(let number of numbers) {
  console.log(number);
}
for...of gives us the values of an iterable. It is different from for...in, which iterates over property keys.

11. Spread Syntax – Introduction

Spread syntax uses three dots (...) to expand the elements of an iterable or the properties of an object in certain contexts.

Example with an Array

const numbers = [10, 20, 30];

console.log(...numbers);

Output: 10 20 30

Copying an Array

const original = [1, 2, 3];
const copy = [...original];

console.log(copy);

Combining Arrays

const first = [1, 2];
const second = [3, 4];

const combined = [...first, ...second];

console.log(combined);
This is only an introduction. Lesson 17 will cover spread syntax and destructuring in detail, including practical examples.

12. Practical Examples

Example 1: Student Greeting

const studentName = "Aarav";
const courseName = "JavaScript";

const greet = () => {
  return `Welcome ${studentName} to ${courseName}!`;
};

console.log(greet());

Example 2: Shopping Bill

const calculateBill = (price, quantity = 1) => {
  const total = price * quantity;
  return `Your total bill is ₹${total}`;
};

console.log(calculateBill(250, 2));
console.log(calculateBill(150));

Example 3: Display Subjects

const subjects = ["HTML", "CSS", "JavaScript"];

for(const subject of subjects) {
  console.log(`You are learning ${subject}`);
}

Example 4: Create a Student Object

const name = "Meera";
const course = "Web Development";

const student = {
  name,
  course,

  introduce() {
    return `I am ${this.name} and I study ${this.course}.`;
  }
};

console.log(student.introduce());
