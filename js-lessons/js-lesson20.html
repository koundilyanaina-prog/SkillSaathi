1. Introduction to JSON

JSON stands for JavaScript Object Notation. It is a lightweight text format used to store and exchange data.

JSON is commonly used when:

  • Sending data between a website and a server.
  • Receiving information from APIs.
  • Saving structured data.
  • Sharing information between different programming languages.

Example JSON Data

{
  "name": "Aman",
  "age": 21,
  "course": "MCA"
}

This example represents information about a student using JSON format.

JSON is a text-based data format. It looks similar to JavaScript objects, but its syntax has stricter rules.

2. JSON Structure and Syntax

JSON data is commonly organized using objects and arrays.

JSON Object

{
  "name": "Riya",
  "age": 22,
  "city": "Ranchi"
}

JSON Array

[
  "HTML",
  "CSS",
  "JavaScript"
]

Array of Objects

[
  {
    "name": "Aman",
    "age": 21
  },
  {
    "name": "Neha",
    "age": 22
  }
]

JSON objects use key-value pairs, while JSON arrays store ordered collections of values.

3. JSON Data Types and Rules

JSON supports the following data types:

  • String: Text enclosed in double quotes.
  • Number: Integer or decimal numbers.
  • Boolean: true or false.
  • Null: Represents an empty or absent value.
  • Object: A collection of key-value pairs.
  • Array: An ordered list of values.

Valid JSON

{
  "name": "Aman",
  "age": 21,
  "isStudent": true,
  "address": null,
  "subjects": ["HTML", "CSS"]
}

Important JSON Rules

  • Property names must use double quotes.
  • String values must use double quotes.
  • Single quotes are not valid JSON string delimiters.
  • JSON does not allow comments.
  • Trailing commas are not allowed.
  • JSON does not support functions or undefined values.
JSON is stricter than JavaScript object syntax. Always check quotation marks and commas.

4. JSON.stringify()

The JSON.stringify() method converts a JavaScript value into a JSON string.

Basic Example

const student = {
  name: "Aman",
  age: 21
};

const jsonData = JSON.stringify(student);

console.log(jsonData);

// {"name":"Aman","age":21}

Pretty-Printed JSON

You can use the third argument to add indentation and make JSON easier to read.

const student = {
  name: "Riya",
  age: 22,
  course: "MCA"
};

const jsonData = JSON.stringify(student, null, 2);

console.log(jsonData);

Converting an Array

const subjects = ["HTML", "CSS", "JavaScript"];

const jsonData = JSON.stringify(subjects);

console.log(jsonData);
JSON.stringify() is useful when you need to send data to a server or save structured information as text.

5. JSON.parse()

The JSON.parse() method converts a valid JSON string into a JavaScript value.

Basic Example

const jsonData = '{"name":"Aman","age":21}';

const student = JSON.parse(jsonData);

console.log(student.name);
console.log(student.age);

Converting JSON Array

const jsonData = '["HTML","CSS","JavaScript"]';

const subjects = JSON.parse(jsonData);

console.log(subjects[0]);
console.log(subjects.length);

Difference Between stringify() and parse()

  • stringify(): JavaScript value → JSON string.
  • parse(): JSON string → JavaScript value.
Use JSON.parse() only with valid JSON text. Invalid JSON causes a SyntaxError.

6. Working with Objects and Arrays

JSON can represent nested objects and arrays. We can convert them to strings and back into JavaScript values.

Nested Object Example

const student = {
  name: "Neha",
  education: {
    course: "MCA",
    university: "Ranchi University"
  },
  skills: ["HTML", "CSS", "JavaScript"]
};

const jsonData = JSON.stringify(student);

const newStudent = JSON.parse(jsonData);

console.log(newStudent.education.course);
console.log(newStudent.skills[1]);

Accessing Array of Objects

const jsonData = `[
  {"name":"Aman","marks":80},
  {"name":"Riya","marks":90}
]`;

const students = JSON.parse(jsonData);

console.log(students[0].name);
console.log(students[1].marks);

After parsing, you can use normal JavaScript property access and array indexing.

7. Handling JSON Errors

Invalid JSON data can cause errors during parsing. Use try...catch to handle these errors safely.

Invalid JSON Example

const data = '{"name":"Aman", age:21}';

try {
  const student = JSON.parse(data);
  console.log(student);
} catch (error) {
  console.log("Invalid JSON:", error.message);
}

Safe JSON Parsing Function

function safeParse(data) {
  try {
    return JSON.parse(data);
  } catch (error) {
    console.log("Could not read JSON:", error.message);
    return null;
  }
}

const result = safeParse('{"name":"Riya"}');

console.log(result);
Never assume that data received from an external source is always valid. Validate and handle errors when parsing it.

8. Introduction to Local Storage

Local Storage is a browser feature that allows websites to store small amounts of data as key-value pairs.

Important features:

  • Data remains available after refreshing the page.
  • Data usually remains after closing and reopening the browser.
  • Data is stored as strings.
  • Each website has its own storage area.
  • Users can inspect or clear it through browser Developer Tools.

Where is Local Storage?

  1. Open your website in the browser.
  2. Press F12 to open Developer Tools.
  3. Select the Application tab in Chrome.
  4. Find Local Storage in the left sidebar.
  5. Select your website's origin.
Do not store passwords, payment information or sensitive personal data in Local Storage. It is accessible to JavaScript running on the same origin.

9. localStorage.setItem()

The setItem() method stores a key-value pair in Local Storage.

Syntax

localStorage.setItem("key", "value");

Example

localStorage.setItem("username", "Aman");
localStorage.setItem("course", "JavaScript");

console.log("Data saved");

Open the browser's Application tab to see the saved values.

Saving Numbers

localStorage.setItem("score", 95);

console.log(localStorage.getItem("score")); 
// "95" (string)
Local Storage stores values as strings. Numbers and booleans are converted to strings when saved.

10. localStorage.getItem()

The getItem() method retrieves a value using its key.

Example

localStorage.setItem("username", "Riya");

const user = localStorage.getItem("username");

console.log(user);

When a Key Does Not Exist

const data = localStorage.getItem("unknownKey");

console.log(data);

// null

Converting a Stored Number

localStorage.setItem("marks", "85");

const marks = Number(localStorage.getItem("marks"));

console.log(marks + 5);

// 90
getItem() returns null when the requested key is not present.

11. removeItem() and clear()

Local Storage provides methods to remove saved information.

removeItem()

Removes one specific key and its value.

localStorage.setItem("username", "Aman");

localStorage.removeItem("username");

console.log(localStorage.getItem("username"));
// null

clear()

Removes all keys and values from the current website's Local Storage.

localStorage.setItem("name", "Riya");
localStorage.setItem("course", "JavaScript");

localStorage.clear();

console.log(localStorage.length);

// 0
Be careful with clear(). It removes all Local Storage entries for the current origin, not just one selected key.

12. Storing Objects with JSON

Local Storage stores strings, so we use JSON.stringify() to save objects and JSON.parse() to retrieve them.

Save an Object

const student = {
  name: "Aman",
  age: 21,
  course: "MCA"
};

localStorage.setItem(
  "student",
  JSON.stringify(student)
);

Retrieve an Object

const savedData = localStorage.getItem("student");

if (savedData !== null) {
  const student = JSON.parse(savedData);
  console.log(student.name);
  console.log(student.course);
}

Complete Example

const student = {
  name: "Neha",
  marks: [80, 90, 85]
};

// Save
localStorage.setItem("studentData", JSON.stringify(student));

// Retrieve
const saved = localStorage.getItem("studentData");

if (saved) {
  const data = JSON.parse(saved);
  console.log(data.name);
  console.log(data.marks);
}
Remember the two-step process: stringify before saving and parse after retrieving.

13. Local Storage vs Session Storage

Both Local Storage and Session Storage store key-value data in the browser, but their lifetimes are different.

Feature Local Storage Session Storage
Lifetime Persists until cleared Usually until the tab session ends
Refresh Data remains Data remains
Storage API localStorage sessionStorage
Scope Same origin Same origin and tab session

Session Storage Example

sessionStorage.setItem("currentPage", "dashboard");

const page = sessionStorage.getItem("currentPage");

console.log(page);

Session Storage is useful for temporary information that should not normally remain after the tab session ends.

14. Practical Examples

Example 1: Save Theme Preference

localStorage.setItem("theme", "dark");

const savedTheme = localStorage.getItem("theme");

console.log("Selected theme:", savedTheme);

Example 2: Save a List of Subjects

const subjects = ["HTML", "CSS", "JavaScript"];

localStorage.setItem("subjects", JSON.stringify(subjects));

const savedSubjects = JSON.parse(
  localStorage.getItem("subjects")
);

console.log(savedSubjects);

Example 3: Save and Update User Profile

const user = {
  name: "Aman",
  city: "Ranchi"
};

localStorage.setItem("profile", JSON.stringify(user));

const savedUser = JSON.parse(
  localStorage.getItem("profile")
);

savedUser.city = "Patna";

localStorage.setItem("profile", JSON.stringify(savedUser));

console.log(savedUser);

Example 4: Safe Storage Access

try {
  const data = {
    name: "Riya",
    course: "MCA"
  };

  localStorage.setItem("profile", JSON.stringify(data));

  const saved = localStorage.getItem("profile");

  console.log(JSON.parse(saved));

} catch (error) {
  console.log("Storage error:", error.message);
}
