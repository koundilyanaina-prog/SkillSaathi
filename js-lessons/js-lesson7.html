Functions and Parameters

Learn how to create reusable blocks of code, pass information to functions and return results.

1. Introduction to Functions

A function is a reusable block of code designed to perform a particular task.

Instead of writing the same code repeatedly, you can write it once inside a function and use it whenever needed.

Example

function greet() {
    console.log("Welcome to SkillSaathi!");
}

greet();

Output:

Welcome to SkillSaathi!

Here, greet is the function name. The code inside the function runs when the function is called.

2. Why Do We Use Functions?

Functions help us organize programs and avoid repeating the same code.

  • Code Reusability: Write code once and use it multiple times.
  • Better Organization: Divide a large program into smaller parts.
  • Easy Maintenance: Update code in one place.
  • Readability: Make programs easier to understand.
  • Less Repetition: Avoid writing identical code again and again.

Without a Function

console.log("Hello Aarav");
console.log("Hello Meera");
console.log("Hello Riya");

With a Function

function greet(name) {
    console.log("Hello " + name);
}

greet("Aarav");
greet("Meera");
greet("Riya");

3. Function Declaration

A function declaration defines a function using the function keyword, followed by its name and parentheses.

Syntax

function functionName() {
    // Statements
}

Example

function showMessage() {
    console.log("Learning JavaScript is fun!");
}

showMessage();

A function declaration has three main parts:

PartDescription
functionKeyword used to declare a function.
Function nameName used to identify and call the function.
Function bodyCode written inside curly braces.

4. Calling a Function

Defining a function does not automatically execute it. You must call the function to run its code.

Example

function welcome() {
    console.log("Welcome!");
}

// Calling the function
welcome();
welcome();
welcome();

Output:

Welcome!
Welcome!
Welcome!

You can call a function multiple times whenever you need it.

5. Parameters and Arguments

Parameters allow functions to receive information. Arguments are the actual values passed when calling a function.

Example

function greet(name) {
    console.log("Hello " + name);
}

greet("Aarav");
greet("Meera");

In this example:

  • name is a parameter.
  • "Aarav" and "Meera" are arguments.

Multiple Parameters

function add(a, b) {
    console.log(a + b);
}

add(10, 20);
add(5, 15);

Output:

30
20

Parameters vs Arguments

Written in function definition.Passed during function call.
Act as input variables.Provide actual input values.

6. Return Statement

The return statement sends a value back from a function to the place where it was called.

Example

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

Output: 30

Return vs console.log

function calculate1(a, b) {
    console.log(a + b);
}

function calculate2(a, b) {
    return a + b;
}

let answer = calculate2(5, 10);

console.log(answer);

console.log: Displays information in the console.

return: Sends a value back so it can be stored, reused or calculated further.

Important

Once JavaScript reaches a return statement, the function stops executing.

function test() {
    return "Finished";
    console.log("This will not run");
}

console.log(test());

7. Function Expressions

A function expression stores a function inside a variable.

Example

const greet = function() {
    console.log("Hello from a function expression!");
};

greet();

Functions created using function expressions can also receive parameters and return values.

Example with Parameters

const multiply = function(a, b) {
    return a * b;
};

console.log(multiply(4, 5));

Output: 20

Unlike a normal function declaration, a function expression cannot generally be called before its assignment is initialized.

8. Arrow Functions

Arrow functions provide a shorter syntax for writing functions. They were introduced in ES6.

Basic Syntax

const functionName = () => {
    // Statements
};

Example

const greet = () => {
    console.log("Hello JavaScript!");
};

greet();

Arrow Function with Parameters

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 5));

Shorter Return Syntax

When the function contains a single expression, you can omit curly braces and the return keyword.

const square = number => number * number;

console.log(square(5));

Output: 25

Different Function Styles

9. Default Parameters

Default parameters provide a predefined value when an argument is not supplied during a function call.

Example

function greet(name = "Student") {
    console.log("Hello " + name);
}

greet("Aarav");
greet();

Output:

Hello Aarav
Hello Student

Multiple Default Parameters

function calculateTotal(price, quantity = 1) {
    return price * quantity;
}

console.log(calculateTotal(100, 3));
console.log(calculateTotal(100));

Output:

300
100

10. Practical Examples

Example 1: Calculate Square

function square(number) {
    return number * number;
}

console.log(square(4));
console.log(square(8));

Example 2: Calculate Rectangle Area

function rectangleArea(length, width) {
    return length * width;
}

let area = rectangleArea(10, 5);

console.log("Area:", area);

Example 3: Student Result

function checkResult(marks) {
    if (marks >= 40) {
        return "Pass";
    }

    return "Fail";
}

console.log(checkResult(75));
console.log(checkResult(30));

Example 4: Arrow Function for Discount

const calculateDiscount = (price, discount) => {
    return price - (price * discount / 100);
};

console.log(calculateDiscount(1000, 10));

Output: 900
