Lesson 15: Forms and Form Validation

Learn how to collect user information, handle form submissions, and validate form data using JavaScript.

Part 2 – Core JavaScript

1. Introduction to HTML Forms

HTML forms are used to collect information from users. They allow visitors to enter details such as their name, email, password, and other information.

Common Form Elements

  • input – Accepts different types of user input.
  • label – Describes an input field.
  • textarea – Accepts longer text.
  • select – Creates a dropdown list.
  • option – Defines an item in a dropdown.
  • button – Creates a clickable button.

Example

<form id="myForm">
  <label for="name">Name:</label>
  <input type="text" id="name">

  <label for="email">Email:</label>
  <input type="email" id="email">

  <button type="submit">Submit</button>
</form>
Forms provide a structured way to collect information from website users.

2. Selecting Form Elements

Before working with form values, we need to select the form elements using JavaScript.

Using getElementById()

const nameInput = document.getElementById("name");
const emailInput = document.getElementById("email");

Using querySelector()

const form = document.querySelector("#myForm");
const button = document.querySelector("button");

Accessing an Input Value

const username = document.getElementById("name").value;

console.log(username);

The value property returns the current value entered in an input field.

3. The Submit Event

The submit event occurs when a user submits a form, usually by clicking its submit button or pressing Enter in a form field.

Example

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
  console.log("Form submitted!");
});

We can use this event to check the user's information before processing the form.

4. Reading Form Values

JavaScript can read the values entered by users through the value property.

Example

const nameInput = document.getElementById("name");
const emailInput = document.getElementById("email");

console.log("Name:", nameInput.value);
console.log("Email:", emailInput.value);

Trimming Extra Spaces

const username = nameInput.value.trim();

The trim() method removes unnecessary spaces from the beginning and end of a string.

5. Preventing Default Form Submission

By default, submitting an HTML form can reload the page or navigate to another location.

The preventDefault() method stops this default browser behavior.

Example

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
  event.preventDefault();

  console.log("Default submission stopped!");
});
preventDefault() is commonly used when JavaScript needs to validate or process form data without reloading the page.

6. Required Field Validation

Required field validation checks whether the user has filled in important fields.

Example

const name = document.getElementById("name").value.trim();

if(name === "") {
  console.log("Name is required!");
} else {
  console.log("Name is valid.");
}

HTML also provides a built-in required attribute:

<input type="text" id="name" required>
HTML validation is useful for basic checks. JavaScript gives us more control over custom validation messages and behavior.

7. Email Validation

Email validation checks whether an email address follows a basic email format.

Example Using a Regular Expression

const email = "student@example.com";

const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if(emailPattern.test(email)) {
  console.log("Valid email format");
} else {
  console.log("Invalid email format");
}

The test() method checks whether a string matches a regular expression.

A format check cannot confirm that an email address exists or belongs to the user. Real applications may need email verification.

8. Password Validation

Password validation checks whether a password meets the required conditions.

Example

const password = "Learn123";

if(password.length < 8) {
  console.log("Password must have at least 8 characters.");
} else {
  console.log("Password length is acceptable.");
}

Checking More Conditions

const password = "Learn123";

const hasUppercase = /[A-Z]/.test(password);
const hasNumber = /[0-9]/.test(password);

if(password.length >= 8 && hasUppercase && hasNumber) {
  console.log("Password meets the example rules.");
} else {
  console.log("Password does not meet the rules.");
}
Never store plain-text passwords in a real application. Passwords must be handled securely on the server.

9. Minlength and Maxlength

These attributes control the minimum and maximum number of characters a user can enter in a text field.

Example

<input
  type="text"
  minlength="3"
  maxlength="20"
  required
>

JavaScript can also check string length:

const username = "Nainsi";

if(username.length < 3) {
  console.log("Username is too short.");
} else if(username.length > 20) {
  console.log("Username is too long.");
} else {
  console.log("Username length is valid.");
}

10. Checking Empty Fields

Before accepting a form, we should check whether important fields contain values.

Example

const name = document.getElementById("name").value.trim();
const email = document.getElementById("email").value.trim();
const password = document.getElementById("password").value;

if(name === "" || email === "" || password === "") {
  console.log("Please fill in all required fields.");
} else {
  console.log("All fields have values.");
}

The logical OR operator || checks whether at least one condition is true.

11. Displaying Error Messages

Instead of displaying errors only in the console, we can show them directly on the webpage.

HTML

<input id="username" type="text">
<p id="errorMessage"></p>

JavaScript

const username = document.getElementById("username");
const error = document.getElementById("errorMessage");

if(username.value.trim() === "") {
  error.textContent = "Username is required.";
  error.style.color = "red";
} else {
  error.textContent = "Username looks good!";
  error.style.color = "green";
}
Use textContent for displaying plain text messages. It avoids interpreting user input as HTML.

12. Real-Time Form Validation

Real-time validation checks user input while the user is typing or interacting with a field.

Example

const password = document.getElementById("password");
const message = document.getElementById("message");

password.addEventListener("input", function() {
  if(password.value.length < 8) {
    message.textContent = "Use at least 8 characters.";
  } else {
    message.textContent = "Password length is acceptable.";
  }
});

The input event runs whenever the value changes due to user interaction.

Real-time feedback helps users correct mistakes before submitting a form.

13. Practical Registration Form

Let's combine the concepts to build a simple registration form with JavaScript validation.

HTML

<form id="registrationForm">
  <input id="fullName" placeholder="Full Name">
  <input id="userEmail" type="email" placeholder="Email">
  <input id="userPassword" type="password" placeholder="Password">
  <button type="submit">Register</button>
  <p id="formMessage"></p>
</form>

JavaScript

const form = document.getElementById("registrationForm");

form.addEventListener("submit", function(event) {
  event.preventDefault();

  const name = document.getElementById("fullName").value.trim();
  const email = document.getElementById("userEmail").value.trim();
  const password = document.getElementById("userPassword").value;
  const message = document.getElementById("formMessage");

  if(name === "" || email === "" || password === "") {
    message.textContent = "Please fill in all fields.";
    return;
  }

  if(password.length < 8) {
    message.textContent = "Password must be at least 8 characters.";
    return;
  }

  message.textContent = "Registration form is valid!";
});
