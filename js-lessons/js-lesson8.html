Arrays and Array Methods

Learn how to store, access, update and manage multiple values using JavaScript arrays.

1. Introduction to Arrays

An array is a special variable that can store multiple values in a single place.

Instead of creating separate variables for every student, we can store all student names inside one array.

Without an array: 
let student1 = "Aman";
let student2 = "Riya";
let student3 = "Rahul";
Using an array: 
let students = ["Aman", "Riya", "Rahul"];

Arrays are useful when we need to work with lists of related data.

2. Creating Arrays

There are different ways to create an array in JavaScript.

Array Literal (Recommended)

let fruits = ["Apple", "Banana", "Mango"];

let numbers = [10, 20, 30, 40];

let mixed = ["Riya", 22, true];

Using the Array Constructor

let colors = new Array("Red", "Blue", "Green");

console.log(colors);
The array literal method [] is generally simpler and recommended for beginners.

3. Accessing Array Elements

Every array element has an index number. JavaScript array indexing starts from 0.

let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Banana
console.log(fruits[2]); // Mango

Accessing the Last Element

let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[fruits.length - 1]);

Here, length - 1 gives the index of the last element.

Remember: The first element is at index 0, not index 1.

4. Modifying Array Elements

We can change an existing array element by using its index.

let fruits = ["Apple", "Banana", "Mango"];

fruits[1] = "Orange";

console.log(fruits);

// ["Apple", "Orange", "Mango"]

The value at index 1 changes from Banana to Orange.

5. Array Length Property

The length property tells us how many elements are present in an array.

let students = ["Aman", "Riya", "Rahul", "Neha"];

console.log(students.length);

// Output: 4

Using length to access the last element

let numbers = [10, 20, 30, 40];

console.log(numbers[numbers.length - 1]);

// Output: 40

6. Adding Elements – push() and unshift()

push()

The push() method adds one or more elements at the end of an array.

let fruits = ["Apple", "Banana"];

fruits.push("Mango");

console.log(fruits);

// ["Apple", "Banana", "Mango"]

unshift()

The unshift() method adds one or more elements at the beginning of an array.

let fruits = ["Apple", "Banana"];

fruits.unshift("Mango");

console.log(fruits);

// ["Mango", "Apple", "Banana"]
Remember:
  • push() adds at the end.
  • unshift() adds at the beginning.

7. Removing Elements – pop() and shift()

pop()

The pop() method removes the last element from an array.

let fruits = ["Apple", "Banana", "Mango"];

fruits.pop();

console.log(fruits);

// ["Apple", "Banana"]

shift()

The shift() method removes the first element from an array.

let fruits = ["Apple", "Banana", "Mango"];

fruits.shift();

console.log(fruits);

// ["Banana", "Mango"]
Remember:
  • pop() removes from the end.
  • shift() removes from the beginning.

8. Finding Elements – indexOf() and includes()

indexOf()

It returns the index of an element. If the element is not found, it returns -1.

let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.indexOf("Banana"));
// Output: 1

console.log(fruits.indexOf("Orange"));
// Output: -1

includes()

It checks whether an array contains a particular value. It returns true or false.

let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.includes("Apple"));
// true

console.log(fruits.includes("Orange"));
// false

9. Other Array Methods – slice() and splice()

slice()

The slice() method returns a selected portion of an array without changing the original array.

let fruits = ["Apple", "Banana", "Mango", "Orange"];

let selected = fruits.slice(1, 3);

console.log(selected);
// ["Banana", "Mango"]

console.log(fruits);
// Original array remains unchanged

The ending index is not included.

splice()

The splice() method can remove, replace or add elements directly in the original array.

Removing elements: 
let fruits = ["Apple", "Banana", "Mango", "Orange"];

fruits.splice(1, 2);

console.log(fruits);

// ["Apple", "Orange"]

Here, 1 is the starting index and 2 is the number of elements to remove.

Adding elements: 
let fruits = ["Apple", "Mango"];

fruits.splice(1, 0, "Banana");

console.log(fruits);

// ["Apple", "Banana", "Mango"]
slice() does not modify the original array. splice() modifies the original array.

10. Looping Through Arrays – forEach()

The forEach() method runs a function once for each array element.

let fruits = ["Apple", "Banana", "Mango"];

fruits.forEach(function(fruit) {
  console.log(fruit);
});

Using Arrow Function

let numbers = [10, 20, 30];

numbers.forEach((number) => {
  console.log(number);
});

We can also access the index of each element.

let students = ["Aman", "Riya", "Rahul"];

students.forEach((student, index) => {
  console.log(index, student);
});

11. Practical Examples

Example 1: Student List

let students = ["Aman", "Riya", "Neha"];

students.push("Rahul");

console.log("Total students:", students.length);

students.forEach((student) => {
  console.log(student);
});

Example 2: Shopping Cart

let cart = ["Notebook", "Pen", "Pencil"];

cart.push("Eraser");

console.log("Cart:", cart);

cart.pop();

console.log("Updated Cart:", cart);

Example 3: Check Product Availability

let products = ["Laptop", "Mouse", "Keyboard"];

if (products.includes("Mouse")) {
  console.log("Product is available");
} else {
  console.log("Product is not available");
}
