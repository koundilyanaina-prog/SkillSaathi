Strings and String Methods

Learn how to create, access, search and manipulate text using JavaScript strings.

1. Introduction to Strings

A string is a sequence of characters used to represent text in JavaScript.

Names, messages, addresses and descriptions are common examples of strings.

let name = "Riya";
let city = 'Patna';
let message = `Welcome to SkillSaathi`;

console.log(name);
console.log(city);
console.log(message);

JavaScript supports three common ways to write strings:

  • Single quotes: 'Hello'
  • Double quotes: "Hello"
  • Backticks: `Hello`

2. Creating Strings

We can create strings using single quotes, double quotes or backticks.

Single and Double Quotes

let firstName = 'Aman';
let lastName = "Kumar";

console.log(firstName);
console.log(lastName);

Template Literals

Template literals use backticks. They allow us to insert variables directly into a string.

let name = "Riya";
let course = "JavaScript";

let message = `Hello ${name}, welcome to ${course}!`;

console.log(message);
Template literals are especially useful when creating dynamic messages with variables.

3. Accessing String Characters

Like arrays, strings use zero-based indexing. The first character has index 0.

let language = "JavaScript";

console.log(language[0]); // J
console.log(language[1]); // a
console.log(language[4]); // S

Using charAt()

The charAt() method returns the character at a specified index.

let word = "SkillSaathi";

console.log(word.charAt(0)); // S
console.log(word.charAt(5)); // S

4. String Length Property

The length property returns the total number of characters in a string, including spaces.

let message = "Hello World";

console.log(message.length);

// Output: 11

We can use length to access the last character.

let word = "JavaScript";

console.log(word[word.length - 1]);

// Output: t

5. Changing Letter Case – toUpperCase() and toLowerCase()

toUpperCase()

Converts all letters into uppercase.

let name = "nainsi";

console.log(name.toUpperCase());

// Output: NAINSI

toLowerCase()

Converts all letters into lowercase.

let city = "PATNA";

console.log(city.toLowerCase());

// Output: patna
Practical use: 
let enteredCity = "PATNA";

if (enteredCity.toLowerCase() === "patna") {
  console.log("City matched!");
}

6. Removing Extra Spaces – trim()

The trim() method removes spaces from the beginning and end of a string.

let username = "   Riya   ";

console.log(username.trim());

// Output: Riya

It does not remove spaces between words.

let message = "  Hello World  ";

console.log(message.trim());

// Output: Hello World

7. Extracting Parts of a String – slice()

The slice() method extracts a portion of a string and returns it as a new string.

let language = "JavaScript";

console.log(language.slice(0, 4));
// Java

console.log(language.slice(4));
// Script

The ending index is not included.

Using Negative Index

let word = "JavaScript";

console.log(word.slice(-6));

// Output: Script

8. Finding Text – indexOf() and includes()

indexOf()

Returns the position of the first occurrence of a specified text. If it is not found, it returns -1.

let message = "Welcome to JavaScript";

console.log(message.indexOf("JavaScript"));
// 11

console.log(message.indexOf("Python"));
// -1

includes()

Checks whether a string contains specified text. It returns true or false.

let message = "Learn JavaScript with SkillSaathi";

console.log(message.includes("JavaScript"));
// true

console.log(message.includes("Python"));
// false

9. Replacing Text – replace() and replaceAll()

replace()

Replaces the first matching occurrence of text.

let message = "I like Java. Java is easy.";

let updated = message.replace("Java", "JavaScript");

console.log(updated);

// I like JavaScript. Java is easy.

replaceAll()

Replaces all matching occurrences of the specified text.

let message = "Java is fun. Java is useful.";

let updated = message.replaceAll("Java", "JavaScript");

console.log(updated);

// JavaScript is fun. JavaScript is useful.
replace() replaces the first match, while replaceAll() replaces every match.

10. Combining Strings – concat()

The concat() method joins two or more strings.

let firstName = "Nainsi";
let lastName = "Kumari";

let fullName = firstName.concat(" ", lastName);

console.log(fullName);

// Nainsi Kumari

We can also combine strings using the + operator.

let first = "Hello";
let second = "World";

console.log(first + " " + second);

11. Splitting Strings – split()

The split() method divides a string into an array of smaller strings.

Split by Spaces

let sentence = "Learn JavaScript Every Day";

let words = sentence.split(" ");

console.log(words);

// ["Learn", "JavaScript", "Every", "Day"]

Split by Commas

let data = "Aman,Riya,Neha";

let names = data.split(",");

console.log(names);

// ["Aman", "Riya", "Neha"]
split() creates an array from a string. We will study arrays and their methods separately in other lessons.

12. Practical Examples

Example 1: Format a User Name

let username = "   riya kumari   ";

let formattedName = username.trim().toUpperCase();

console.log(formattedName);

// RIYA KUMARI

Example 2: Check a Message

let message = "Welcome to SkillSaathi";

if (message.includes("SkillSaathi")) {
  console.log("Welcome, learner!");
} else {
  console.log("Message not found");
}

Example 3: Extract a First Name

let fullName = "Aman Kumar";

let firstName = fullName.slice(0, 4);

console.log(firstName);

// Aman
