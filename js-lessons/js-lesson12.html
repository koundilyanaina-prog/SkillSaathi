Lesson 12: DOM Introduction and Selection

Learn how JavaScript connects with HTML documents and how to select elements using DOM methods.

Part 2 – Core JavaScript

1. What is DOM?

DOM stands for Document Object Model.

It is a programming interface that represents an HTML document as a tree of objects. JavaScript uses the DOM to access and work with HTML elements.

Example HTML

<!DOCTYPE html>
<html>
<body>
  <h1>Hello Learner</h1>
  <p>Welcome to SkillSaathi</p>
</body>
</html>

When a browser loads this HTML, it creates a DOM representation of the document.

Remember: HTML provides the structure, the DOM represents that structure as objects, and JavaScript can interact with those objects.

2. Why DOM is Important

The DOM allows JavaScript to access elements from an HTML page.

Using the DOM, JavaScript can:

  • Select HTML elements.
  • Read text and attributes.
  • Change content and styles.
  • Add or remove HTML elements.
  • Respond to user interactions.

Example

<h1 id="heading">Old Heading</h1>

<script>
  const title = document.getElementById("heading");
  console.log(title.textContent);
</script>

Output in Console:

Old Heading

Here JavaScript selects the heading using its ID and reads its text.

3. DOM Tree Structure

The DOM represents an HTML document in a tree-like structure. Each element becomes a node.

Example HTML

<html>
  <body>
    <h1>My Website</h1>
    <p>Welcome!</p>
  </body>
</html>

Simplified DOM Tree

Document
   |
  html
   |
  body
   |
   |------ h1
   |        |
   |      "My Website"
   |
   |------ p
            |
         "Welcome!"

In this tree:

  • Document: Represents the entire document.
  • Parent: An element that contains other nodes.
  • Child: A node inside another node.
  • Sibling: Nodes that share the same parent.
  • Text node: Contains text inside an element.

4. Understanding Document Object

The document object represents the currently loaded HTML document.

It provides methods and properties that JavaScript can use to access the page.

console.log(document.title);
console.log(document.URL);
console.log(document.body);

These statements display the page title, current document URL, and body element in the browser console.

Important Point

The document object is the main entry point for selecting elements from an HTML page.

5. Selecting Elements with getElementById()

getElementById() selects an element using its unique ID.

HTML

<h1 id="mainTitle">Welcome Learner</h1>

JavaScript

const heading = document.getElementById("mainTitle");

console.log(heading);

Result: JavaScript returns the matching HTML element.

An ID should be unique within an HTML document. If no matching ID exists, getElementById() returns null.

6. Selecting Elements with getElementsByClassName()

This method selects all elements that have a specified class name.

HTML

<p class="message">First Message</p>
<p class="message">Second Message</p>
<p class="message">Third Message</p>

JavaScript

const messages =
  document.getElementsByClassName("message");

console.log(messages);
console.log(messages[0]);

Important:

  • It returns an HTMLCollection.
  • It can contain multiple matching elements.
  • Elements can be accessed using indexes.
  • The collection is live and updates when matching elements change.

7. Selecting Elements with getElementsByTagName()

This method selects elements using their HTML tag name.

HTML

<h2>First Heading</h2>
<h2>Second Heading</h2>
<p>A paragraph</p>

JavaScript

const headings =
  document.getElementsByTagName("h2");

console.log(headings);
console.log(headings[0]);

This selects all matching h2 elements from the document.

Like getElementsByClassName(), this method returns a live HTMLCollection.

8. Selecting Elements with querySelector()

querySelector() selects the first element that matches a CSS selector.

Select by ID

const heading = document.querySelector("#mainTitle");

Select by Class

const message = document.querySelector(".message");

Select by Tag

const paragraph = document.querySelector("p");

It uses CSS selector syntax, so:

  • #name selects an ID.
  • .name selects a class.
  • p selects a paragraph element.
querySelector() returns only the first matching element. If no match is found, it returns null.

9. Selecting Elements with querySelectorAll()

querySelectorAll() selects all elements that match a CSS selector.

HTML

<p class="info">First Paragraph</p>
<p class="info">Second Paragraph</p>
<p class="info">Third Paragraph</p>

JavaScript

const paragraphs =
  document.querySelectorAll(".info");

console.log(paragraphs);
console.log(paragraphs[0]);

Important:

  • It returns a NodeList.
  • It can contain multiple matching elements.
  • Elements can be accessed using indexes.
  • The returned NodeList is static and does not automatically update when matching elements are added later.

10. Difference Between DOM Selectors

Let's compare the five important DOM selection methods.

getElementById("title")

getElementsByClassName("message")

getElementsByTagName("p")

querySelector(".message")

querySelectorAll(".message")
  • getElementById(): Selects one element by ID.
  • getElementsByClassName(): Selects matching elements by class and returns a live HTMLCollection.
  • getElementsByTagName(): Selects matching elements by tag and returns a live HTMLCollection.
  • querySelector(): Returns the first match for a CSS selector.
  • querySelectorAll(): Returns all matches in a static NodeList.
Tip: querySelector() and querySelectorAll() are flexible because they support CSS selector syntax.

11. Practical Examples

Example 1: Select an Element by ID

<h1 id="welcome">Hello Student</h1>

<script>
  const heading =
    document.getElementById("welcome");

  console.log(heading.textContent);
</script>

Output:

Hello Student

Example 2: Select Elements by Class

<p class="subject">HTML</p>
<p class="subject">CSS</p>
<p class="subject">JavaScript</p>

<script>
  const subjects =
    document.querySelectorAll(".subject");

  console.log(subjects.length);
</script>

Output:

3

Example 3: Select the First Paragraph

<p>First Paragraph</p>
<p>Second Paragraph</p>

<script>
  const first =
    document.querySelector("p");

  console.log(first.textContent);
</script>

Output:

First Paragraph
