1. Introduction to Array Methods

JavaScript provides several built-in methods to work with arrays. Three very useful methods are map(), filter() and reduce().

  • map(): Creates a new array by transforming every element.
  • filter(): Creates a new array containing only elements that pass a condition.
  • reduce(): Processes array elements and combines them into one final value.
All three methods are useful when working with lists of numbers, student records, products and other data.

2. Introduction to map()

The map() method runs a callback function for every element of an array and returns a new array containing the results.

const numbers = [1, 2, 3, 4];

const doubled = numbers.map(function(number){
  return number * 2;
});

console.log(doubled);

// [2, 4, 6, 8]

The original array remains unchanged.

const numbers = [2, 4, 6];

const result = numbers.map(num => num + 5);

console.log(result);  // [7, 9, 11]
console.log(numbers); // [2, 4, 6]

3. map() Syntax

The basic syntax is:

array.map(function(element, index, array){
  // return a new value
});

Parameters

  • element: Current element being processed.
  • index: Position of the current element.
  • array: The original array being processed.

Using an Arrow Function

const prices = [100, 200, 300];

const updatedPrices = prices.map(price => price + 50);

console.log(updatedPrices);
map() returns a new array. If you do not return a value from the callback, the resulting elements will be undefined.

4. Using map() with Numbers

We can use map() to perform calculations on every number in an array.

Square Every Number

const numbers = [2, 3, 4, 5];

const squares = numbers.map(num => num * num);

console.log(squares);

// [4, 9, 16, 25]

Add 10 to Every Number

const marks = [50, 60, 70, 80];

const updatedMarks = marks.map(mark => mark + 10);

console.log(updatedMarks);

// [60, 70, 80, 90]

Convert Values to Strings

const numbers = [10, 20, 30];

const labels = numbers.map(num => "Value: " + num);

console.log(labels);

5. Using map() with Objects

Arrays often contain objects. map() can extract or transform a particular property from every object.

const students = [
  {name: "Aman", marks: 80},
  {name: "Riya", marks: 90},
  {name: "Neha", marks: 85}
];

const names = students.map(student => student.name);

console.log(names);

// ["Aman", "Riya", "Neha"]

Update Object Data

const products = [
  {name: "Pen", price: 10},
  {name: "Book", price: 100}
];

const updatedProducts = products.map(product => {
  return {
    ...product,
    price: product.price + 5
  };
});

console.log(updatedProducts);

This creates a new array with updated objects while leaving the original objects unchanged.

6. Introduction to filter()

The filter() method creates a new array containing only the elements that satisfy a given condition.

const numbers = [10, 15, 20, 25, 30];

const result = numbers.filter(num => num > 20);

console.log(result);

// [25, 30]

Here, only numbers greater than 20 are included in the new array.

filter() does not modify the original array. It returns a new array with the matching elements.

7. filter() Syntax

array.filter(function(element, index, array){
  return condition;
});

How it works

  1. JavaScript checks each element.
  2. The callback function returns true or false.
  3. If true, the element is included.
  4. If false, the element is excluded.
const ages = [12, 18, 25, 15, 30];

const adults = ages.filter(age => age >= 18);

console.log(adults);

// [18, 25, 30]

8. Filtering Numbers

filter() is useful for selecting numbers based on conditions.

Even Numbers

const numbers = [1, 2, 3, 4, 5, 6];

const evenNumbers = numbers.filter(num => num % 2 === 0);

console.log(evenNumbers);

// [2, 4, 6]

Numbers Greater Than 50

const marks = [35, 60, 75, 40, 90];

const passedMarks = marks.filter(mark => mark >= 50);

console.log(passedMarks);

// [60, 75, 90]

Remove Negative Numbers

const values = [-5, 10, -2, 20, 0];

const positive = values.filter(num => num >= 0);

console.log(positive);

// [10, 20, 0]

9. Filtering Objects

We can filter arrays of objects using their properties.

Students Who Passed

const students = [
  {name: "Aman", marks: 35},
  {name: "Riya", marks: 85},
  {name: "Neha", marks: 72}
];

const passed = students.filter(student => student.marks >= 40);

console.log(passed);

Products Under a Budget

const products = [
  {name: "Pen", price: 10},
  {name: "Bag", price: 800},
  {name: "Book", price: 100}
];

const affordable = products.filter(product => product.price <= 100);

console.log(affordable);

10. Introduction to reduce()

The reduce() method processes every array element and combines the results into a single value.

It is commonly used for:

  • Calculating totals.
  • Adding numbers.
  • Calculating averages.
  • Counting items.
  • Building a single result from many values.
const numbers = [10, 20, 30];

const total = numbers.reduce((sum, num) => {
  return sum + num;
}, 0);

console.log(total);

// 60
reduce() returns one accumulated result. That result can be a number, string, array or object.

11. reduce() Syntax

array.reduce(function(accumulator, currentValue){
  return updatedAccumulator;
}, initialValue);

Important Parameters

  • Accumulator: Stores the result collected so far.
  • Current Value: The current array element.
  • Initial Value: The starting value of the accumulator.

Step-by-Step Example

const numbers = [5, 10, 15];

const total = numbers.reduce((sum, num) => {
  return sum + num;
}, 0);

// First: 0 + 5 = 5
// Second: 5 + 10 = 15
// Third: 15 + 15 = 30

console.log(total);
Providing an initial value is generally recommended because it makes the starting state clear and also handles empty arrays safely.

12. Calculating Sum with reduce()

Sum of Numbers

const numbers = [10, 20, 30, 40];

const sum = numbers.reduce((total, num) => total + num, 0);

console.log(sum);

// 100

Product of Numbers

const numbers = [2, 3, 4];

const product = numbers.reduce((result, num) => {
  return result * num;
}, 1);

console.log(product);

// 24

Count Array Elements

const fruits = ["Apple", "Mango", "Banana", "Apple"];

const count = fruits.reduce((total, fruit) => {
  return total + 1;
}, 0);

console.log(count);

// 4

13. Finding Total and Average

We can use reduce() to calculate the total marks and then divide by the number of students to find the average.

const marks = [80, 90, 70, 60];

const total = marks.reduce((sum, mark) => {
  return sum + mark;
}, 0);

const average = total / marks.length;

console.log("Total Marks:", total);
console.log("Average Marks:", average);

// Total Marks: 300
// Average Marks: 75

Calculate Total Shopping Bill

const prices = [100, 250, 50, 300];

const bill = prices.reduce((total, price) => {
  return total + price;
}, 0);

console.log("Total Bill:", bill);

14. map(), filter() and reduce() Comparison

Method Purpose Returns
map() Transforms every element New array
filter() Selects matching elements New array
reduce() Combines elements into a result Single accumulated value

Same Array, Different Results

const numbers = [1, 2, 3, 4];

const doubled = numbers.map(num => num * 2);

const even = numbers.filter(num => num % 2 === 0);

const total = numbers.reduce((sum, num) => sum + num, 0);

console.log(doubled); // [2, 4, 6, 8]
console.log(even);    // [2, 4]
console.log(total);   // 10

15. Chaining Array Methods

We can use multiple array methods one after another. This is called method chaining.

Example: Filter and Then Transform

const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers
  .filter(num => num % 2 === 0)
  .map(num => num * 10);

console.log(result);

// [20, 40, 60]

Example: Filter and Calculate Total

const prices = [100, 200, 50, 300, 80];

const total = prices
  .filter(price => price >= 100)
  .reduce((sum, price) => sum + price, 0);

console.log(total);

// 600
Chaining makes it possible to perform multiple operations in a readable sequence without creating many temporary arrays.

16. Practical Examples

Example 1: Student Marks

const students = [
  {name: "Aman", marks: 85},
  {name: "Riya", marks: 35},
  {name: "Neha", marks: 90},
  {name: "Rahul", marks: 40}
];

const passedStudents = students.filter(student => student.marks >= 40);

const studentNames = passedStudents.map(student => student.name);

console.log("Passed Students:", studentNames);

Example 2: Shopping Cart Total

const cart = [
  {name: "Book", price: 200},
  {name: "Pen", price: 20},
  {name: "Bag", price: 800}
];

const total = cart.reduce((sum, item) => {
  return sum + item.price;
}, 0);

console.log("Shopping Total:", total);

Example 3: Employee Salary Update

const employees = [
  {name: "Aman", salary: 20000},
  {name: "Riya", salary: 25000},
  {name: "Neha", salary: 30000}
];

const updatedEmployees = employees.map(employee => ({
  ...employee,
  salary: employee.salary + 2000
}));

console.log(updatedEmployees);
