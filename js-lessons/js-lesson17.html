1. Introduction to Destructuring

Destructuring is an ES6 feature that allows us to extract values from arrays or properties from objects and store them in separate variables.

Without destructuring:

const student = ["Aman", 21, "BCA"];

const name = student[0];
const age = student[1];
const course = student[2];

console.log(name, age, course);

Using destructuring:

const student = ["Aman", 21, "BCA"];

const [name, age, course] = student;

console.log(name);
console.log(age);
console.log(course);
Destructuring makes code shorter, cleaner and easier to read.

2. Array Destructuring

Array destructuring extracts array elements into variables according to their positions.

const colors = ["Red", "Green", "Blue"];

const [first, second, third] = colors;

console.log(first);  // Red
console.log(second); // Green
console.log(third);  // Blue

Important Point

The order of variables matters. The first variable receives the first array element, the second receives the second element, and so on.

const numbers = [10, 20, 30];

const [a, b, c] = numbers;

console.log(a); // 10
console.log(b); // 20
console.log(c); // 30

3. Skipping Array Elements

You can skip unwanted array elements by leaving an empty space between commas.

const fruits = ["Apple", "Mango", "Banana"];

const [first, , third] = fruits;

console.log(first); // Apple
console.log(third); // Banana

Here, the second element, Mango, is skipped.

An empty position in destructuring tells JavaScript to ignore that array element.

4. Default Values in Destructuring

If an array does not contain enough elements, you can provide default values.

const student = ["Riya"];

const [name, age = 20] = student;

console.log(name); // Riya
console.log(age);  // 20

The default value is used when the extracted value is undefined.

const colors = ["Red"];

const [first, second = "Blue"] = colors;

console.log(first);
console.log(second);

5. Swapping Variables

Destructuring makes it easy to exchange the values of two variables without using a temporary variable.

let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a); // 20
console.log(b); // 10

How does it work?

  • The right side creates an array containing the values.
  • The left side assigns those values in a different order.
  • The two variables exchange their values.

6. Nested Array Destructuring

An array can contain another array. We can extract values from nested arrays using nested destructuring.

const numbers = [10, [20, 30]];

const [first, [second, third]] = numbers;

console.log(first);  // 10
console.log(second); // 20
console.log(third);  // 30

Another example:

const data = ["Aman", [85, 90]];

const [name, [maths, science]] = data;

console.log(name);
console.log(maths);
console.log(science);

7. Object Destructuring

Object destructuring extracts property values from an object and stores them in variables.

const student = {
  name: "Neha",
  age: 22,
  course: "MCA"
};

const { name, age, course } = student;

console.log(name);
console.log(age);
console.log(course);
Unlike array destructuring, object destructuring uses property names instead of positions.

Property names must match

const product = {
  title: "Laptop",
  price: 45000
};

const { title, price } = product;

console.log(title);
console.log(price);

8. Renaming Variables

You can give a different variable name to an object property while destructuring.

const student = {
  name: "Aman",
  age: 21
};

const { name: studentName, age: studentAge } = student;

console.log(studentName);
console.log(studentAge);

Here, name is assigned to studentName and age is assigned to studentAge.

Syntax: { propertyName: newVariableName }

9. Default Values in Objects

You can assign default values when an object property may be missing.

const student = {
  name: "Priya"
};

const { name, age = 18 } = student;

console.log(name); // Priya
console.log(age);  // 18

If the property already has a value, the actual value is used.

const product = {
  name: "Phone",
  price: 15000
};

const { name, price = 10000 } = product;

console.log(price); // 15000

10. Nested Object Destructuring

Objects can contain other objects. Nested destructuring helps extract deeply nested properties.

const student = {
  name: "Rohan",
  address: {
    city: "Ranchi",
    state: "Jharkhand"
  }
};

const {
  name,
  address: { city, state }
} = student;

console.log(name);
console.log(city);
console.log(state);
In this example, city and state are extracted from the nested address object.

11. Introduction to Spread Operator

The spread operator (...) expands elements of an array or properties of an object.

Example:

const numbers = [10, 20, 30];

console.log(...numbers);

// Output:
// 10 20 30

Without spread, the array is treated as one value. With spread, its individual elements are expanded.

The three dots (...) are called the spread syntax when used to expand elements or properties.

12. Spread with Arrays

You can use spread to insert all elements of an existing array into another array.

const first = [1, 2, 3];

const second = [...first, 4, 5];

console.log(second);

// [1, 2, 3, 4, 5]

Combining values

const numbers = [10, 20];

const updated = [5, ...numbers, 30];

console.log(updated);

// [5, 10, 20, 30]

13. Copying and Combining Arrays

Spread syntax can create a shallow copy of an array.

const original = ["HTML", "CSS", "JavaScript"];

const copy = [...original];

console.log(copy);

Now you can modify the copied array without changing the original array's top-level elements.

const original = [10, 20, 30];

const copy = [...original];

copy.push(40);

console.log(original); // [10, 20, 30]
console.log(copy);     // [10, 20, 30, 40]

Combining two arrays

const frontend = ["HTML", "CSS"];
const backend = ["Node.js", "PHP"];

const skills = [...frontend, ...backend];

console.log(skills);
Spread creates a shallow copy, not a deep copy. Nested objects inside an array may still share references.

14. Spread with Objects

Spread syntax can copy and combine object properties.

const student = {
  name: "Aman",
  age: 21
};

const updatedStudent = {
  ...student,
  course: "MCA"
};

console.log(updatedStudent);

Combining Objects

const personal = {
  name: "Riya",
  age: 22
};

const education = {
  course: "MCA",
  college: "Ranchi University"
};

const profile = {
  ...personal,
  ...education
};

console.log(profile);

Overwriting Properties

const user = {
  name: "Aman",
  city: "Delhi"
};

const updatedUser = {
  ...user,
  city: "Ranchi"
};

console.log(updatedUser);

// city will be Ranchi
If the same property appears more than once, the value from the last occurrence is used.

15. Rest Operator Introduction

Rest syntax also uses three dots (...), but it collects remaining values into a single array or object.

Example with arrays:

const numbers = [10, 20, 30, 40, 50];

const [first, second, ...remaining] = numbers;

console.log(first);     // 10
console.log(second);    // 20
console.log(remaining); // [30, 40, 50]

Example with objects:

const student = {
  name: "Neha",
  age: 22,
  course: "MCA",
  city: "Ranchi"
};

const { name, ...details } = student;

console.log(name);
console.log(details);
Remember: Spread expands values, while rest collects remaining values. Their meaning depends on where the ... syntax is used.

16. Practical Examples

Example 1: Student Profile

const student = {
  name: "Anjali",
  marks: [85, 90, 88]
};

const { name, marks } = student;
const [maths, science, computer] = marks;

console.log("Student:", name);
console.log("Maths:", maths);
console.log("Science:", science);
console.log("Computer:", computer);

Example 2: Shopping Cart

const cart1 = ["Book", "Pen"];
const cart2 = ["Notebook", "Pencil"];

const finalCart = [...cart1, ...cart2];

console.log("Cart Items:", finalCart);

Example 3: Updating User Details

const user = {
  name: "Rahul",
  city: "Patna",
  role: "Student"
};

const updatedUser = {
  ...user,
  city: "Ranchi",
  role: "Developer"
};

console.log(updatedUser);
