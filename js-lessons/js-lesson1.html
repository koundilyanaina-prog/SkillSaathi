Lesson 1: Introduction to JavaScript

Learn what JavaScript is, why it is used, and how it makes websites interactive.

1. What is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic.

HTML creates the structure, CSS designs the appearance, and JavaScript adds behaviour.

  • HTML: Structure of a webpage.
  • CSS: Styling and layout.
  • JavaScript: Interaction and functionality.

2. What can JavaScript do?

  • Respond to button clicks.
  • Validate forms.
  • Display messages and alerts.
  • Update webpage content.
  • Create games, calculators and interactive applications.

3. Your First JavaScript Program

The console.log() method displays information in the browser console.

console.log("Hello, SkillSaathi!");

The alert() method displays a popup message.
