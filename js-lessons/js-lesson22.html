Promises and Async/Await

Learn how JavaScript handles asynchronous operations using Promises and async/await.

1. Introduction to Promises

A Promise is a JavaScript object that represents the eventual completion or failure of an asynchronous operation.

It helps us handle operations that may finish in the future.

Why do we need Promises?

  • To handle asynchronous operations.
  • To manage successful and failed results.
  • To organize code that depends on future results.
  • To avoid deeply nested callback structures.
let myPromise = new Promise(function(resolve, reject){
    resolve("Task completed!");
});

console.log(myPromise);
Remember: A Promise does not automatically make an operation asynchronous. It provides a structured way to represent and handle its eventual result.

2. Promise States

Every Promise has one of three states.

StateMeaning
PendingThe operation is still in progress.
FulfilledThe operation completed successfully.
RejectedThe operation failed.

Promise state flow

          PENDING
          /     \
         /       \
   FULFILLED   REJECTED
    Success      Failure

A Promise starts as pending. Later, it may become fulfilled or rejected. Once settled, its state cannot change again.

3. Creating a Promise

We create a Promise using the new Promise() constructor.

const promise = new Promise(function(resolve, reject){

    let taskCompleted = true;

    if(taskCompleted){
        resolve("Task successful!");
    }else{
        reject("Task failed!");
    }

});

The Promise constructor receives an executor function with two parameters:

  • resolve: Used when the operation succeeds.
  • reject: Used when the operation fails.
The executor function runs immediately when the Promise is created.

4. resolve() and reject()

resolve()

It fulfills a Promise with a successful result.

const promise = new Promise(function(resolve, reject){
    resolve("Welcome to SkillSaathi!");
});

reject()

It rejects a Promise with a reason for failure.

const promise = new Promise(function(resolve, reject){
    reject("Something went wrong!");
});

5. then() Method

The then() method handles the successful result of a Promise.

Syntax

promise.then(function(result){
    // Handle successful result
});

Example

const promise = new Promise(function(resolve){
    resolve("Payment successful!");
});

promise.then(function(result){
    console.log(result);
});

Output:

Payment successful!

The value passed to resolve() becomes available inside the then() callback.

6. catch() Method

The catch() method handles a rejected Promise.

const promise = new Promise(function(resolve, reject){
    reject("Unable to complete the task.");
});

promise.catch(function(error){
    console.log(error);
});

Output:

Unable to complete the task.
Use catch() to handle errors instead of allowing rejected Promises to go unhandled.

7. finally() Method

The finally() method runs after a Promise settles, whether it is fulfilled or rejected.

const promise = new Promise(function(resolve){
    resolve("Data loaded!");
});

promise
    .then(function(result){
        console.log(result);
    })
    .catch(function(error){
        console.log(error);
    })
    .finally(function(){
        console.log("Operation finished.");
    });

Output:

Data loaded!
Operation finished.

It is useful for cleanup tasks, such as hiding a loading indicator.

8. Promise Chaining

Promise chaining means connecting multiple then() methods to perform operations in sequence.

Promise.resolve(5)
    .then(function(number){
        console.log(number);
        return number * 2;
    })
    .then(function(result){
        console.log(result);
        return result + 10;
    })
    .then(function(finalResult){
        console.log(finalResult);
    });

Output:

5
10
20

Each then() can return a value that becomes the input of the next then().

Returning a value from a then() callback is important when the next step depends on its result.

9. Handling Multiple Promises

JavaScript provides methods to work with multiple Promises together.

These methods are commonly called Promise combinators.

Promise.all()

Promise.all() fulfills when all input Promises fulfill. It rejects if any input Promise rejects.

const promise1 = Promise.resolve("HTML");
const promise2 = Promise.resolve("CSS");
const promise3 = Promise.resolve("JavaScript");

Promise.all([promise1, promise2, promise3])
    .then(function(results){
        console.log(results);
    })
    .catch(function(error){
        console.log(error);
    });

Output:

["HTML", "CSS", "JavaScript"]

Promise.allSettled()

Promise.allSettled() waits until every input Promise has settled, whether fulfilled or rejected.

const p1 = Promise.resolve("Success");
const p2 = Promise.reject("Failed");

Promise.allSettled([p1, p2])
    .then(function(results){
        console.log(results);
    });

It returns an array containing the status and result or rejection reason of each Promise.

Promise.race()

Promise.race() settles with the result of the first input Promise that settles.

const p1 = new Promise(function(resolve){
    setTimeout(function(){
        resolve("First task");
    }, 1000);
});

const p2 = new Promise(function(resolve){
    setTimeout(function(){
        resolve("Second task");
    }, 2000);
});

Promise.race([p1, p2])
    .then(function(result){
        console.log(result);
    });

Output:

First task

10. Introduction to async and await

async and await provide a cleaner way to work with Promises.

async keyword

Adding async before a function makes it return a Promise.

async function greet(){
    return "Hello Student!";
}

greet().then(function(message){
    console.log(message);
});

Output:

Hello Student!

await keyword

await pauses the execution of the surrounding async function until the Promise settles. It does not block the entire JavaScript program.

function getMessage(){
    return new Promise(function(resolve){
        setTimeout(function(){
            resolve("Welcome to SkillSaathi!");
        }, 2000);
    });
}

async function showMessage(){
    console.log("Please wait...");

    const result = await getMessage();

    console.log(result);
}

showMessage();

The function waits for the Promise result before continuing to the next statement inside that async function.

11. async Functions in Detail

An async function always returns a Promise.

Example 1: Returning a value

async function getNumber(){
    return 100;
}

getNumber().then(function(number){
    console.log(number);
});

Example 2: Returning a Promise

async function getResult(){
    return Promise.resolve("Success!");
}

getResult().then(function(result){
    console.log(result);
});

Example 3: Using await

function task(){
    return new Promise(function(resolve){
        setTimeout(function(){
            resolve("Task completed!");
        }, 1000);
    });
}

async function runTask(){
    const result = await task();
    console.log(result);
}

runTask();

12. Error Handling with try...catch

When using await, we can handle rejected Promises using try...catch.

function checkResult(){
    return new Promise(function(resolve, reject){
        reject("Something went wrong!");
    });
}

async function showResult(){
    try{
        const result = await checkResult();
        console.log(result);
    }
    catch(error){
        console.log("Error:", error);
    }
}

showResult();

Output:

Error: Something went wrong!

Using finally with async/await

async function loadData(){
    try{
        console.log("Loading...");
        const result = await Promise.resolve("Data ready!");
        console.log(result);
    }
    catch(error){
        console.log(error);
    }
    finally{
        console.log("Loading process finished.");
    }
}

loadData();

13. Sequential and Parallel Execution

Sequential execution

When one task depends on the result of another, we may need to await them one after another.

async function runSequentially(){
    const first = await Promise.resolve("First");
    console.log(first);

    const second = await Promise.resolve("Second");
    console.log(second);
}

runSequentially();

Parallel execution

When tasks are independent, we can start them together and wait for all results using Promise.all().

async function runTogether(){
    const results = await Promise.all([
        Promise.resolve("HTML"),
        Promise.resolve("CSS"),
        Promise.resolve("JavaScript")
    ]);

    console.log(results);
}

runTogether();
Use sequential execution when tasks depend on each other. Use Promise.all() when independent tasks can run together.

function loginUser(username){

        if(username === "student"){

        console.log(error);

login();

    });

async function displayData(){

    const result = await processData();

    console.log(result);

displayData();

getCourses();
