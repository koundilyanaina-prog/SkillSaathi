Objects and Object Properties

Learn how to organize related information using JavaScript objects and work with their properties and methods.

1. Introduction to Objects

An object is a collection of related data and functionality stored as key-value pairs.

For example, a student can have a name, age, course and city. Instead of storing these details in separate variables, we can group them inside one object.

let student = {
  name: "Riya",
  age: 22,
  course: "JavaScript",
  city: "Patna"
};

console.log(student);

Here, name, age, course and city are properties of the object.

2. Creating Objects

The most common way to create an object is by using curly braces {}.

let car = {
  brand: "Tata",
  model: "Nexon",
  year: 2025
};

console.log(car);

Creating an Empty Object

let user = {};

user.name = "Aman";
user.age = 24;

console.log(user);
An object stores information using property names and their corresponding values.

3. Object Properties and Values

Each property has a name (key) and a value.

let employee = {
  name: "Neha",
  department: "HR",
  salary: 25000,
  isActive: true
};
  • name is a property and "Neha" is its value.
  • department is a property and "HR" is its value.
  • Values can be strings, numbers, booleans, arrays or even other objects.

4. Accessing Object Properties

There are two common ways to access object properties.

Dot Notation

let student = {
  name: "Riya",
  age: 22
};

console.log(student.name);
console.log(student.age);

Bracket Notation

let student = {
  name: "Riya",
  age: 22
};

console.log(student["name"]);
console.log(student["age"]);
When to use bracket notation? 
let propertyName = "name";

console.log(student[propertyName]);

Bracket notation is useful when the property name is stored inside a variable.

5. Adding New Properties

We can add new properties to an existing object using dot notation or bracket notation.

let student = {
  name: "Aman",
  age: 21
};

student.course = "JavaScript";
student["city"] = "Patna";

console.log(student);

The object now contains four properties.

6. Updating Object Properties

We can update an existing property by assigning it a new value.

let student = {
  name: "Riya",
  age: 20,
  course: "HTML"
};

student.age = 22;
student.course = "JavaScript";

console.log(student);

Updating a property does not create a duplicate property. It changes the existing value.

7. Deleting Object Properties

The delete operator removes a property from an object.

let student = {
  name: "Aman",
  age: 22,
  city: "Patna"
};

delete student.city;

console.log(student);

The city property is removed from the object.

Use delete carefully because it permanently removes that property from the current object.

8. Nested Objects

An object can contain another object as one of its properties. This is called a nested object.

let student = {
  name: "Riya",
  age: 22,
  address: {
    city: "Patna",
    state: "Bihar",
    country: "India"
  }
};

console.log(student.name);
console.log(student.address.city);
console.log(student.address.state);

To access nested properties, use dot notation repeatedly or bracket notation.

9. Object Methods

A function stored as a property of an object is called a method.

let student = {
  name: "Neha",
  course: "JavaScript",

  introduce: function() {
    console.log("Hello, my name is " + this.name);
  }
};

student.introduce();

The this keyword refers to the current object in this method call.

Short Method Syntax

let user = {
  name: "Aman",

  greet() {
    console.log("Hello " + this.name);
  }
};

user.greet();

10. Useful Object Operations

Object.keys()

Returns an array containing an object's property names.

let student = {
  name: "Riya",
  age: 22,
  city: "Patna"
};

console.log(Object.keys(student));

// ["name", "age", "city"]

Object.values()

Returns an array containing an object's property values.

console.log(Object.values(student));

// ["Riya", 22, "Patna"]

Object.entries()

Returns an array of key-value pairs.

console.log(Object.entries(student));

// [["name","Riya"],["age",22],["city","Patna"]]

11. Practical Examples

Example 1: Student Profile

let student = {
  name: "Aman",
  rollNumber: 101,
  course: "MCA",
  city: "Patna"
};

console.log("Student:", student.name);
console.log("Course:", student.course);

Example 2: Product Details

let product = {
  name: "Laptop",
  price: 45000,
  inStock: true
};

product.price = 42000;

console.log("Product:", product.name);
console.log("Updated Price:", product.price);

Example 3: Employee Introduction

let employee = {
  name: "Neha",
  role: "Developer",

  introduce() {
    console.log(
      "I am " + this.name + " and I work as a " + this.role
    );
  }
};

employee.introduce();
