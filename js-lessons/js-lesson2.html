Variables: var, let and const

Learn how to declare, store, update and use variables in JavaScript.

1. What are Variables?

A variable is a named container used to store information. We can give a variable a name and use that name whenever we need its stored value.

Example:

let studentName = "Aarav";

console.log(studentName);

Here, studentName is the variable name and "Aarav" is the value stored in it.

2. Declaring Variables

JavaScript provides three keywords to declare variables: var, let and const.

Using var

var is the older way to declare variables. A variable declared with var can be reassigned and redeclared within the same scope. 

var city = "Patna";

city = "Ranchi";

var city = "Delhi";

console.log(city);

Using let

let is used when a variable's value may change. It can be reassigned, but it cannot be redeclared in the same scope. 

let score = 50;

score = 80;

console.log(score);

Using const

const is used when a variable should not be reassigned. A const variable must be initialized when it is declared. 

const country = "India";

console.log(country);

// country = "Japan";
// This reassignment causes an error.

3. Difference Between var, let and const

var age = 20;
age = 21;       // Allowed
var age = 22;   // Redeclaration allowed

let marks = 75;
marks = 85;     // Allowed
// let marks = 90;  // Error in same scope

const pi = 3.14;
// pi = 3.15;    // Error
Important: In modern JavaScript, prefer const by default. Use let when reassignment is needed. Avoid using var in most modern code.

4. Variable Scope

Scope determines where a variable can be accessed in a JavaScript program.

Global Scope

A variable declared outside a function or block can generally be accessed throughout its scope. 

let message = "Hello Students";

function showMessage(){
  console.log(message);
}

showMessage();

Block Scope

Variables declared with let and const inside a block are accessible only within that block. 

{
  let course = "JavaScript";
  const level = "Beginner";

  console.log(course);
  console.log(level);
}

// Variables above cannot be accessed here.

Function Scope

A variable declared with var inside a function is available within that function. 

function studentDetails(){
  var name = "Meera";
  console.log(name);
}

studentDetails();

// name cannot be accessed outside the function.

5. Rules for Naming Variables

  • Variable names can contain letters, numbers, underscores and dollar signs.
  • A variable name cannot begin with a number.
  • Spaces are not allowed in variable names.
  • JavaScript variable names are case-sensitive.
  • Reserved keywords cannot be used as variable names.
  • Use meaningful names that describe the stored information.

Valid Names

let studentName = "Aarav";
let total_marks = 450;
let userAge = 20;
let $price = 100;

Invalid Names

// let 2name = "Aarav";
// let student name = "Aarav";
// let let = 10;
Best Practice: Use camelCase for variable names, such as studentName, totalMarks and userAge.

6. Practical Example

Let's create a simple student profile using variables. 

let studentName = "Meera";
let courseName = "JavaScript";
let studyHours = 3;

console.log("Student:", studentName);
console.log("Course:", courseName);
console.log("Daily Study Hours:", studyHours);
