Operators and Expressions

Learn how JavaScript performs calculations, compares values and combines logical conditions using operators.

1. What are Operators?

Operators are special symbols or keywords that perform operations on values and variables.

For example:

let a = 10;
let b = 5;
let result = a + b;

console.log(result); // 15

Here, + is an operator that adds two values.

What is an Expression?

An expression is a combination of values, variables and operators that produces a result.

10 + 5
price * quantity
age >= 18

2. Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

OperatorMeaningExampleResult
+Addition10 + 515
-Subtraction10 - 55
*Multiplication10 * 550
/Division10 / 52
%Remainder10 % 31
**Exponentiation2 ** 38
++Increment by 1x++Increases x

Practical Example

let a = 20;
let b = 6;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** 2);

3. Assignment Operators

Assignment operators assign values to variables or update their existing values.

OperatorExampleSame As
=x = 10x = 10
+=x += 5x = x + 5
-=x -= 5x = x - 5
*=x *= 2x = x * 2
/=x /= 2x = x / 2
%=x %= 3x = x % 3
let score = 50;

score += 10;
console.log(score); // 60

score -= 5;
console.log(score); // 55

score *= 2;
console.log(score); // 110

4. Comparison Operators

Comparison operators compare two values and return a Boolean result: true or false.

OperatorMeaningExample
==Equal value (allows type conversion)5 == "5" → true
===Equal value and type5 === "5" → false
!=Not equal value5 != 3 → true
!==Not equal value or type5 !== "5" → true
>Greater than10 > 5 → true
<Less than10 < 5 → false
>=Greater than or equal10 >= 10 → true
<=Less than or equal5 <= 10 → true

Important: == vs ===

console.log(10 == "10");  // true
console.log(10 === "10"); // false

=== checks both value and data type. It is generally recommended for predictable comparisons.

5. Logical Operators

Logical operators combine or reverse Boolean values.

OperatorNameMeaning
&&ANDTrue when both conditions are true
||ORTrue when at least one condition is true
!NOTReverses a Boolean value

Examples

let hasID = true;
let hasTicket = true;

console.log(hasID && hasTicket); // true
console.log(hasID || false);     // true
console.log(!hasID);             // false

AND (&&): Both values must be true.

OR (||): At least one value must be true.

NOT (!): Changes true to false and false to true.

6. String Concatenation

The + operator can also join strings. This is called concatenation.

let firstName = "Aarav";
let lastName = "Kumar";

let fullName = firstName + " " + lastName;

console.log(fullName);
// Aarav Kumar

When a string and number are added, JavaScript may convert the number into a string.

let result = "Total: " + 100;
console.log(result); // Total: 100

7. Operator Precedence

Operator precedence decides which operation is performed first in an expression.

let result = 10 + 5 * 2;
console.log(result); // 20

Multiplication is performed before addition.

Parentheses can change the order of calculation:

let result = (10 + 5) * 2;
console.log(result); // 30

Basic Order to Remember

  1. Parentheses ()
  2. Exponentiation **
  3. Multiplication, Division and Remainder
  4. Addition and Subtraction
  5. Comparison operators
  6. Logical operators
  7. Assignment operators

This is a simplified learning order; operators at the same precedence level may follow associativity rules.

8. Practical Example

Let's calculate the total price of products and check a few comparisons.

let notebookPrice = 50;
let penPrice = 10;
let quantity = 3;

let total = (notebookPrice + penPrice) * quantity;

console.log("Total Amount: " + total);
console.log(total > 100);
console.log(total === 180);

Output:

Total Amount: 180
true
true
