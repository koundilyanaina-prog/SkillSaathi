Loops: for, while and do-while

Learn how to repeat a block of code efficiently using JavaScript loops.

1. Introduction to Loops

A loop is a programming structure that executes a block of code repeatedly while a condition is satisfied.

For example, if you want to display numbers from 1 to 100, writing 100 separate console.log statements would be inefficient. A loop can do this with just a few lines of code.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5

2. Why Do We Use Loops?

Loops make programs shorter, faster to write and easier to maintain.

  • Repeat tasks without writing the same code again.
  • Process multiple items in arrays or collections.
  • Perform repeated calculations.
  • Generate tables, lists and patterns.
  • Reduce unnecessary code duplication.

Without a Loop

console.log("Hello");
console.log("Hello");
console.log("Hello");

With a Loop

for (let i = 1; i <= 3; i++) {
    console.log("Hello");
}

Both examples display Hello three times, but the loop is easier to extend.

3. The for Loop

A for loop is commonly used when you know how many times you want to repeat a task.

Syntax

for (initialization; condition; update) {
    // Code to repeat
}

A for loop has three main parts:

PartPurpose
InitializationCreates or initializes the counter variable.
ConditionChecks whether the loop should continue.
UpdateChanges the counter after each iteration.

Example

for (let i = 1; i <= 5; i++) {
    console.log("Number:", i);
}

Here, the loop starts at 1, continues while i is less than or equal to 5, and increases i by 1 each time.

Counting Backwards

for (let i = 5; i >= 1; i--) {
    console.log(i);
}

Output: 5, 4, 3, 2, 1

4. The while Loop

A while loop repeats code as long as its condition remains true. It is useful when the number of repetitions is not known in advance.

Syntax

while (condition) {
    // Code to repeat
}

Example

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output: 1, 2, 3, 4, 5

Important: Update the loop variable when needed. If the condition never becomes false, the loop may run forever. This is called an infinite loop.

5. The do...while Loop

A do...while loop executes its code block at least once before checking the condition.

Syntax

do {
    // Code to execute
} while (condition);

Example

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Output: 1, 2, 3, 4, 5

Important Difference

let number = 10;

while (number < 5) {
    console.log("While loop");
}

do {
    console.log("Do while loop");
} while (number < 5);

The while loop executes zero times because its condition is false from the beginning. The do...while loop executes once before checking the condition.

6. The break Statement

The break statement immediately stops the loop, even if the loop condition is still true.

Example

for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break;
    }

    console.log(i);
}

Output: 1, 2, 3, 4

When i becomes 5, the loop stops completely.

7. The continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

Example

for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue;
    }

    console.log(i);
}

Output: 1, 2, 4, 5

When i is 3, that iteration is skipped. The remaining iterations continue normally.

8. Nested Loops

A nested loop is a loop placed inside another loop. The inner loop completes its iterations for each iteration of the outer loop.

Example: Number Pattern

for (let i = 1; i <= 3; i++) {
    let row = "";

    for (let j = 1; j <= 3; j++) {
        row += j + " ";
    }

    console.log(row);
}

Output:

1 2 3
1 2 3
1 2 3

Nested loops are useful for working with tables, grids and patterns.

9. Practical Examples

Example 1: Multiplication Table

let number = 5;

for (let i = 1; i <= 10; i++) {
    console.log(number + " x " + i + " = " + (number * i));
}

Example 2: Sum of Numbers from 1 to 10

let sum = 0;

for (let i = 1; i <= 10; i++) {
    sum += i;
}

console.log("Total:", sum);

Output: Total: 55

Example 3: Even Numbers

for (let i = 2; i <= 20; i += 2) {
    console.log(i);
}

Example 4: Countdown Using while

let count = 5;

while (count >= 1) {
    console.log(count);
    count--;
}

console.log("Finished!");
