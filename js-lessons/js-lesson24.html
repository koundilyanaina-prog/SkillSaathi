Modules and Code Organization

Learn how to divide JavaScript code into separate files using modules, imports and exports.

Level: Advanced Beginner

1. Introduction to JavaScript Modules

A JavaScript module is a separate file that contains code such as variables, functions, classes or objects.

Modules allow us to divide a large program into smaller, manageable files.

// math.js export function add(a, b) { return a + b; }

Here, math.js is a module that exports an add function so another file can use it.

2. Why Use Modules?

Modules help us organize code and make projects easier to maintain.

  • Keep code organized in separate files.
  • Reuse functions in multiple files.
  • Make large projects easier to understand.
  • Reduce unnecessary global variables.
  • Make teamwork easier.
Think of modules like different departments in an organization. Each department handles a specific task, but they work together.

3. Module Scope

In JavaScript modules, variables and functions are private to that module by default.

They cannot be accessed from another file unless we export them.

// user.js const username = "Nainsi"; function welcome() { console.log("Welcome " + username); }

Here, username and welcome() are not automatically available in other JavaScript files.

We need to export them if another module needs to use them.

4. Export and Import

Export makes a variable, function or class available to other modules.

Import allows another module to use an exported value.

// math.js export const pi = 3.14; export function multiply(a, b) { return a * b; } // app.js import { pi, multiply } from "./math.js"; console.log(pi); console.log(multiply(4, 5));
The file path in an import statement identifies the module we want to use. Keep the file extension .js in browser module imports.

5. Named Exports

Named exports allow us to export multiple values from a single file.

// tools.js export const course = "JavaScript"; export const duration = "25 Lessons"; export function showCourse() { return "Welcome to SkillSaathi"; }

Each exported value has its own name.

6. Named Imports

To import named exports, we use curly braces and write the exact exported names.

// app.js import { course, duration, showCourse } from "./tools.js"; console.log(course); console.log(duration); console.log(showCourse());

Remember: named imports must match the exported names unless we rename them.

7. Default Export

A module can also have one default export. It is useful when a file mainly provides one important value.

// message.js export default function greet() { return "Hello, welcome to SkillSaathi!"; }
A module can have only one default export, but it can also have multiple named exports.

8. Default Import

We can import a default export without using curly braces.

// app.js import greet from "./message.js"; console.log(greet());

The name used for a default import can be chosen by the importing file.

9. Importing Multiple Values

We can import multiple named values from one module in a single statement.

// student.js export const name = "Aarav"; export const age = 20; export function getDetails() { return name + " is " + age + " years old."; } // app.js import { name, age, getDetails } from "./student.js"; console.log(name); console.log(age); console.log(getDetails());

10. Renaming Imports and Exports

We can use the as keyword to give an exported or imported value another name.

Renaming during export

const firstName = "Nainsi"; export { firstName as studentName };

Renaming during import

import { studentName as name } from "./student.js"; console.log(name);

11. Exporting from Another Module

We can re-export values from another module. This is useful when organizing large projects into folders.

// math.js export function add(a, b) { return a + b; } // index.js export { add } from "./math.js"; // app.js import { add } from "./index.js"; console.log(add(10, 5));

The index.js file acts as a central place for exporting functions from other files.

12. Dynamic Imports

Dynamic imports allow us to load a module when it is needed instead of loading it at the beginning.

// app.js async function loadMath() { const mathModule = await import("./math.js"); console.log(mathModule.add(10, 20)); } loadMath();

Dynamic import returns a Promise, so we can use await or .then().

import("./math.js") .then((module) => { console.log(module.add(5, 3)); }) .catch((error) => { console.log("Module loading failed:", error); });

13. Organizing Project Files

A good project structure keeps related files together.

module-project/ │ ├── index.html ├── app.js │ ├── modules/ │ ├── math.js │ ├── message.js │ └── student.js │ └── styles/ └── style.css

Here:

  • index.html: Main webpage.
  • app.js: Main JavaScript file.
  • modules: Contains reusable JavaScript files.
  • styles: Contains CSS files.

14. Practical Modular Project

Let's create a small student information project using separate JavaScript modules.

Step 1: Create the project folder

Inside your js-lessons folder, create a folder named module-project.

Step 2: Create this file structure

module-project/ │ ├── index.html ├── app.js ├── student.js └── message.js

Step 3: index.html

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Student Module Project</title> </head> <body> <h1>Student Information</h1> <div id="output"></div> <script type="module" src="app.js"></script> </body> </html>

Step 4: student.js

// student.js export const student = { name: "Aarav", course: "JavaScript", progress: "Lesson 24" };

Step 5: message.js

// message.js export function createMessage(student) { return `Hello ${student.name}! You are learning ${student.course}. Your current progress is ${student.progress}.`; }

Step 6: app.js

// app.js import { student } from "./student.js"; import { createMessage } from "./message.js"; const output = document.getElementById("output"); output.textContent = createMessage(student);
Important: Browser modules should be tested through a local server, not by directly opening index.html using file://.

Step 7: Run the project with Live Server

  1. Open VS Code.
  2. Install the Live Server extension if it is not already installed.
  3. Open the module-project folder.
  4. Right-click index.html.
  5. Select Open with Live Server.
  6. Your browser should show the student information.
