1. Introduction to APIs

Modern websites often need information from other applications or servers. For example, a weather website needs weather information, and a news website needs articles.

An API allows different software applications to communicate and exchange information.

Everyday examples

  • A weather application getting current weather information.
  • A shopping website retrieving product details.
  • A learning platform loading course information.
  • A social media application displaying posts.
Simple meaning: An API acts as a communication bridge between different software applications.

2. What is an API?

4. HTTP Requests and Responses

HTTP stands for Hypertext Transfer Protocol. It is commonly used for communication between clients and web servers.

Common HTTP methods

Common HTTP status codes

Request and response

A request contains information such as the URL, HTTP method, headers and sometimes a body.

A response contains a status code, headers and sometimes response data.

5. Introduction to Fetch API

The Fetch API is a browser feature that allows JavaScript to make network requests and receive responses.

The fetch() method returns a Promise. We can handle it using then(), catch() or async/await.

Basic syntax

fetch("https://example.com/data")
    .then(function(response){
        return response.json();
    })
    .then(function(data){
        console.log(data);
    })
    .catch(function(error){
        console.log(error);
    });
Fetch is built into modern browsers. You do not need to install an additional JavaScript library to use it.

6. fetch() Syntax

Basic request

fetch(url, options);

The first argument is the resource URL. The optional second argument contains request settings such as method, headers and body.

Example

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(function(response){
        console.log(response);
    })
    .catch(function(error){
        console.log("Request failed:", error);
    });

This example sends a GET request to a sample API.

A fetch request can fail because of network problems or browser security restrictions. Also, an HTTP error such as 404 does not automatically reject the Fetch Promise.

7. Handling Responses

The response object contains information about the server's response.

Useful response properties

  • response.status - HTTP status code.
  • response.ok - True when status is in the 200–299 range.
  • response.statusText - Status description.
  • response.headers - Response headers.
fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(function(response){

        console.log(response.status);
        console.log(response.ok);

    });

Checking the response

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(function(response){

        if(!response.ok){
            throw new Error("HTTP error: " + response.status);
        }

        return response.json();
    })
    .then(function(data){
        console.log(data);
    })
    .catch(function(error){
        console.log(error.message);
    });

8. response.json()

Many APIs return data in JSON format.

The response.json() method reads the response body and parses JSON data into JavaScript values.

Example

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(function(response){
        return response.json();
    })
    .then(function(data){
        console.log(data);
        console.log(data.title);
    });

Sample JSON response

{
    "userId": 1,
    "id": 1,
    "title": "Example post title",
    "body": "This is sample post content."
}
Important: response.json() is asynchronous and returns a Promise. That is why we use return or await with it.

9. Handling API Errors

API requests can fail for several reasons.

Common reasons

  • Internet connection is unavailable.
  • The requested URL is incorrect.
  • The server returns an HTTP error.
  • The browser blocks a request because of CORS restrictions.
  • The response contains invalid or unexpected data.

Error handling using then() and catch()

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(function(response){

        if(!response.ok){
            throw new Error("Unable to load data");
        }

        return response.json();
    })
    .then(function(data){
        console.log(data);
    })
    .catch(function(error){
        console.log("Error:", error.message);
    });

Error handling using async/await

async function getData(){

    try{
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if(!response.ok){
            throw new Error("Request failed");
        }

        const data = await response.json();

        console.log(data);

    }catch(error){
        console.log("Error:", error.message);
    }
}

getData();

10. Working with JSON Data

JSON stands for JavaScript Object Notation. It is a common format for exchanging structured information.

Example JSON data

{
    "name": "Naina",
    "course": "JavaScript",
    "completed": false,
    "score": 85
}

Accessing returned data

fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(response => response.json())
    .then(data => {

        console.log(data.id);
        console.log(data.title);
        console.log(data.body);

    });

Once JSON has been parsed, you can access its properties just like a normal JavaScript object.

11. GET Requests

A GET request is used to retrieve information from a server.

Example

async function getPost(){

    const response = await fetch(
        "https://jsonplaceholder.typicode.com/posts/1"
    );

    if(!response.ok){
        throw new Error("Unable to get post");
    }

    const data = await response.json();

    console.log(data);
}

getPost().catch(error => console.log(error.message));

Fetch uses GET by default when no method is specified.

12. POST Requests

A POST request sends information to a server, often to create a new resource.

Example

async function createPost(){

    const response = await fetch(
        "https://jsonplaceholder.typicode.com/posts",
        {
            method: "POST",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify({
                title: "My First Post",
                body: "Learning Fetch API",
                userId: 1
            })
        }
    );

    if(!response.ok){
        throw new Error("Unable to create post");
    }

    const data = await response.json();

    console.log(data);
}

createPost().catch(error => console.log(error.message));

Understanding POST options

  • method: Specifies the HTTP method.
  • headers: Provides additional request information.
  • Content-Type: Tells the server the format of the request body.
  • body: Contains the data being sent.
  • JSON.stringify(): Converts a JavaScript object into a JSON string.

13. Async/Await with Fetch

We can combine async/await with Fetch API to write cleaner asynchronous code.

Example

async function getUsers(){

    try{

        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        if(!response.ok){
            throw new Error("Failed to load users");
        }

        const users = await response.json();

        console.log(users);

    }catch(error){

        console.log(error.message);

    }
}

getUsers();

Step-by-step explanation

  1. async declares an asynchronous function.
  2. fetch() sends the request.
  3. await waits for the response Promise.
  4. response.json() reads and parses the data.
  5. try...catch handles errors.
  6. The resulting data can be used in the application.

14. Loading and Error Messages

When an API request takes time, users should receive feedback.

A good application can show:

  • Loading message while waiting.
  • Data after a successful request.
  • Error message if the request fails.

Example

async function loadData(){

    const output = document.getElementById("output");

    output.textContent = "Loading...";

    try{

        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if(!response.ok){
            throw new Error("Unable to load data");
        }

        const data = await response.json();

        output.textContent = data.title;

    }catch(error){

        output.textContent = error.message;

    }
}
Always provide useful feedback instead of leaving users with an empty screen when a request is running or fails.
