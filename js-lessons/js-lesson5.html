Conditional Statements

Learn how JavaScript makes decisions and executes different blocks of code based on conditions.

1. What are Conditional Statements?

Conditional statements allow a program to make decisions. They execute different blocks of code depending on whether a condition is true or false.

For example, a program can check whether a student has passed an examination or not.

let marks = 75;

if (marks >= 40) {
    console.log("You passed!");
}

Here, JavaScript checks the condition. If it is true, the message is displayed.

2. The if Statement

The if statement executes a block of code only when the given condition is true.

Syntax

if (condition) {
    // Code executes if condition is true
}

Example

let age = 20;

if (age >= 18) {
    console.log("You are eligible to vote.");
}

Since age is 20, the condition is true and the message is displayed.

3. The if...else Statement

The if...else statement provides two possible paths. One block runs if the condition is true, and another runs if it is false.

Syntax

if (condition) {
    // If true
} else {
    // If false
}

Example

let marks = 32;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

Output: Fail

4. The else if Ladder

Use else if when you need to check multiple conditions.

Syntax

if (condition1) {
    // First condition
} else if (condition2) {
    // Second condition
} else if (condition3) {
    // Third condition
} else {
    // If none are true
}

Example: Grade Calculator

let marks = 82;

if (marks >= 90) {
    console.log("Grade A+");
} else if (marks >= 80) {
    console.log("Grade A");
} else if (marks >= 70) {
    console.log("Grade B");
} else if (marks >= 40) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

Output: Grade A

5. Nested if Statements

A nested if statement means placing one if statement inside another if statement.

Example

let age = 22;
let hasID = true;

if (age >= 18) {
    if (hasID === true) {
        console.log("Entry allowed");
    } else {
        console.log("Please show your ID");
    }
} else {
    console.log("You are under 18");
}

The inner condition is checked only when the outer condition is true.

6. The switch Statement

The switch statement is useful when you want to compare one expression against several possible values.

Syntax

switch (expression) {
    case value1:
        // Code
        break;
    case value2:
        // Code
        break;
    default:
        // Default code
}

Example: Day Selector

let day = 3;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    case 3:
        console.log("Wednesday");
        break;
    case 4:
        console.log("Thursday");
        break;
    default:
        console.log("Unknown day");
}

Output: Wednesday

Important Keywords

  • case defines a value to compare.
  • break stops execution from continuing into the next case.
  • default runs when no case matches.

7. The Ternary Operator

The ternary operator is a shorter way to write a simple if...else expression.

Syntax

condition ? valueIfTrue : valueIfFalse;

Example

let age = 19;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output: Adult

The condition is checked first. If true, the value before the colon is selected. Otherwise, the value after the colon is selected.

8. Practical Examples

Example 1: Positive, Negative or Zero

let number = -5;

if (number > 0) {
    console.log("Positive number");
} else if (number < 0) {
    console.log("Negative number");
} else {
    console.log("Zero");
}

Example 2: Even or Odd

let number = 12;

if (number % 2 === 0) {
    console.log("Even number");
} else {
    console.log("Odd number");
}

Example 3: Simple Login Check

let username = "student";
let password = "hello123";

if (username === "student" && password === "hello123") {
    console.log("Login successful");
} else {
    console.log("Invalid username or password");
}
