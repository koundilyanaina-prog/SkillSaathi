Data Types and Type Conversion

Understand different types of data in JavaScript and learn how to convert values from one type to another.

1. What are Data Types?

A data type describes the kind of value stored in a variable.

JavaScript has different data types to represent text, numbers, logical values and collections of information.

let studentName = "Meera";
let age = 21;
let isLearning = true;

Here, the values belong to different data types.

2. String Data Type

A String is used to store text. Strings are written inside single quotes, double quotes or backticks.

let firstName = "Aarav";
let city = 'Patna';
let message = `Welcome to SkillSaathi`;

console.log(firstName);
console.log(city);
console.log(message);
Remember: A string represents text, even when it contains numbers inside quotation marks. 
let phoneNumber = "9876543210";

3. Number Data Type

The Number data type is used for both whole numbers and decimal numbers.

let age = 20;
let price = 99.50;
let temperature = -5;

console.log(age);
console.log(price);
console.log(temperature);

JavaScript also supports special numeric values such as Infinity and NaN (Not a Number).

console.log(10 / 0);       // Infinity
console.log("hello" * 2);  // NaN

4. Boolean Data Type

Boolean values represent only two possible states: true or false.

let isStudent = true;
let isLoggedIn = false;

console.log(isStudent);
console.log(isLoggedIn);

Booleans are commonly used when a program needs to represent a yes/no or on/off condition.

5. Undefined and Null

Undefined

A variable that has been declared but not assigned a value contains undefined.

let result;

console.log(result); // undefined

Null

Null represents an intentional absence of a value.

let selectedStudent = null;

console.log(selectedStudent); // null
Difference: undefined often means a value has not been assigned. Null is used when we intentionally want to represent no value.

6. Object and Array – Introduction

Object

An object stores related information using key-value pairs.

let student = {
  name: "Meera",
  age: 20,
  course: "JavaScript"
};

console.log(student);
console.log(student.name);

Array

An array stores an ordered collection of values.

let subjects = ["HTML", "CSS", "JavaScript"];

console.log(subjects);
console.log(subjects[0]);
console.log(subjects[2]);

Array positions start from index 0.

7. The typeof Operator

The typeof operator helps us identify the data type of a value.

let name = "Aarav";
let age = 22;
let active = true;
let result;

console.log(typeof name);   // string
console.log(typeof age);    // number
console.log(typeof active); // boolean
console.log(typeof result); // undefined
Important JavaScript detail: typeof null returns "object". This is a long-standing JavaScript behaviour, not an indication that null is actually an object.

8. Type Conversion

Type conversion means deliberately changing a value from one data type to another.

Convert to String

let age = 25;

let textAge = String(age);

console.log(textAge);
console.log(typeof textAge);

Convert to Number

let price = "150";

let numericPrice = Number(price);

console.log(numericPrice);
console.log(typeof numericPrice);

Convert to Boolean

let value = 1;

let status = Boolean(value);

console.log(status); // true

Other useful conversion examples

console.log(Number("50"));     // 50
console.log(Number("Hello"));  // NaN
console.log(String(100));      // "100"
console.log(Boolean(0));       // false
console.log(Boolean("Hello"));// true

9. Type Coercion

Type coercion happens when JavaScript automatically converts a value from one type to another during an operation.

console.log("5" + 2); // "52"
console.log("5" - 2); // 3
console.log("5" * 2); // 10

In the first example, JavaScript converts 2 into a string and joins the values. In the other examples, the numeric string is converted to a number.

Tip: Use explicit conversion with String(), Number() or Boolean() when you want your code to be easier to understand.
