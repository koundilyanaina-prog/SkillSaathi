Lesson 13: DOM Manipulation

Learn how to change HTML content, update styles, work with attributes, and create or remove elements using JavaScript.

Part 2 – Core JavaScript

1. What is DOM Manipulation?

DOM Manipulation means changing the content, structure, or appearance of an HTML document using JavaScript.

After selecting an element from the DOM, we can modify it according to our requirements.

What Can We Change?

  • Text inside HTML elements.
  • HTML content inside elements.
  • CSS styles and classes.
  • HTML attributes.
  • The structure of a page by adding or removing elements.
<h1 id="title">Old Heading</h1>

<script>
  const heading = document.getElementById("title");
  heading.textContent = "New Heading";
</script>

Result: The heading changes from Old Heading to New Heading.

Remember: Lesson 12 taught us how to select elements. In this lesson, we will learn how to modify those selected elements.

2. Changing Text with textContent

The textContent property gets or changes the text inside an HTML element.

Example

<h2 id="message">Welcome Student</h2>

<script>
  const text = document.getElementById("message");

  text.textContent = "Welcome to SkillSaathi";
</script>

Result:

Welcome to SkillSaathi

You can also read the existing text:

console.log(text.textContent);
textContent treats assigned content as plain text. HTML tags written inside it will not be interpreted as HTML.

3. Changing HTML with innerHTML

The innerHTML property gets or changes the HTML content inside an element.

Example

<div id="content">
  Original Content
</div>

<script>
  const box = document.getElementById("content");

  box.innerHTML = "<h2>New Heading</h2><p>New Paragraph</p>";
</script>

Result: The div now contains a heading and a paragraph.

Be careful when using innerHTML with user-provided content. Inserting untrusted HTML can create security risks such as cross-site scripting (XSS). Use textContent for plain text.

4. Changing Styles with JavaScript

JavaScript can change the CSS styles of an HTML element using the style property.

Example

<h1 id="heading">SkillSaathi</h1>

<script>
  const heading = document.getElementById("heading");

  heading.style.color = "purple";
  heading.style.backgroundColor = "lightyellow";
  heading.style.fontSize = "35px";
</script>

Common style properties:

  • style.color
  • style.backgroundColor
  • style.fontSize
  • style.border
  • style.padding
  • style.margin
CSS property names with hyphens are written in camelCase in JavaScript. For example, background-color becomes backgroundColor.

5. Changing CSS Classes with classList

The classList property lets JavaScript work with the CSS classes of an element.

Important Methods

  • add() – Adds a class.
  • remove() – Removes a class.
  • toggle() – Adds a class if absent or removes it if present.
  • contains() – Checks whether a class exists.

Example

<div id="box" class="card">Hello Student</div>

<script>
  const box = document.getElementById("box");

  box.classList.add("active");
  box.classList.remove("card");

  console.log(box.classList.contains("active"));
</script>

Output:

true

We can also toggle a class:

box.classList.toggle("highlight");

6. Adding HTML Attributes

Attributes provide additional information about HTML elements.

JavaScript can add or update attributes using setAttribute().

Example

<img id="photo">

<script>
  const image = document.getElementById("photo");

  image.setAttribute("src", "student.jpg");
  image.setAttribute("alt", "Student Image");
  image.setAttribute("width", "200");
</script>

Here, JavaScript sets the image source, alternative text, and width.

setAttribute() can add a new attribute or update an existing attribute.

7. Removing HTML Attributes

The removeAttribute() method removes an attribute from an HTML element.

Example

<button id="submitBtn" disabled>
  Submit
</button>

<script>
  const button = document.getElementById("submitBtn");

  button.removeAttribute("disabled");
</script>

Result: The disabled attribute is removed and the button becomes enabled.

Another Example

const link = document.getElementById("myLink");

link.removeAttribute("target");

This removes the target attribute from the selected link.

8. Creating Elements with createElement()

The createElement() method creates a new HTML element using JavaScript.

Example

const newParagraph = document.createElement("p");

newParagraph.textContent = "I am a new paragraph";

console.log(newParagraph);

This creates a paragraph element in memory. It will not appear on the page until it is added to the document.

Creating a Heading

const heading = document.createElement("h2");

heading.textContent = "Welcome Learners";
createElement() creates the element, but does not automatically insert it into the page.

9. Adding Elements with appendChild()

The appendChild() method adds a node as the last child of a parent element.

Example

<div id="container"></div>

<script>
  const container = document.getElementById("container");

  const paragraph = document.createElement("p");

  paragraph.textContent = "Hello from JavaScript!";

  container.appendChild(paragraph);
</script>

Result: A new paragraph appears inside the container.

Adding a List Item

const list = document.createElement("ul");

const item = document.createElement("li");

item.textContent = "Learn JavaScript";

list.appendChild(item);

The new list item is added inside the list element.

10. Removing Elements with remove()

The remove() method removes an element from the DOM.

Example

<p id="oldText">This paragraph will be removed.</p>

<script>
  const paragraph = document.getElementById("oldText");

  paragraph.remove();
</script>

Result: The paragraph is removed from the document.

Removing a Child with removeChild()

const parent = document.getElementById("container");

const child = document.getElementById("item");

parent.removeChild(child);

removeChild() removes a specific child node from its parent.
