📖 1. What are HTML Media Elements?

HTML media elements allow us to display images, play audio and show videos directly on a webpage.

The most commonly used media elements are:

  • <img> – Displays an image.
  • <audio> – Plays an audio file.
  • <video> – Plays a video file.

🖼️ 2. Adding Images

The <img> element is used to display images. It uses two important attributes:

  • src: Specifies the image location.
  • alt: Provides alternative text if the image cannot load.

Example:

<img src="flower.jpg" alt="A beautiful flower" width="300">

Remember: The <img> element does not need a closing tag.

🎵 3. Adding Audio

The <audio> element allows users to play sound files on a webpage.

Example:

<audio controls>
  <source src="music.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

The controls attribute displays play, pause and volume controls.

🎥 4. Adding Videos

The <video> element is used to display videos on a webpage.

Example:

<video width="400" controls>
  <source src="video.mp4" type="video/mp4">
  Your browser does not support video.
</video>

The controls attribute provides video playback controls.

⚙️ 5. Important Media Attributes

  • controls: Shows media controls.
  • autoplay: Attempts to play media automatically.
  • loop: Repeats the media.
  • muted: Starts media without sound.
  • width: Sets the width of media.
  • height: Sets the height of media.

Note: Browsers often block autoplay with sound. Autoplay may work when the media is muted.

🌐 6. Complete Media Webpage Example

<!DOCTYPE html>
<html>
<head>
  <title>My Media Page</title>
</head>
<body>

  <h1>Welcome to My Media Page</h1>

  <h2>My Image</h2>
  <img src="flower.jpg" alt="Flower" width="300">

  <h2>My Audio</h2>
  <audio controls>
    <source src="music.mp3" type="audio/mpeg">
  </audio>

  <h2>My Video</h2>
  <video width="400" controls>
    <source src="video.mp4" type="video/mp4">
  </video>

</body>
</html>
