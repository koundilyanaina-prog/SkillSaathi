📘 Part 1: What is Semantic HTML?

Semantic HTML means using HTML elements that clearly describe the meaning and purpose of their content.

For example, a header represents the introductory area of a page, while a footer represents its closing area.

Why use Semantic HTML?

  • Makes webpage structure easier to understand.
  • Improves accessibility.
  • Helps search engines understand page content.
  • Makes code easier to maintain.

🏗️ Part 2: Important Semantic Elements

1. Header

Defines the introductory area of a page or section.

<header>
  <h1>My Website</h1>
</header>

2. Nav

Contains important navigation links.

<nav>
  <a href="index.html">Home</a>
  <a href="about.html">About</a>
</nav>

3. Main

Contains the main content of a webpage.

<main>
  <h2>Welcome to My Website</h2>
  <p>This is the main content.</p>
</main>

4. Section

Groups related content into a section.

<section>
  <h2>Our Courses</h2>
  <p>Explore our learning courses.</p>
</section>

5. Article

Represents independent, self-contained content.

<article>
  <h2>Learning HTML</h2>
  <p>HTML is used to structure webpages.</p>
</article>

6. Aside

Contains additional or related content.

<aside>
  <h3>Related Topics</h3>
  <p>Learn CSS and JavaScript too.</p>
</aside>

7. Footer

Defines the closing area of a page or section.

<footer>
  <p>Copyright 2026 My Website</p>
</footer>

💻 Part 3: Complete Semantic Webpage Example

<header>
  <h1>My Learning Website</h1>
</header>

<nav>
  <a href="#">Home</a>
  <a href="#">Courses</a>
</nav>

<main>
  <section>
    <h2>Our Courses</h2>

    <article>
      <h3>HTML Course</h3>
      <p>Learn HTML step by step.</p>
    </article>
  </section>

  <aside>
    <p>Explore more learning resources.</p>
  </aside>
</main>

<footer>
  <p>Copyright 2026</p>
</footer>
