Lesson 16: Useful HTML5 Elements

Explore useful HTML elements such as details, progress, meter, time, mark, abbr and dialog.

🎯 What You Will Learn

  • How to use details and summary for expandable information.
  • The difference between progress and meter.
  • How to represent dates and times with the time element.
  • How to highlight text with mark and explain abbreviations with abbr.
  • How to use dialog for a simple dialog box.

1. Details and Summary

<details> creates a disclosure widget. The <summary> element provides the visible label. The user can open or close it without writing JavaScript.

<details>
  <summary>What is HTML?</summary>
  <p>HTML structures content on web pages.</p>
</details>

2. Progress and Meter

Use <progress> to show the completion progress of a task. Use <meter> to show a measurement within a known range.

<label for="courseProgress">Course progress</label>
<progress id="courseProgress"
          value="7" max="10">70%</progress>

<label for="skillLevel">Skill level</label>
<meter id="skillLevel"
       min="0" max="100" value="75">
  75 out of 100
</meter>

3. Time, Mark and Abbr

<time> can provide a machine-readable date or time through its datetime attribute. <mark> highlights relevant text. <abbr> identifies an abbreviation and can provide its full meaning in a title.

<p>Class starts on
  <time datetime="2026-11-10">10 November 2026</time>.
</p>

<p>Remember to <mark>practice daily</mark>.</p>

<p><abbr title="HyperText Markup Language">
  HTML
</abbr> structures web content.</p>

4. Dialog Element

<dialog> represents a dialog box. JavaScript can open it with showModal() and close it with close(). The example below uses buttons to control it.

<button type="button" onclick="document
  .getElementById('infoDialog').showModal()">
  Open information
</button>

<dialog id="infoDialog">
  <p>Welcome to SkillSaathi!</p>
  <button type="button"
    onclick="document.getElementById('infoDialog').close()">
    Close
  </button>
</dialog>

In larger projects, keep JavaScript in a separate file and connect buttons with event listeners.
