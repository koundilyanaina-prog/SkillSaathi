LESSON 09 · HTML BASICS

Let's Learn HTML Entities & Symbols! ✨

Learn how to display special characters, symbols and emojis on your webpages.

🎯 What You Will Learn

  • What are HTML entities?
  • How to display special characters
  • How to use mathematical symbols
  • How to display currency symbols
  • How to add emojis to webpages

📖 1. What are HTML Entities?

HTML entities are special codes used to display reserved characters and symbols that may otherwise be interpreted as HTML code. 

&lt;  displays  <
&gt;  displays  >
&amp; displays  &

🔤 2. Common HTML Entities

Here are some commonly used HTML entities:

&nbsp;  → Non-breaking space
&copy;  → © Copyright
&reg;   → ® Registered
&trade; → ™ Trademark
&hearts; → ♥ Heart

💰 3. Currency Symbols

HTML supports many currency symbols:

&#8377; → ₹ Indian Rupee
&euro;  → € Euro
&pound; → £ British Pound
&yen;   → ¥ Japanese Yen

➗ 4. Mathematical Symbols

&plus;  → +
&minus; → −
&times; → ×
&divide; → ÷
&ne;    → ≠
&le;    → ≤
&ge;    → ≥

😊 5. Using Emojis in HTML

We can directly add emojis to HTML using UTF-8 encoding. Our webpage already uses UTF-8 through the meta charset tag. 

<h2>Welcome to SkillSaathi 😊</h2>
<p>Keep Learning 🚀</p>
<p>You can do it! ❤️</p>

📌 6. Important Points

  • HTML entities usually begin with an ampersand (&) and end with a semicolon (;).
  • Use entities to display reserved HTML characters.
  • Use UTF-8 encoding for a wide range of characters and emojis.
  • Numeric entities can represent characters using decimal or hexadecimal codes.
