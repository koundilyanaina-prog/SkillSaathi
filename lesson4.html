LESSON 04 · HTML BASICS

HTML Lists and Tables 📋

Learn how to organise information using lists and display structured data using HTML tables.

🎯 What You Will Learn

  • Create ordered and unordered lists.
  • Understand list items and nested lists.
  • Create HTML tables using rows and columns.
  • Use table headings and data cells.

📘 Part 1: Unordered Lists

An unordered list displays items with bullet points. Use the <ul> tag to create the list and <li> for each item. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Output Example

  • HTML
  • CSS
  • JavaScript

Remember: Every list item should be placed inside an li tag.

🔢 Part 2: Ordered Lists

An ordered list displays items in a sequence, usually with numbers. Use the <ol> tag. 

<ol>
  <li>Open VS Code</li>
  <li>Create an HTML file</li>
  <li>Write your code</li>
  <li>Open it in a browser</li>
</ol>

Output Example

  1. Open VS Code
  2. Create an HTML file
  3. Write your code
  4. Open it in a browser

You can also change the numbering style using the type attribute, such as 1, A, a, I or i. 

<ol type="A">
  <li>First Topic</li>
  <li>Second Topic</li>
</ol>

📂 Part 3: Nested Lists

A nested list is a list placed inside another list item. It is useful for organising related topics and subtopics. 

<ul>
  <li>Web Development
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </li>
  <li>Programming</li>
</ul>

Common Mistakes

  • Forgetting to close li tags.
  • Placing nested lists outside the parent li element.
  • Mixing up ol and ul tags.

📊 Part 4: HTML Tables

HTML tables organise information into rows and columns. Important table tags include:

  • <table> — Creates a table.
  • <tr> — Creates a table row.
  • <th> — Creates a heading cell.
  • <td> — Creates a data cell.

Example Code

<table border="1">
  <tr>
    <th>Name</th>
    <th>Course</th>
  </tr>
  <tr>
    <td>Nina</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>Rahul</td>
    <td>CSS</td>
  </tr>
</table>

Output Example

Name Course
Nina HTML
Rahul CSS

Tip: In modern websites, use CSS instead of the old border attribute to style tables.
