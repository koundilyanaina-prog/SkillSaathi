1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

What does HTML do?

  • It gives text a structure, such as headings and paragraphs.
  • It connects pages through links.
  • It places images, tables, forms and other content on a page.

HTML, CSS and JavaScript

  • HTML: structures the content.
  • CSS: controls appearance, colours, spacing and layout.
  • JavaScript: adds behaviour and interaction.
Think of a house: HTML is its structure, CSS is its decoration, and JavaScript makes its interactive features work.

2. The structure of an HTML page

A standard HTML document has a document declaration, an html element, a head section and a body section.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Page</title> </head> <body> <h1>Hello, Learner!</h1> <p>I am learning HTML.</p> </body> </html>
Code Purpose
<!DOCTYPE html> Tells the browser to use modern HTML standards mode. It is a declaration, not an HTML tag.
<html> The root element that contains the page.
<head> Contains metadata, the title and links to resources.
<title> Sets the page title shown in the browser tab.
<body> Contains the main content displayed on the page.

Why is the title tag important?

The title is not the same as the visible h1 heading. It names the document in the browser tab, helps identify pages in bookmarks and may be used as a search-result title.

<head> <title>My Cooking Blog</title> </head> <body> <h1>Welcome to my blog</h1> </body>
Remember: put the title inside head. Put visible headings, paragraphs, images and buttons inside body.

3. Tags, elements and attributes

What is a tag?

A tag is markup written inside angle brackets. For example, <p> is an opening tag and </p> is a closing tag.

What is an element?

<p>Welcome to SkillSaathi!</p>

In this example, the opening tag, the text and the closing tag together form a paragraph element.

What is an attribute?

An attribute provides extra information or settings for an element. It is usually written in the opening tag as a name and value.

<a href="https://example.com">Visit website</a>

Here, href is the attribute name and the web address is its value. The link text is what the visitor sees.

Do all tags need a closing tag?

No. Elements such as br, hr and img are void elements. They do not have closing tags. Most text elements, such as p and h1, do have closing tags.

Void Elements, Nesting & Element Types

1. Void Elements

Void elements do not have closing tags and cannot contain child elements. Examples: br, hr, img, input and meta. 

<p>First line<br>Second line</p>
<hr>
<img src="flower.jpg" alt="A flower">

2. Nesting Elements

Nesting means placing one element inside another. Close the inner element before closing its parent. 

<p>Learn <strong>HTML</strong> today.</p>

3. Block and Inline Elements

Block elements normally start on a new line. Examples: p, div and headings.

Inline elements normally flow within text. Examples: strong, em and a.

Common HTML Mistakes

  • Forgetting a closing tag where one is required.
  • Writing an image without meaningful alt text.
  • Closing nested elements in the wrong order.

4. Headings and text tags

Headings: h1 to h6

HTML provides six heading levels. h1 is the highest-level heading; h6 is the lowest. Use headings to organise content, not just to make text large.

<h1>My Website</h1> <h2>About Me</h2> <h3>My Hobbies</h3> <h4>Reading</h4> <h5>My Favourite Books</h5> <h6>Book Notes</h6>

Paragraph: p

Use p for a paragraph of text. Separate paragraphs with separate p elements.

<p>I am learning web development.</p> <p>I will practise every day.</p>

New line: br

br inserts a line break within text. It has no closing tag. Use it when a line break is meaningful, such as in an address or poem.

<p>First line<br>Second line</p>
Do not use many br tags just to create space between sections. Use CSS margin and padding for spacing.

Horizontal divider: hr

hr represents a thematic break between sections of content. Browsers usually display it as a horizontal line.

<p>Chapter One</p> <hr> <p>Chapter Two</p>

Text emphasis and meaning

Tag Use
<strong>Marks important text; browsers usually show it in bold.
<em>Adds emphasis; browsers usually show it in italics.
<b>Draws attention without adding strong importance.
<i>Marks text in an alternate voice or mood, such as a technical term.
<mark>Highlights text as relevant.
<small>Represents side comments or small print.
<sub>Displays subscript, such as the 2 in H₂O.
<sup>Displays superscript, such as the 2 in x².
<p>HTML is <strong>important</strong>.</p> <p>This word is <em>emphasised</em>.</p> <p>Water is H<sub>2</sub>O.</p> <p>Two squared is 2<sup>2</sup>.</p>

5. Creating lists

Unordered list: ul

Use ul when the order of the items does not matter. Each list item goes inside an li element.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

Ordered list: ol

Use ol when the order matters, such as steps in a process.

<ol> <li>Open VS Code</li> <li>Write HTML</li> <li>Save the file</li> </ol>

Description list: dl, dt and dd

Use dl for a list of terms and descriptions. dt is the term and dd is its description.

<dl> <dt>HTML</dt> <dd>Structures web page content.</dd> <dt>CSS</dt> <dd>Styles the page.</dd> </dl>
Remember: ul and ol contain li elements. Do not use list tags just to create visual spacing.

6. Common attributes and HTML comments

Attributes add information to elements. Common examples include id, class, title, href, src, alt and lang.

Attribute Purpose
idIdentifies a particular element on a page.
classGroups elements for styling or scripting.
hrefSpecifies the destination of a link.
srcSpecifies the source of an image or other embedded resource.
altProvides alternative text for an image.
langIdentifies the language of the document or an element.
titleCan provide advisory information about an element. It is different from the title element in head.

HTML comments

Comments are notes in the source code. They are not displayed as page content by the browser.

<!-- This is a comment --> <h1>My Website</h1>
Do not put passwords or private information in comments. Comments are still visible to anyone who can inspect the source.
