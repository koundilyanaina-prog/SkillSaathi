📘 Part 1: What Are HTML Attributes?

HTML attributes provide additional information about HTML elements. They are written inside the opening tag. 

<a href="https://example.com">
  Visit Website
</a>

In this example, href is an attribute that specifies the destination of the link.

Basic Attribute Syntax

<element attribute="value">
  Content
</element>

Most attributes use a name and a value. Always use quotation marks around attribute values.

🏷️ Part 2: Global HTML Attributes

Global attributes can be used on most HTML elements.

1. id Attribute

The id attribute gives an element a unique identifier. 

<h1 id="main-heading">
  Welcome to My Website
</h1>

An id should be unique within a webpage.

2. class Attribute

The class attribute groups elements so they can share CSS styles or JavaScript behavior. 

<p class="intro">
  Welcome to my website.
</p>

<p class="intro">
  Learn HTML with us.
</p>

3. title Attribute

The title attribute provides additional information, often displayed as a tooltip when hovering. 

<button title="Click to continue">
  Continue
</button>

4. style Attribute

The style attribute adds inline CSS to an element. 

<p style="color: purple;">
  Welcome to SkillSaathi!
</p>

For larger projects, using an external CSS file is usually better.

🔗 Part 3: Common HTML Attributes

1. href

Specifies the destination of a link.

<a href="https://example.com">
  Visit Example
</a>

2. src

Specifies the location of an image or media file.

<img src="photo.jpg"
     alt="A beautiful landscape">

3. alt

Provides alternative text for an image. It is useful for screen readers and when an image cannot be displayed. 

<img src="book.jpg"
     alt="An open learning book">

📝 Part 4: HTML Form Attributes

1. placeholder

Displays a short hint inside an input field.

<input type="text"
       placeholder="Enter your name">

2. required

Makes a form field mandatory before submission.

<input type="email" required>

3. readonly

Makes a field uneditable by the user, but its value can still be submitted with a form. 

<input type="text"
       value="SkillSaathi"
       readonly>

4. disabled

Disables a form control. Its value is not submitted with the form. 

<button disabled>
  Not Available
</button>

🧩 Part 5: Data Attributes

Custom data attributes begin with data-. They allow developers to store extra information on HTML elements. 

<button data-course="HTML">
  Start Learning
</button>

JavaScript can read this information using the element's dataset property.

💬 Part 6: HTML Comments

Comments are notes written in HTML code. Browsers do not display them as webpage content. 

<!-- This is an HTML comment -->

<h1>Welcome to SkillSaathi</h1>

Comments help explain code and organize larger projects. Never store passwords or private information in comments.

🧹 Part 7: HTML Coding Best Practices

  • Use lowercase for HTML tag and attribute names.
  • Put quotation marks around attribute values.
  • Use meaningful id and class names.
  • Keep id values unique on each page.
  • Always provide useful alt text for meaningful images.
  • Close elements correctly and maintain proper nesting.
  • Indent code to make it easy to read.
  • Use external CSS for larger styling tasks.

Correct Nesting Example

<p>
  This is <strong>important</strong> text.
</p>

Incorrect Nesting Example

<p>
  This is <strong>important</p>
</strong>
