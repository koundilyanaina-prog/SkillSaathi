LESSON 03 · HTML BASICS

Headings, Paragraphs and Text Formatting ✍️

Learn how to organise text and highlight important information using HTML tags.

🎯 What You Will Learn

  • Use all six HTML heading levels.
  • Create paragraphs using the p tag.
  • Emphasise text using strong and em.
  • Use line breaks and horizontal rules correctly.

📘 Part 1: HTML Headings

HTML provides six heading levels, from <h1> to <h6>. Use them to organise a page into a clear hierarchy. 

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>
<h4>Heading Level 4</h4>
<h5>Heading Level 5</h5>
<h6>Heading Level 6</h6>

Tip: Choose headings according to their meaning, not just their appearance. Usually, a page has one main h1 heading.

Common Mistakes

  • Choosing h1, h2 and h3 only to make text bigger or smaller.
  • Skipping heading levels without a structural reason.
  • Forgetting to close a heading tag.

📝 Part 2: Paragraphs

The <p> tag represents a paragraph. Browsers normally display paragraphs as separate blocks of text. 

<p>Welcome to SkillSaathi.</p>
<p>I am learning HTML step by step.</p>

Line Breaks and Horizontal Rules

Use <br> when a line break is part of the content, such as in an address or a poem. 

<p>First line<br>Second line</p>

Use <hr> when you want to indicate a thematic break between sections. 

<p>Topic One</p>
<hr>
<p>Topic Two</p>

Avoid using many br tags just to create spacing. CSS is better for controlling layout and spacing.

✨ Part 3: Text Formatting

HTML has tags that give text meaning or emphasis. Here are the most useful examples. 

<strong>Important information</strong>
<em>Emphasised text</em>
<b>Attention-grabbing text</b>
<i>Alternative voice or term</i>
<mark>Highlighted text</mark>
<small>Small print</small>
<del>Deleted text</del>
<ins>Inserted text</ins>
H<sub>2</sub>O
x<sup>2</sup>

Important Difference

  • <strong> indicates importance.
  • <em> indicates emphasis.
  • <b> draws attention without adding importance by itself.
  • <i> can represent an alternate voice or term.
  • <mark> highlights text for reference.

Remember: The browser's default appearance can vary. Use CSS when you need precise control over colours, sizes or styles.
