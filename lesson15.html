Lesson 15: Responsive Images and Figure Elements

Learn how to create flexible images, choose image sources for different screens, add captions and improve image loading.

🎯 What You Will Learn

  • Why responsive images matter.
  • How to use srcset and sizes.
  • How the <picture> element offers different image formats or sources.
  • How to add captions with <figure> and <figcaption>.
  • How loading="lazy" can defer off-screen images.

1. Responsive Images

A responsive image adapts to the screen or layout where it is displayed. The CSS rule below lets an image shrink inside its container without becoming wider than that container.

img {
  max-width: 100%;
  height: auto;
}

Use width and height attributes when the image dimensions are known. They help the browser reserve space before the image loads.

2. The srcset and sizes Attributes

srcset lists image-file choices with their intrinsic widths. sizes tells the browser how wide the image is expected to appear at different viewport sizes.

<img
  src="small-photo.jpg"
  srcset="small-photo.jpg 480w,
          medium-photo.jpg 800w,
          large-photo.jpg 1200w"
  sizes="(max-width: 600px) 100vw,
         (max-width: 1000px) 80vw,
         700px"
  alt="A mountain landscape">

Use real files that exist in your project. The browser chooses a suitable candidate based on the available information and display conditions.

3. The picture Element

<picture> lets you provide alternate image sources. The browser checks the <source> elements in order and uses the first supported matching source. Keep an <img> element as the fallback.

<picture>
  <source media="(max-width: 600px)"
          srcset="mobile-banner.jpg">
  <source type="image/webp"
          srcset="banner.webp">
  <img src="banner.jpg"
       alt="SkillSaathi learning banner">
</picture>

4. Figure and Figcaption

Use <figure> for self-contained content such as an image, diagram, or code example. Use <figcaption> to provide its caption.

<figure>
  <img src="classroom.jpg"
       alt="Students learning together"
       width="600" height="400">
  <figcaption>
    Learning together at SkillSaathi
  </figcaption>
</figure>

5. Lazy Loading

loading="lazy" asks the browser to defer loading an image until it is near the visible area. It is often useful for images lower down a long page. Do not lazy-load the main hero image if it is immediately visible.

<img src="gallery-photo.jpg"
     alt="A student working on a laptop"
     loading="lazy"
     width="600" height="400">

Remember: Every meaningful image needs useful alternative text. Use an empty alt="" only for purely decorative images.
