LESSON 13 · HTML FINAL PROJECT

Let's Build Your First Complete Website! 🚀

It's time to use everything you have learned in HTML and create your own complete website.

🎯 What You Will Learn

  • How to create a complete HTML webpage
  • How to organize website sections
  • How to create navigation menus
  • How to add images and links
  • How to create contact forms
  • How to use semantic HTML elements
  • How to build a real mini website project

🌐 1. What Is a Complete Website?

A website is a collection of webpages that share information with visitors. A complete website usually contains different sections such as a header, navigation menu, main content and footer. 


<header>Website Header</header>

<nav>Navigation Menu</nav>

<main>
  <section>Main Content</section>
  <section>About Section</section>
</main>

<footer>Website Footer</footer>

🧱 2. Plan Your Website Structure

Before writing HTML, decide which sections your website needs. For this project, we will create a personal learning website.

  • Home: Welcome visitors.
  • About: Introduce your website.
  • Courses: Display available courses.
  • Contact: Provide a contact form.
  • Footer: Display copyright information.

🧭 3. Create a Navigation Menu

A navigation menu helps visitors move between different sections of a website. 


<nav>
  <a href="#home">Home</a>
  <a href="#about">About</a>
  <a href="#courses">Courses</a>
  <a href="#contact">Contact</a>
</nav>

🖼️ 4. Add Images and Links

Images make a website attractive, while links help visitors explore other webpages and resources. 


<img src="image.jpg"
     alt="Learning illustration">

<a href="https://example.com">
  Visit Website
</a>

📚 5. Display Your Courses

You can use sections, headings, paragraphs and lists to display information about your courses. 


<section id="courses">
  <h2>Our Courses</h2>

  <article>
    <h3>HTML Basics</h3>
    <p>Learn how to build webpages.</p>
  </article>

  <article>
    <h3>CSS Basics</h3>
    <p>Learn how to style webpages.</p>
  </article>
</section>

📩 6. Create a Contact Form

A contact form allows visitors to enter their details and send a message. 


<form>
  <label for="name">Your Name:</label>
  <input type="text" id="name" required>

  <label for="email">Your Email:</label>
  <input type="email" id="email" required>

  <button type="submit">Send Message</button>
</form>

🦶 7. Create a Website Footer

A footer usually appears at the bottom of a webpage. It can contain copyright information and useful links. 


<footer>
  <p>© 2026 My Learning Website</p>
</footer>

⭐ 8. Final Project Checklist

  • Use a proper HTML document structure.
  • Add a website title.
  • Create a navigation menu.
  • Add Home and About sections.
  • Display at least two courses.
  • Add an image with alt text.
  • Create a contact form.
  • Add a footer.
