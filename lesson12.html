LESSON 12 · HTML BASICS

Let's Learn HTML SEO & Meta Tags! 🔍

Learn how to make webpages search-engine friendly using HTML title tags, meta descriptions and other important tags.

🎯 What You Will Learn

  • What is SEO?
  • HTML Title Tag
  • Meta Description
  • Meta Keywords
  • Viewport Meta Tag
  • Open Graph Meta Tags
  • HTML SEO Best Practices

🔍 1. What is SEO?

SEO stands for Search Engine Optimization. It helps search engines understand webpage content and can improve how pages appear in search results.

Good SEO also makes website content clear and useful for visitors.

🏷️ 2. HTML Title Tag

The title tag defines the title of a webpage. It usually appears in the browser tab and may appear as the clickable heading in search results. 

<title>Learn HTML - SkillSaathi</title>

📝 3. Meta Description

A meta description provides a short summary of a webpage. Search engines may use it as a snippet in search results. 

<meta name="description"
content="Learn HTML, CSS and JavaScript for free with SkillSaathi.">

🔑 4. Meta Keywords

Meta keywords were once used to describe webpage topics. Major search engines like Google do not use this tag for ranking. 

<meta name="keywords"
content="HTML, CSS, Web Development">

📱 5. Viewport Meta Tag

The viewport tag helps webpages display properly on mobile devices and different screen sizes. 

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

🌐 6. Open Graph Meta Tags

Open Graph tags control how a webpage preview appears when someone shares its link on supported social platforms. 

<meta property="og:title"
content="Learn HTML - SkillSaathi">

<meta property="og:description"
content="Explore free web development lessons.">

<meta property="og:image"
content="https://example.com/course-image.jpg">

<meta property="og:type" content="website">

⭐ 7. HTML SEO Best Practices

  • Write a unique and meaningful title for every page.
  • Add a useful meta description.
  • Use clear and descriptive headings.
  • Add meaningful alt text to informative images.
  • Create descriptive links.
  • Make webpages mobile-friendly.
  • Write original and helpful content.
