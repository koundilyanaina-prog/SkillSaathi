LESSON 08 · HTML BASICS

Let's Learn HTML Iframes! 🌐

Learn how to embed webpages, maps and videos inside your HTML page.

🎯 What You Will Learn

  • What is an HTML iframe?
  • How to embed another webpage
  • How to embed YouTube videos
  • How to set iframe width and height
  • Important iframe attributes

📖 1. What is an HTML Iframe?

An iframe (Inline Frame) is used to display another webpage or external content inside the current webpage. 

<iframe src="https://example.com"></iframe>

💻 2. Iframe Width and Height

We can use width and height attributes to control the size of an iframe. 

<iframe
  src="https://example.com"
  width="500"
  height="300">
</iframe>

🎬 3. Embedding YouTube Videos

We can embed YouTube videos using an iframe. YouTube provides an Embed option to get the video URL. 

<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="YouTube video"
  allowfullscreen>
</iframe>

🗺️ 4. Embedding Google Maps

Google Maps can also be displayed inside a webpage using an iframe embed link. 

<iframe
  src="YOUR_GOOGLE_MAPS_EMBED_URL"
  width="600"
  height="400">
</iframe>

📌 5. Important Iframe Attributes

  • src: Specifies the page to display.
  • width: Sets the iframe width.
  • height: Sets the iframe height.
  • title: Describes the iframe content.
  • allowfullscreen: Allows fullscreen viewing.
  • loading: Controls when the iframe loads.
