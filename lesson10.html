LESSON 10 · HTML BASICS

Let's Learn Advanced HTML Forms! 📝

Learn input types, validation and how to create professional HTML forms.

🎯 What You Will Learn

  • Different HTML input types
  • Required fields and validation
  • Minimum and maximum length
  • Radio buttons and checkboxes
  • Submit and reset buttons

📖 1. Different Input Types

HTML supports different types of form inputs.

<input type="text">
<input type="email">
<input type="password">
<input type="number">
<input type="date">
<input type="tel">

🔒 2. Required Fields

The required attribute makes a field compulsory.

<input type="email" required>

📏 3. Minlength and Maxlength

These attributes control the minimum and maximum number of characters.

<input type="text"
  minlength="3"
  maxlength="20">

🔘 4. Radio Buttons

Radio buttons allow users to select one option from a group.

<input type="radio" name="gender" value="male">
Male

<input type="radio" name="gender" value="female">
Female

☑️ 5. Checkboxes

Checkboxes allow users to select multiple options.

<input type="checkbox" name="skill" value="html">
HTML

<input type="checkbox" name="skill" value="css">
CSS

🚀 6. Submit and Reset Buttons

<button type="submit">Submit</button>
<button type="reset">Reset</button>

📌 7. Important Form Attributes

  • required: Makes a field compulsory.
  • minlength: Sets minimum characters.
  • maxlength: Sets maximum characters.
  • min and max: Set numeric limits.
  • placeholder: Displays a helpful hint.
  • pattern: Defines an input format.

  3. Which input allows multiple selections?
  4. What is the purpose of the reset button?
