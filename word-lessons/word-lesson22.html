Mail Merge

Learn how to create personalized letters, labels and documents for multiple recipients using Mail Merge.

1. What is Mail Merge?

Mail Merge is a Microsoft Word feature that combines a main document with a data source to create multiple personalized documents.

Instead of writing the same letter separately for every person, you prepare one document and connect it to a list of recipients.

Example: A school can create personalized invitation letters for 100 parents using one letter template and a recipient list.

2. Main Components of Mail Merge

Main Document

The document containing the common message, such as a letter or invitation.

Data Source

The list containing recipient information, such as names, addresses and email details. It may be an Excel spreadsheet or another supported data source.

Merge Fields

Placeholders inserted into the main document. Word replaces them with information from each recipient's record.

Example data fields:
FirstName | LastName | City | Email

3. Steps to Perform Mail Merge

  1. Open Microsoft Word and create your main document.
  2. Go to the Mailings tab.
  3. Click Start Mail Merge and choose the document type, such as Letters.
  4. Click Select Recipients.
  5. Choose an existing list or create a new recipient list.
  6. Place the cursor where personalized information should appear.
  7. Click Insert Merge Field and select the required field.
  8. Use Preview Results to check each recipient's document.
  9. Click Finish & Merge to create the final documents.
Tip: Check the recipient list carefully before completing the merge. Incorrect data can create incorrect letters.

4. Example of a Mail Merge Letter

Dear «FirstName» «LastName»,

We are pleased to invite you to our annual school event in «City».

Thank you for your support.

Regards,
School Administration

The merge fields are replaced with actual recipient information for each generated letter.

5. Types of Mail Merge

  • Letters: Personalized letters for many recipients.
  • Email Messages: Personalized email messages through a supported email setup.
  • Envelopes: Envelopes with recipient addresses.
  • Labels: Address labels or product labels.
  • Directory: A combined list or catalogue using data records.

6. Practical Activity

Create a simple recipient list in Excel with these columns:

FirstName | LastName | City
Riya | Sharma | Ranchi
Aman | Kumar | Patna
Neha | Singh | Delhi

Then perform these tasks:

  1. Create a new Word document with an invitation letter.
  2. Start Mail Merge and select Letters.
  3. Connect your Excel recipient list.
  4. Insert FirstName, LastName and City merge fields.
  5. Preview the results for all three recipients.
  6. Finish the merge and review the generated letters.
Learning Goal: Create multiple personalized letters from one document and a recipient list.
