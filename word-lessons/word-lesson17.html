Lesson 17 of 25 | Styles and Themes

🎯 Learning Objectives

Learn how to use built-in styles and themes to maintain consistent formatting throughout a document.

  • Understand Word styles.
  • Apply heading and paragraph styles.
  • Modify and create styles.
  • Understand document themes.
  • Change theme colours and fonts.
  • Use styles to create organized documents.

1. What are Styles?

Styles are predefined sets of formatting options that can be applied to text with a single action.

A style may contain font type, font size, colour, boldness, spacing and alignment settings.

Common Word Styles

  • Normal
  • Title
  • Subtitle
  • Heading 1
  • Heading 2
  • Heading 3
  • Quote
  • Emphasis
Tip: Use heading styles instead of manually making every heading bold and large. This also helps Word understand your document structure.

2. How to Apply a Style

  1. Select the text you want to format, or place the cursor in its paragraph.
  2. Open the Home tab.
  3. Find the Styles group.
  4. Choose a style such as Title or Heading 1.
  5. The selected text will receive the style formatting.
Example:
  • Document title → Title style
  • Main chapter heading → Heading 1
  • Subheading → Heading 2
  • Normal paragraph → Normal style

3. Modifying an Existing Style

You can change an existing style to match your preferred document design.

  1. Open the Home tab.
  2. Right-click the style you want to change in the Styles gallery.
  3. Select Modify.
  4. Change the font, size, colour and other formatting options.
  5. Click OK.

Text using that style can update automatically according to the modified style settings.

4. Creating a New Style

If the built-in styles do not meet your needs, you can create your own style.

  1. Format a sample paragraph the way you want.
  2. Select the formatted text.
  3. Open the Styles gallery.
  4. Choose Create a Style, where available.
  5. Enter a meaningful style name.
  6. Click OK.
A custom style helps you maintain the same formatting throughout a long report or business document.

5. What are Themes?

A theme is a coordinated set of design choices that gives a document a consistent appearance.

Word themes can include:

  • Theme Colours
  • Theme Fonts
  • Theme Effects

Themes help create a consistent design across headings, text and visual elements.

6. How to Apply a Theme

  1. Open the Design tab.
  2. Click Themes.
  3. Browse the available theme designs.
  4. Select a theme.
  5. Observe how supported document elements change appearance.

You can also customize theme colours, fonts and effects from the Design tab.

7. Changing Theme Colours and Fonts

Theme Colours

Theme Colours provide a coordinated colour palette for document elements.

  1. Open the Design tab.
  2. Click Colors.
  3. Select a colour set.

Theme Fonts

Theme Fonts define coordinated heading and body font combinations.

  1. Open the Design tab.
  2. Click Fonts.
  3. Choose a font combination.

Theme Effects

Theme Effects control the visual appearance of supported objects such as shapes and SmartArt.

8. Why Styles and Themes Matter

  • Save time when formatting large documents.
  • Maintain consistent headings and paragraphs.
  • Make documents easier to navigate.
  • Support automatic Table of Contents creation.
  • Improve the professional appearance of reports.
  • Make global formatting changes easier.
Important: Heading styles are especially useful when creating an automatic Table of Contents. We will explore that in Lesson 20.

9. Practical Activity

Create a document named Styles-Themes-Practice.docx.

  1. Write a title: MY COMPUTER LEARNING JOURNEY.
  2. Add three main headings.
  3. Apply Heading 1 to the main headings.
  4. Add two subheadings under each main heading.
  5. Apply Heading 2 to the subheadings.
  6. Apply a suitable document theme.
  7. Change theme colours.
  8. Modify one heading style.
  9. Save your document.
