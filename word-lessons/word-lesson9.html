Lesson 9 of 25 | Line Spacing and Indentation

🎯 Learning Objectives

In this lesson, you will learn how to control the space between lines and paragraphs and how to adjust paragraph indentation.

  • Understand line spacing.
  • Change spacing before and after paragraphs.
  • Use first-line and hanging indentation.
  • Adjust left and right indentation.
  • Use the ruler and Paragraph dialog box.

1. What is Line Spacing?

Line spacing is the vertical distance between two lines of text in a paragraph. Proper line spacing makes a document easier to read.

Common Line Spacing Options

  • Single (1.0): Normal, compact spacing.
  • 1.15: Slightly more space than single spacing.
  • 1.5: More space between lines, useful for assignments.
  • Double (2.0): Large spacing, often used for academic documents.
  • Multiple: Allows custom line spacing values.
Remember: Line spacing changes the distance between lines, not the size of the text.

2. How to Change Line Spacing

  1. Select the paragraph or text.
  2. Open the Home tab.
  3. Find the Paragraph group.
  4. Click Line and Paragraph Spacing.
  5. Choose 1.0, 1.15, 1.5 or 2.0.
Example: Select an assignment paragraph and choose 1.5 spacing to make it more readable.

3. Spacing Before and After Paragraphs

Paragraph spacing controls the extra space before or after a paragraph.

  • Before: Adds space above a paragraph.
  • After: Adds space below a paragraph.

Steps

  1. Select the paragraph.
  2. Open the Home tab.
  3. In the Paragraph group, open the dialog box launcher.
  4. Find the Spacing section.
  5. Set Before and After values.
  6. Click OK.
Tip: Use paragraph spacing instead of pressing Enter repeatedly to create gaps between paragraphs.

4. What is Indentation?

Indentation is the distance between a paragraph and the page margins. It changes where a paragraph begins or ends.

Types of Indentation

  • Left Indent: Moves the entire paragraph away from the left margin.
  • Right Indent: Moves the paragraph away from the right margin.
  • First Line Indent: Moves only the first line inward.
  • Hanging Indent: Keeps the first line at the margin while the remaining lines move inward.

5. Using the Ruler

The horizontal ruler helps you adjust indentation visually.

  1. Open the View tab.
  2. Tick the Ruler option.
  3. Select the paragraph.
  4. Use the small markers on the left side of the ruler to adjust first-line and hanging indentation.
  5. Drag the left and right indent markers to change paragraph boundaries.
The ruler is especially useful when formatting reports, assignments and professional documents.

6. Practical Activity

Open Microsoft Word and create a document using the following instructions:

  1. Type a paragraph about your favourite subject.
  2. Set line spacing to 1.5.
  3. Set 6 pt spacing after the paragraph.
  4. Apply a first-line indent.
  5. Write another paragraph and apply a hanging indent.
  6. Save the document as Spacing-Practice.docx.
