Hyperlinks and Bookmarks

Learn how to connect documents to websites, email addresses and specific locations within a document.

1. What is a Hyperlink?

A hyperlink is a clickable text or object that takes the reader to another location. It can connect to a website, an email address, another file or a specific place inside the same document.

Common types of hyperlinks

  • Web hyperlink: Opens a website in a browser.
  • Email hyperlink: Opens an email application with an email address.
  • Document hyperlink: Opens another file or document.
  • Internal hyperlink: Takes the reader to a heading or bookmark inside the same document.
Example: A resume may contain a clickable portfolio link so an employer can view your work.

2. How to Insert a Hyperlink

  1. Select the text or object you want to make clickable.
  2. Open the Insert tab.
  3. Click Link or Hyperlink, depending on your Word version.
  4. Choose the link destination.
  5. Enter the web address or select the required file or location.
  6. Click OK or Insert to create the hyperlink.
Shortcut: Select the text and press Ctrl + K to open the Insert Hyperlink dialog.

3. How to Edit or Remove a Hyperlink

Edit a hyperlink

  1. Right-click the linked text.
  2. Select Edit Hyperlink.
  3. Change the destination or displayed text.
  4. Click OK to save the changes.

Remove a hyperlink

  1. Right-click the linked text.
  2. Select Remove Hyperlink.
  3. The text remains in the document, but the clickable link is removed.
Remember: Removing a hyperlink does not normally delete the text itself.

4. What is a Bookmark?

A bookmark is a named location inside a Word document. It helps you mark a particular position so you can return to it quickly or create a link to it.

Bookmarks are especially useful in long reports, books, manuals and project documents.

Example: In a 50-page report, you can create a bookmark called "Conclusion" and quickly return to that section.

5. How to Insert a Bookmark

  1. Open your Word document.
  2. Select the text or place the cursor at the location you want to mark.
  3. Go to the Insert tab.
  4. Click Bookmark.
  5. Enter a bookmark name without spaces.
  6. Click Add.
Example bookmark names:
Introduction
Chapter1
Conclusion2026
Important: Bookmark names should begin with a letter, should not contain spaces and must be unique within the document.

6. How to Go to a Bookmark

  1. Open the Insert tab and select Bookmark.
  2. Select the bookmark name from the list.
  3. Click Go To.
  4. Word moves to the selected location.

You can also use the Go To feature through Ctrl + G and select Bookmark if that option is available in your Word version.

7. Linking to a Bookmark

You can create a hyperlink that takes the reader directly to a bookmark in the same document.

  1. First, create a bookmark in the document.
  2. Select the text that will act as the link.
  3. Press Ctrl + K.
  4. Choose the option for a place in this document.
  5. Select the required heading or bookmark.
  6. Click OK.
Practical Use: A table of contents can contain links that take readers directly to different sections of a document.

8. Practical Activity

Create a document with these three headings:

1. Introduction
2. My Skills
3. Conclusion

Now perform these tasks:

  1. Write a short paragraph below each heading.
  2. Select the text "Visit SkillSaathi".
  3. Press Ctrl + K and insert your website link.
  4. Create a bookmark named "MySkills" at the My Skills section.
  5. Insert another text called "Go to My Skills".
  6. Make it a hyperlink to the MySkills bookmark.
  7. Test both hyperlinks.
Learning Goal: Learn to connect information and navigate long documents using hyperlinks and bookmarks.
