LESSON 05 · WORD FUNDAMENTALS

Cut, Copy, Paste and Undo/Redo

Learn how to move, duplicate and restore content in Microsoft Word using simple commands and keyboard shortcuts.

1. Introduction

Microsoft Word provides useful editing commands that help you manage document content quickly.

Cut, Copy and Paste are used to move or duplicate content. Undo and Redo help reverse or restore actions.

Remember: These commands save time and make document editing easier.

2. Cut Command

The Cut command removes selected content from its current position and places it temporarily on the Clipboard.

Steps to Cut Text

  1. Select the text you want to move.
  2. Go to the Home tab.
  3. Click Cut in the Clipboard group.
  4. Place the cursor at the new location.
  5. Click Paste.
Shortcut: Ctrl + X

3. Copy Command

The Copy command creates a duplicate of selected content without removing the original content.

Steps to Copy Text

  1. Select the required text.
  2. Click Copy on the Home tab.
  3. Move the cursor to the destination.
  4. Click Paste.
Shortcut: Ctrl + C

4. Paste Command

The Paste command inserts content stored on the Clipboard into your document.

Steps to Paste

  1. Cut or copy some text.
  2. Place the cursor where you want the content.
  3. Use the Paste command.
Shortcut: Ctrl + V

Depending on the content and Word version, Paste options may let you keep source formatting, merge formatting or paste text only.

5. Understanding the Clipboard

The Clipboard temporarily stores content that you cut or copy.

  • It helps transfer content between locations.
  • You can paste copied content in another place.
  • Office Clipboard may retain multiple copied items, depending on the version and settings.
Example: Copy a paragraph from one document and paste it into another document.

6. Undo Command

Undo reverses the most recent action. It is useful when you accidentally delete text, apply unwanted formatting or make another mistake.

How to Use Undo

  1. Make a change in your document.
  2. Click Undo on the Quick Access Toolbar or use the keyboard shortcut.
  3. Your recent action will be reversed.
Shortcut: Ctrl + Z

7. Redo Command

Redo restores an action that you previously reversed using Undo.

How to Use Redo

  1. First perform an action.
  2. Use Undo to reverse it.
  3. Use Redo to restore the action.
Common Shortcut: Ctrl + Y

Some Word versions also support Ctrl + Shift + Z for Redo.

8. Difference Between These Commands

  • Cut: Removes selected content from its original position.
  • Copy: Creates a duplicate of selected content.
  • Paste: Inserts Clipboard content.
  • Undo: Reverses a recent action.
  • Redo: Restores an undone action.

9. Practical Activity

Open a blank Word document and type:

Microsoft Word is useful.
I am learning document editing.
Practice makes learning easier.
  1. Select the first sentence and copy it.
  2. Paste the copied sentence at the end.
  3. Select the second sentence and cut it.
  4. Paste it below the third sentence.
  5. Press Ctrl + Z to undo the last action.
  6. Press Ctrl + Y to redo it.
Learning Goal: Use all five commands confidently without losing your original content.
