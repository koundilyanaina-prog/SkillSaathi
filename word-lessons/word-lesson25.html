LESSON 25 · FINAL ASSESSMENT

Final Review and Practical Assessment

Review your Microsoft Word skills and complete practical tasks to demonstrate what you have learned throughout the course.

1. Course Revision – Word Fundamentals

  • Microsoft Word is used to create, edit and format documents.
  • The Ribbon contains tabs such as Home, Insert, Layout, References, Review and View.
  • Documents can be created, opened and saved in different formats.
  • Text can be selected, edited, copied, moved and formatted.
  • Paragraph settings control alignment, spacing and indentation.
Useful shortcuts:
Ctrl + N – New document
Ctrl + O – Open document
Ctrl + S – Save document
Ctrl + C – Copy
Ctrl + V – Paste
Ctrl + X – Cut
Ctrl + Z – Undo
Ctrl + Y – Redo

2. Course Revision – Formatting and Design

  • Use bullets and numbering to organize information.
  • Set margins, orientation and paper size through Layout tools.
  • Add borders, colours, headers, footers and page numbers.
  • Insert tables, pictures, shapes and text boxes.
  • Use columns, page breaks and section breaks to organize pages.
  • Apply styles and themes for consistent formatting.

3. Course Revision – Advanced Word Skills

  • Use Find and Replace to locate and change text.
  • Insert hyperlinks and bookmarks for navigation.
  • Create a Table of Contents using heading styles.
  • Add citations, footnotes and bibliographies when required.
  • Use spelling, grammar, comments and Track Changes tools.
  • Create personalized letters using Mail Merge.
  • Use templates for professional documents.
  • Print documents and export them as PDF files.

4. Practical Assessment – Create a Professional Resume

Task: Create a one or two-page professional resume in Microsoft Word.

Your resume must contain:

  1. Your full name and contact information.
  2. A short professional profile or career objective.
  3. Education details in a neat table or structured layout.
  4. Technical and personal skills.
  5. Work experience or relevant projects, if applicable.
  6. Consistent headings, font styles and spacing.
  7. Page numbers if the resume has more than one page.

Final steps

  1. Proofread the resume.
  2. Check page layout and alignment.
  3. Save the editable file as My_Resume.docx.
  4. Export a copy as My_Resume.pdf.
Assessment Goal: Demonstrate your ability to create and format a professional document independently.

5. Practical Assessment – Create a Short Report

Task: Create a report on the topic "Importance of Digital Education".

  1. Add a title page with the report title and your details.
  2. Write sections for Introduction, Benefits, Challenges and Conclusion.
  3. Apply Heading 1 and Heading 2 styles appropriately.
  4. Insert an automatic Table of Contents.
  5. Add at least one relevant picture.
  6. Insert page numbers and a header or footer.
  7. Add a citation for a source you actually used.
  8. Export the final report as a PDF.
