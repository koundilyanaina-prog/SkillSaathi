Printing, Exporting and PDF

Learn how to prepare documents for printing and export them into PDF format for sharing.

1. Preparing a Document for Printing

Before printing a document, review its content, layout and page settings. A well-prepared document reduces printing mistakes and paper waste.

  • Check spelling and grammar.
  • Review margins and page orientation.
  • Confirm page size and page numbers.
  • Check headers, footers, tables and images.
  • Remove unnecessary blank pages.
  • Preview the final document before printing.
Remember: Always check the Print Preview before sending a document to the printer.

2. How to Open Print Settings

  1. Open your Word document.
  2. Click File.
  3. Select Print.
  4. Choose the available printer.
  5. Set the number of copies.
  6. Choose which pages to print.
  7. Review the preview and click Print.
Shortcut: Press Ctrl + P to open the Print screen.

3. Important Printing Options

Copies

Choose how many copies of the document you want to print.

Page Range

Print all pages, the current page or a selected range, depending on the available options.

One-sided or Two-sided

Choose whether to print on one side or both sides of the paper. Two-sided printing depends on printer support.

Orientation

Choose Portrait or Landscape according to the document layout.

Paper Size

Select a supported paper size, such as A4 or Letter.

4. What is a PDF?

PDF stands for Portable Document Format. It is widely used to share documents while preserving their layout across different devices and platforms.

  • PDF files are convenient for sharing.
  • They generally preserve fonts, images and page layout.
  • They are useful for resumes, reports, forms and official documents.
  • They can be opened using many PDF reader applications and web browsers.

5. How to Save or Export a Word Document as PDF

Method 1: Save As

  1. Open File and select Save As.
  2. Choose a folder for the file.
  3. Enter the file name.
  4. Choose PDF from the file type list.
  5. Click Save.

Method 2: Export

  1. Open the File menu.
  2. Select Export, if available.
  3. Choose Create PDF/XPS Document.
  4. Select the destination folder.
  5. Click Publish.
Note: The exact options may differ depending on your Word version.

6. Word Format vs PDF Format

Word Document (.docx)
Best for editing, updating and collaborating on document content.

PDF Document (.pdf)
Best for sharing a finished document while preserving its appearance.

7. Practical Activity

Use your resume or another completed document for this activity.

  1. Open the document in Microsoft Word.
  2. Check its spelling, margins and page layout.
  3. Press Ctrl + P and inspect Print Preview.
  4. Check the page range and orientation.
  5. Return to the document without printing.
  6. Use Save As to export it as a PDF.
  7. Open the PDF and check that the layout is correct.
Learning Goal: Prepare a document for printing and create a shareable PDF copy.
