LESSON 01 · WORD FUNDAMENTALS

Introduction to Microsoft Word

Understand what Microsoft Word is, why it is used, and how it helps us create professional documents.

1. What is Microsoft Word?

Microsoft Word is a word-processing application developed by Microsoft. It is used to create, edit, format, save and print text-based documents.

It allows users to prepare letters, resumes, reports, assignments, notices, applications and many other types of documents.

Remember: Microsoft Word is mainly used for creating and managing text documents.

2. Why Do We Use Microsoft Word?

  • To write letters and applications.
  • To create professional resumes and CVs.
  • To prepare school and college assignments.
  • To create reports and business documents.
  • To format text using different fonts, sizes and colours.
  • To insert tables, pictures, shapes and other elements.
  • To save, print and share documents.

3. Important Features of Microsoft Word

Text Formatting

Change font style, size, colour and appearance of text.

Paragraph Formatting

Control alignment, spacing, indentation and paragraph layout.

Insert Tools

Add pictures, tables, shapes, charts and other objects.

Spell Check

Identify spelling and grammar mistakes in a document.

Page Layout

Adjust margins, page orientation, size and page borders.

Save and Export

Save documents in Word format or export them as PDF files.

4. Where is Microsoft Word Used?

Education: Assignments, notes, projects and question papers.
Office: Reports, official letters, meeting documents and notices.
Business: Invoices, proposals, business letters and documentation.
Personal Use: Resumes, applications, invitations and personal notes.

5. Practical Understanding

Imagine you want to apply for a job. You need to create a professional resume.

Using Microsoft Word, you can:

  • Write your name and contact information.
  • Add your education and skills.
  • Format headings and paragraphs.
  • Insert lines, tables or other design elements.
  • Save the resume and export it as a PDF.
