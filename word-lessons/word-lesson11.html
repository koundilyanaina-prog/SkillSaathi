Lesson 11 of 25 | Page Borders and Page Background

🎯 Learning Objectives

In this lesson, you will learn how to make Word documents visually attractive using page borders, colours and watermarks.

  • Understand page borders.
  • Apply different border styles.
  • Change page background colour.
  • Add a watermark.
  • Remove or customize page backgrounds.

1. What are Page Borders?

A page border is a decorative or simple line placed around the edges of a document page.

Page borders can make certificates, invitations, assignments and reports look more professional.

Common Border Settings

  • None: Removes the page border.
  • Box: Adds a border around all four sides.
  • Shadow: Adds a shadow effect to the border.
  • 3-D: Creates a three-dimensional border effect.
  • Custom: Allows you to select individual sides.

2. How to Apply a Page Border

  1. Open your Word document.
  2. Go to the Design tab.
  3. Click Page Borders in the Page Background group.
  4. Choose the required border setting.
  5. Select the border style, colour and width.
  6. Choose whether the border applies to the whole document or a section, where available.
  7. Click OK.
Note: In some older versions of Word, Page Borders may appear under the Page Layout tab.

3. Border Style, Colour and Width

You can customize the appearance of your page border.

  • Style: Select solid, dotted, dashed or double lines.
  • Colour: Choose a colour for the border.
  • Width: Change how thick the border appears.
  • Art: Use decorative designs in versions that support this option.
Example: A certificate may use a double-line golden border, while a school assignment may use a simple black border.

4. Page Background Colour

Page Colour changes the background colour of the document page.

Steps to Change Page Colour

  1. Open the Design tab.
  2. Click Page Color.
  3. Choose a colour from the palette.
  4. Use More Colors if you need a custom colour.
  5. Choose No Color to remove the background colour.
Important: A coloured page background may not print unless the relevant background printing setting is enabled. Always check Print Preview.

5. What is a Watermark?

A watermark is faint text or an image displayed behind the main document content.

Common examples include:

  • CONFIDENTIAL
  • DRAFT
  • SAMPLE
  • COMPANY NAME

How to Insert a Watermark

  1. Open the Design tab.
  2. Click Watermark.
  3. Select a ready-made watermark or choose Custom Watermark.
  4. Choose Text Watermark or Picture Watermark.
  5. Customize the text, font, size, colour or image.
  6. Apply the watermark.

6. Remove a Border or Watermark

Remove Page Border

  1. Go to Design → Page Borders.
  2. Select None.
  3. Click OK.

Remove Watermark

  1. Go to Design → Watermark.
  2. Select Remove Watermark.

Remove Page Colour

  1. Go to Design → Page Color.
  2. Select No Color.

7. Practical Activity

Create a document named Page-Design-Practice.docx.

  1. Type a heading: MY LEARNING JOURNEY.
  2. Write a short paragraph about yourself.
  3. Apply a box-style page border.
  4. Change the border colour to dark blue.
  5. Set a light page background colour.
  6. Add a DRAFT watermark.
  7. Save your document.
