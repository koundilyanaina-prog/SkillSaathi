LESSON 03 · WORD FUNDAMENTALS

Creating, Opening and Saving Documents

Learn how to create new Word documents, open existing files and save your work safely.

1. What is a Word Document?

A Word document is a digital file created using Microsoft Word. It can contain text, images, tables, shapes and other information.

The commonly used Word document extension is .docx.

Remember: A document is your digital workspace where you create and organize information.

2. Creating a New Document

You can create a new document whenever you want to start fresh.

Method 1: Using the Start Screen

  1. Open Microsoft Word.
  2. Choose Blank Document.
  3. A new empty page will appear.
  4. Start typing your content.

Method 2: Using the File Menu

  1. Open an existing Word window.
  2. Click the File tab.
  3. Select New.
  4. Choose Blank Document.

Keyboard Shortcut

Press Ctrl + N to create a new document.

3. Opening an Existing Document

If you have already created and saved a document, you can open it again to continue working.

Steps to Open a Document

  1. Open Microsoft Word.
  2. Click File.
  3. Select Open.
  4. Choose Recent Documents or Browse.
  5. Locate your file and select it.
  6. Click Open.
Shortcut: Press Ctrl + O to open a document.

4. Saving a Document

Saving stores your document so you can access it later. It is important to save your work regularly.

Steps to Save for the First Time

  1. Click the File tab.
  2. Select Save As.
  3. Choose Browse or a suitable storage location.
  4. Enter a meaningful file name.
  5. Choose the required file type.
  6. Click Save.
Example File Name: My_First_Document.docx

5. Save vs Save As

Save

Save updates the existing file with your latest changes.

Save As

Save As allows you to create a new copy, choose another name, location or file format.

Example: You have a file named Resume.docx. Using Save updates that file. Using Save As, you can create another file named Updated_Resume.docx.

6. Common Word File Formats

  • .docx: Standard modern Word document format.
  • .doc: Older Word document format.
  • .pdf: Portable format useful for sharing and printing.
  • .txt: Plain text format without most formatting.
  • .rtf: Rich Text Format, which supports basic formatting.

The format you choose depends on how you plan to use or share the document.

7. AutoSave and AutoRecover

AutoSave

AutoSave can automatically save changes to supported files stored in OneDrive or SharePoint, when the feature is enabled.

AutoRecover

AutoRecover helps recover unsaved work after certain unexpected closures or crashes. Its availability and settings depend on your Word version.

Important: AutoRecover is not a replacement for saving your document regularly.

8. Practical Activity

Let's create and save your first document.

  1. Open Microsoft Word.
  2. Create a Blank Document.
  3. Type the heading: My First Word Document.
  4. Write your name and today's date.
  5. Save the document as My_First_Word_Document.docx.
  6. Close the document and open it again.
Learning Goal: You should be able to create, save and reopen your own Word document without help.
