Lesson 13 of 25 | Working with Tables

🎯 Learning Objectives

In this lesson, you will learn how to create, edit and format tables in Microsoft Word.

  • Understand rows, columns and cells.
  • Insert a table.
  • Add and delete rows and columns.
  • Merge and split cells.
  • Format tables professionally.
  • Use tables to organize information.

1. What is a Table?

A table is a structure used to organize information into rows and columns.

  • Row: A horizontal line of cells.
  • Column: A vertical arrangement of cells.
  • Cell: The individual box where data is entered.
Example: Student Marks Table
NameSubjectMarks
RahulEnglish85
PriyaMaths92
AmanScience78

2. How to Insert a Table

  1. Open your Word document.
  2. Go to the Insert tab.
  3. Click Table.
  4. Move your mouse over the grid to select the number of rows and columns.
  5. Click to insert the table.
  6. Enter your information into the cells.

Other Insertion Options

  • Insert Table: Enter the exact number of rows and columns.
  • Draw Table: Draw table boundaries manually.
  • Convert Text to Table: Turn selected, properly separated text into a table.

3. Adding and Deleting Rows or Columns

You can change the structure of a table whenever required.

To Add a Row or Column

  1. Click inside a table cell.
  2. Open the Table Layout tab.
  3. Choose Insert Above, Insert Below, Insert Left or Insert Right.

To Delete a Row or Column

  1. Select the required row or column.
  2. Open the Table Layout tab.
  3. Click Delete.
  4. Choose Delete Rows, Delete Columns or another suitable option.

4. Merging and Splitting Cells

Merge Cells

Merging combines two or more selected cells into one larger cell.

  1. Select the cells you want to combine.
  2. Open the Table Layout tab.
  3. Click Merge Cells.

Split Cells

Splitting divides one cell into multiple rows or columns.

  1. Select the cell.
  2. Open the Table Layout tab.
  3. Click Split Cells.
  4. Enter the required number of rows and columns.
  5. Click OK.
Tip: A merged cell is useful for creating a heading across multiple columns.

5. Formatting a Table

Word provides tools to improve the appearance of tables.

  • Table Styles: Apply ready-made designs.
  • Shading: Add background colours to cells.
  • Borders: Add or remove table lines.
  • Alignment: Align text inside cells.
  • Cell Size: Adjust row height and column width.
  • Text Direction: Change the direction of text inside a cell.

How to Apply a Table Style

  1. Click anywhere inside the table.
  2. Open the Table Design tab.
  3. Select a style from the Table Styles gallery.
  4. Customize borders and shading if required.

6. Sorting and Repeating Header Rows

Sorting Data

You can arrange table data alphabetically or numerically.

  1. Select the table or relevant column.
  2. Open Table Layout.
  3. Click Sort.
  4. Choose the column and sorting order.
  5. Click OK.

Repeating Header Rows

For tables that continue across multiple pages, you can repeat the heading row at the top of each page.

  1. Select the table's header row.
  2. Open Table Layout.
  3. Click Repeat Header Rows.

7. Practical Activity

Create a file named Student-Marks-Table.docx.

  1. Insert a table with 4 columns and 6 rows.
  2. Add headings: Roll No., Name, Subject and Marks.
  3. Enter information for five students.
  4. Apply a professional table style.
  5. Make the heading row bold.
  6. Change the heading row background colour.
  7. Adjust column widths.
