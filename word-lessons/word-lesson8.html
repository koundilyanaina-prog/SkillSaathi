Bullets and Numbering

Learn how to organize information into clear lists using bullets, numbers and multilevel numbering.

1. What are Bullets and Numbering?

Bullets and Numbering are list-formatting features in Microsoft Word. They help present information in an organized and readable way.

Instead of writing long paragraphs, you can divide information into separate list items.

Remember: Bullets are useful for unordered lists, while numbering is useful when the sequence or order matters.

2. What are Bulleted Lists?

A bulleted list uses symbols such as dots, circles or squares to identify each item.

Example

  • Microsoft Word
  • Microsoft Excel
  • Microsoft PowerPoint
  • Microsoft Outlook

Use bullets when the listed items do not need to follow a particular order.

Steps to Create a Bulleted List

  1. Open a Word document.
  2. Go to the Home tab.
  3. Find the Paragraph group.
  4. Click the Bullets button.
  5. Type your first item and press Enter for the next item.

3. Changing Bullet Styles

Microsoft Word offers different bullet symbols.

You can choose from options such as:

  • Filled round bullets
  • Hollow round bullets
  • Square bullets
  • Custom symbols

Steps

  1. Click the dropdown arrow next to the Bullets button.
  2. Select a bullet style from the available options.
  3. To create a custom style, choose Define New Bullet if available.
  4. Select a symbol or picture and confirm.

4. What are Numbered Lists?

A numbered list uses numbers or letters to arrange information in a specific sequence.

Example

  1. Open Microsoft Word.
  2. Create a new document.
  3. Type your content.
  4. Save your document.

Numbered lists are especially useful for instructions, procedures and step-by-step guides.

Steps to Create a Numbered List

  1. Open the Home tab.
  2. Locate the Paragraph group.
  3. Click the Numbering button.
  4. Type your first item.
  5. Press Enter to create the next numbered item.

5. Different Numbering Styles

Word provides multiple numbering formats.

Numbers:

  1. First Item
  2. Second Item
  3. Third Item

Letters:

  1. First Item
  2. Second Item
  3. Third Item

Roman Numerals:

  1. First Item
  2. Second Item
  3. Third Item

Choose the Numbering dropdown to select the style you need.

6. Multilevel Lists

A multilevel list organizes information into main points and subpoints.

Example

  1. Computer Skills
    • Microsoft Word
    • Microsoft Excel
  2. Creative Skills
    • Graphic Design
    • Content Writing

How to Create a Sublevel

  1. Create a numbered or bulleted list.
  2. Press Enter to create the next item.
  3. Press Tab to move the item to a lower level.
  4. Use Shift + Tab to move it back to the previous level.
You can also use the Increase Indent and Decrease Indent commands to adjust list levels.

7. Continuing and Restarting Numbering

Sometimes a numbered list needs to continue from a previous list or start again from the beginning.

Continue Numbering

Use Continue Numbering when you want a list to continue its earlier sequence.

Restart at 1

Use Restart at 1 when you want a new list to begin again from number one.

Right-click a numbered list item to find relevant numbering options in supported Word versions.

8. Removing Bullets and Numbering

You can remove list formatting whenever it is no longer required.

  1. Select the list items.
  2. Open the Home tab.
  3. Click the Bullets or Numbering button to turn off that list formatting.

The content remains in the document, but the list markers are removed.
