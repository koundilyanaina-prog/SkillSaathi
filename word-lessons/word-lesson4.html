LESSON 04 · WORD FUNDAMENTALS

Typing, Selecting and Editing Text

Learn how to enter text, move the cursor, select words and paragraphs, and make changes to document content.

1. Typing Text in Microsoft Word

Typing is the process of entering letters, numbers and symbols into a document using a keyboard.

  1. Open a blank Word document.
  2. Click inside the Document Area.
  3. Start typing using your keyboard.
  4. Press Enter when you want to start a new paragraph.
Remember: Word automatically moves text to the next line when the current line becomes full. You generally do not need to press Enter at the end of every line.

2. Understanding the Cursor

The cursor, also called the insertion point, shows where the next character will appear when you type.

Moving the Cursor

  • Use the Left Arrow and Right Arrow keys to move character by character.
  • Use the Up Arrow and Down Arrow keys to move between lines.
  • Click anywhere in the text to position the cursor there.
  • Press Home to move to the beginning of a line.
  • Press End to move to the end of a line.

3. Selecting Text

Selecting text means highlighting a part of your document so that you can edit, delete, copy or format it.

Selecting with the Mouse

  1. Place your mouse pointer before the text.
  2. Hold the left mouse button.
  3. Drag across the text you want to select.
  4. Release the mouse button.

Selecting with the Keyboard

Hold the Shift key and use the arrow keys to extend your selection.

Selecting the Entire Document

Press Ctrl + A to select all content in the document.

4. Selecting Words, Lines and Paragraphs

  • A word: Double-click a word to select it.
  • A sentence: Use the mouse to drag across the sentence.
  • A line: Click and drag across the required line.
  • A paragraph: Select the paragraph by dragging across its content.
  • Entire document: Use Ctrl + A.
Tip: Selecting the correct amount of text before editing helps prevent accidental changes.

5. Editing Text

Editing means changing existing content to improve or correct it.

Inserting Text

Click at the required position and start typing. New characters will appear at the cursor position.

Deleting Text

  • Backspace: Deletes the character to the left of the cursor.
  • Delete: Deletes the character to the right of the cursor.

Replacing Text

Select the text you want to replace and type the new content.

Example:
Original: I am learning Excell.
Corrected: I am learning Excel.

6. Important Keyboard Keys

  • Enter: Starts a new paragraph.
  • Spacebar: Inserts a space between words.
  • Backspace: Deletes the previous character.
  • Delete: Deletes the next character.
  • Shift: Helps select text and type capital letters.
  • Caps Lock: Toggles uppercase typing.
  • Tab: Inserts a tab space or moves to the next cell in a table.
  • Arrow Keys: Move the cursor.

7. Useful Text Selection Shortcuts

  • Ctrl + A — Select all content.
  • Shift + ← — Select one character to the left.
  • Shift + → — Select one character to the right.
  • Ctrl + Shift + → — Select the next word.
  • Ctrl + Shift + ← — Select the previous word.
  • Home — Move to the beginning of the line.
  • End — Move to the end of the line.

8. Practical Activity

Practice typing, selecting and editing text in a blank Word document.

Step 1: Type This Paragraph

Microsoft Word is a useful application for creating documents. It helps students and professionals prepare letters, reports and assignments. Learning Word improves our computer skills.

Step 2: Perform These Tasks

  1. Select the word "useful".
  2. Move the cursor to the end of the paragraph.
  3. Add the sentence: "I am learning Microsoft Word."
  4. Correct any spelling mistake you intentionally create.
  5. Use Ctrl + A to select the complete document.
Learning Goal: You should be able to type, select, insert, replace and delete text confidently.
