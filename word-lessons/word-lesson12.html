Lesson 12 of 25 | Headers, Footers and Page Numbers

🎯 Learning Objectives

In this lesson, you will learn how to add repeating information at the top and bottom of document pages.

  • Understand headers and footers.
  • Insert and edit a header.
  • Insert and edit a footer.
  • Add and format page numbers.
  • Use different first-page and odd/even page settings.

1. What is a Header?

A header is the area at the top of a document page, above the main body text.

It can contain information that you want to display on multiple pages.

Common Header Content

  • Document title
  • Company or institution name
  • Chapter name
  • Logo or other small image
  • Date or author name
Example: A school report can display the school name in the header of every page.

2. How to Insert a Header

  1. Open your Word document.
  2. Go to the Insert tab.
  3. Click Header in the Header & Footer group.
  4. Choose a built-in header style.
  5. Type your required information.
  6. Click Close Header and Footer or double-click in the main document area.
You can also double-click near the top margin of a page to open the header editing area.

3. What is a Footer?

A footer is the area at the bottom of a document page, below the main body text.

Common Footer Content

  • Page numbers
  • Copyright information
  • Document version
  • Website address
  • Contact details

How to Insert a Footer

  1. Open the Insert tab.
  2. Click Footer.
  3. Choose a footer design.
  4. Enter the required information.
  5. Close Header and Footer.

4. Adding Page Numbers

Page numbers help readers navigate long documents and find information easily.

Steps to Insert Page Numbers

  1. Open the Insert tab.
  2. Click Page Number.
  3. Choose where the number should appear.
  4. Select a style.
  5. Close Header and Footer.

Common Page Number Positions

  • Top of Page
  • Bottom of Page
  • Page Margins
  • Current Position

5. Formatting Page Numbers

Word allows you to customize the page numbering format.

  1. Go to Insert → Page Number.
  2. Choose Format Page Numbers.
  3. Select a number format, such as 1, 2, 3 or i, ii, iii.
  4. Choose whether numbering starts at a particular number.
  5. Click OK.
For many reports, page numbering starts from 1. Some academic documents use Roman numerals for introductory pages.

6. Different First Page

Sometimes the first page of a document, such as a title page, should not display the same header or footer as the other pages.

How to Use Different First Page

  1. Double-click inside the header or footer area.
  2. Open the Header & Footer tab.
  3. Select Different First Page.
  4. Edit the first-page header or footer separately.

This option is useful for reports, projects and professional documents with a cover page.

7. Different Odd and Even Pages

Word can display different headers and footers on odd-numbered and even-numbered pages.

  1. Open the header or footer editing area.
  2. Go to the Header & Footer tab.
  3. Select Different Odd & Even Pages.
  4. Enter separate content for odd and even pages.
Example: A printed book may show the book title on left pages and the chapter title on right pages.

8. Removing Headers, Footers and Page Numbers

  • Remove Header: Insert → Header → Remove Header.
  • Remove Footer: Insert → Footer → Remove Footer.
  • Remove Page Numbers: Insert → Page Number → Remove Page Numbers.

Menu names and positions may vary slightly between Word versions.

9. Practical Activity

Create a three-page document named Header-Footer-Practice.docx.

  1. Write a short report on computer education.
  2. Add the heading SKILLSAATHI in the header.
  3. Add your name in the footer.
  4. Insert page numbers at the bottom of each page.
  5. Enable Different First Page.
  6. Check that the page numbers appear correctly.
  7. Save your document.
