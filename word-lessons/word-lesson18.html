LESSON 18 · ADVANCED WORD SKILLS

Find, Replace and Navigation

Learn how to quickly locate words, replace text and move through long Word documents efficiently.

1. What is Find?

The Find feature helps you search for a particular word, phrase or text inside a document. Instead of reading every page, you can locate the required text quickly.

How to use Find

  1. Open your Word document.
  2. Go to the Home tab.
  3. Click Find in the Editing group.
  4. Type the word or phrase you want to search.
  5. Word highlights the matching results.
Shortcut: Press Ctrl + F to open the Navigation Pane and search your document.

2. What is Replace?

The Replace feature allows you to change a word or phrase throughout a document without editing every occurrence manually.

How to use Replace

  1. Open the Home tab.
  2. Click Replace in the Editing group.
  3. Enter the existing word in the Find what box.
  4. Enter the new word in the Replace with box.
  5. Click Replace to change one occurrence.
  6. Click Replace All to change all matching occurrences.
Example:
Find what: Student
Replace with: Learner

Using Replace All changes every matching occurrence of "Student" to "Learner".
Important: Always review your document after using Replace All. A word may appear in a context where replacing it is not appropriate.

3. Understanding the Navigation Pane

The Navigation Pane helps you move through a document. It is especially useful when working with long reports, books or assignments.

It provides three useful views:

  • Headings: Shows document headings and helps you jump between sections.
  • Pages: Displays page thumbnails so you can move to a particular page.
  • Results: Shows matching results when you search for text.
Tip: Use properly formatted heading styles to make document navigation easier.

4. Find and Replace Options

Match Case

Finds text with the same uppercase and lowercase pattern as your search term.

Find Whole Words Only

Searches for a complete word instead of matching it as part of another word.

Replace All

Replaces all matching occurrences in the document at once.

Go To

Allows you to jump directly to a particular page, section, line or other document location, depending on the options available in your Word version.

5. Useful Keyboard Shortcuts

Ctrl + F – Find text

Ctrl + H – Open Replace

Ctrl + G – Go To

6. Practical Activity

Create a document containing the following paragraph:

SkillSaathi is a learning platform. Students can learn computer skills. Students can practise new skills and improve their knowledge. Every student can learn at their own pace.

Now perform these tasks:

  1. Press Ctrl + F and search for the word "Students".
  2. Press Ctrl + H to open Replace.
  3. Replace "Students" with "Learners".
  4. Use Replace All and review the changes.
  5. Press Ctrl + G and explore the Go To option.
Learning Goal: Understand how to find, replace and navigate text without manually searching every page.
