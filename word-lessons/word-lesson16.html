Lesson 16 of 25 | Columns, Page Breaks and Section Breaks

🎯 Learning Objectives

Learn how to organize document content into columns and control where pages and sections begin.

  • Create one, two and three-column layouts.
  • Insert and remove page breaks.
  • Understand section breaks.
  • Use different layouts in one document.
  • Understand how section formatting works.

1. What are Columns?

Columns divide text into vertical sections on a page. They are commonly used in newspapers, newsletters and magazines.

Common Column Layouts

  • One Column
  • Two Columns
  • Three Columns
  • Left
  • Right
  • More Columns for custom settings

2. How to Create Columns

  1. Select the text you want to arrange into columns. If you want the entire document, do not select any text.
  2. Open the Layout tab.
  3. Click Columns.
  4. Choose One, Two or Three.
  5. For custom settings, click More Columns.
  6. Adjust the width and spacing if required.
  7. Click OK.
Tip: Select only the required text if you want columns in one part of a document rather than the whole document. Word may use section formatting to apply the layout.

3. Column Breaks

A column break moves the text after the break to the beginning of the next column.

How to Insert a Column Break

  1. Place the cursor where the next column should begin.
  2. Open the Layout tab.
  3. Click Breaks.
  4. Select Column.

This is useful when you want a new topic to start at the top of another column.

4. What is a Page Break?

A page break forces the content after the cursor to begin on a new page.

How to Insert a Page Break

  1. Place the cursor where the new page should begin.
  2. Open the Insert tab.
  3. Click Page Break.

You can also use the keyboard shortcut Ctrl + Enter.

Important: Avoid pressing Enter repeatedly to move content to a new page. A page break keeps the layout more reliable when you edit the document.

5. Removing a Page Break

  1. Go to the Home tab.
  2. Click the Show/Hide ¶ button to display formatting marks.
  3. Find the Page Break marker.
  4. Select the marker.
  5. Press Delete or Backspace.

Be careful not to delete other content while removing breaks.

6. What is a Section Break?

A section break divides a document into separate sections. Each section can have different formatting settings.

Why Use Section Breaks?

  • Use portrait and landscape pages in one document.
  • Change margins in selected sections.
  • Use different headers and footers.
  • Change page numbering arrangements.
  • Apply columns to only one section.

7. Types of Section Breaks

  • Next Page: Starts a new section on the next page.
  • Continuous: Starts a new section on the same page.
  • Even Page: Starts the next section on the next even-numbered page.
  • Odd Page: Starts the next section on the next odd-numbered page.

How to Insert a Section Break

  1. Place the cursor where the new section should begin.
  2. Open the Layout tab.
  3. Click Breaks.
  4. Choose the required section break type.

8. Difference Between Page Break and Section Break

Page Break: Moves following content to a new page but does not create a new section.

Section Break: Divides the document into sections so that different formatting can be applied.

For example, a report may have portrait pages for most content and one landscape page for a wide table. A section break can help achieve this.

9. Practical Activity

Create a document named Page-Section-Practice.docx.

  1. Write a short article about computer education.
  2. Apply a two-column layout to the article.
  3. Insert a column break before a new topic.
  4. Insert a page break before the conclusion.
  5. Insert a Next Page section break before a new section.
  6. Change the new section to Landscape orientation.
  7. Save your document.
