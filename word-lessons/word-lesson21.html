LESSON 21 · ADVANCED WORD SKILLS

Spelling, Grammar and Review Tools

Learn how to check writing, correct errors, add comments and review changes in a Word document.

1. Why Proofreading Matters

Proofreading means checking a document for spelling, grammar, punctuation and formatting mistakes before sharing or printing it.

A well-reviewed document is easier to understand and looks more professional.

Remember: Automatic suggestions are helpful, but you should always read your document yourself before finalizing it.

2. Spelling and Grammar Check

Microsoft Word can identify possible spelling and grammar issues and suggest corrections.

How to check spelling and grammar

  1. Open your document.
  2. Select the Review tab.
  3. Choose Editor or Spelling & Grammar, depending on your Word version.
  4. Review each suggested correction.
  5. Accept a suggestion or ignore it when it is not appropriate.
Shortcut: Press F7 to start spelling and grammar checking in many desktop versions of Word.

3. AutoCorrect

AutoCorrect automatically fixes certain common typing mistakes while you type.

Example:
Typing "teh" may automatically change to "the" when that correction is available in your language settings.

You can manage AutoCorrect options through Word settings. The exact location may differ between versions.

4. Comments

Comments allow reviewers to add notes or feedback without changing the main document text.

How to add a comment

  1. Select the text you want to discuss.
  2. Open the Review tab.
  3. Click New Comment.
  4. Type your feedback.
  5. Post or send the comment.

You can reply to comments, resolve them or delete them depending on your permissions and Word version.

5. Track Changes

Track Changes records edits made to a document. It helps authors and reviewers see what has been added, removed or modified.

How to use Track Changes

  1. Open the Review tab.
  2. Click Track Changes to turn it on.
  3. Edit the document.
  4. Review the marked changes.
  5. Use Accept or Reject to decide which changes to keep.
Important: Turning Track Changes off stops recording new edits, but it does not automatically accept or remove existing tracked changes.

6. Compare Documents

The Compare feature helps identify differences between two versions of a document.

  1. Open the Review tab.
  2. Select Compare.
  3. Choose the original document.
  4. Choose the revised document.
  5. Review the differences shown by Word.

This is useful when reviewing updated reports, assignments or business documents.

7. Practical Activity

Create a short document containing a paragraph about your education or career goals.

  1. Type a paragraph with a few intentional spelling mistakes.
  2. Run spelling and grammar checking using F7.
  3. Review the suggestions and correct appropriate errors.
  4. Select one sentence and add a comment.
  5. Turn on Track Changes and edit another sentence.
  6. Accept or reject the tracked edit.
Learning Goal: Practice proofreading and collaborate on documents using Word's review tools.
