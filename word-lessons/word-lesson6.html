LESSON 06 · WORD FUNDAMENTALS

Font Formatting and Text Effects

Learn how to change the appearance of text using font styles, sizes, colours and special text effects.

1. What is Font Formatting?

Font formatting means changing the visual appearance of text in a document.

It helps make headings clear, highlight important information and create professional documents.

Remember: Font formatting changes how text looks, not the actual meaning of the text.

2. Understanding the Font Group

The Font group is available on the Home tab in Microsoft Word.

It contains commonly used formatting options such as:

  • Font Name
  • Font Size
  • Bold, Italic and Underline
  • Font Colour
  • Text Highlight Colour
  • Change Case
  • Strikethrough
  • Subscript and Superscript
  • Text Effects and Typography

3. Changing the Font Type

A font is the design or style of letters and characters.

Microsoft Word provides different fonts, such as Arial, Calibri, Times New Roman and Aptos, depending on the installed version.

Steps

  1. Select the text.
  2. Open the Home tab.
  3. Find the Font Name dropdown.
  4. Choose the required font.
Example:
Arial – Clean and simple
Georgia – Traditional style
Times New Roman – Formal style

4. Changing Font Size

Font Size controls how large or small your text appears.

Steps

  1. Select the required text.
  2. Go to the Home tab.
  3. Click the Font Size box.
  4. Choose a size or type your own value.
  5. Press Enter.
Font size 13
Font size 18
Font size 26

You can also use Ctrl + Shift + > to increase font size and Ctrl + Shift + < to decrease it in many Word desktop versions.

5. Bold, Italic and Underline

Bold

Bold makes text thicker and darker. It is commonly used for headings and important words.

This text is bold.

Shortcut: Ctrl + B

Italic

Italic makes text slanted. It is often used for emphasis or titles.

This text is italic.

Shortcut: Ctrl + I

Underline

Underline adds a line beneath the selected text.

This text is underlined.

Shortcut: Ctrl + U

6. Changing Font Colour

Font Colour changes the colour of selected text.

Steps

  1. Select the text.
  2. Open the Home tab.
  3. Click the Font Colour dropdown.
  4. Choose a colour from the palette.

7. Text Highlight Colour

Text Highlight Colour places a coloured background behind selected text, similar to using a highlighter pen.

Steps

  1. Select the text.
  2. Open the Home tab.
  3. Click Text Highlight Colour.
  4. Choose the required colour.
This is highlighted text.

Use highlighting to draw attention to important information.

8. Change Case

Change Case allows you to change how letters appear without retyping the text.

  • Sentence case: Makes the beginning of a sentence uppercase.
  • lowercase: Converts all letters to lowercase.
  • UPPERCASE: Converts all letters to uppercase.
  • Capitalize Each Word: Capitalizes the first letter of each word.
  • tOGGLE cASE: Reverses the existing letter case.

Steps

  1. Select the text.
  2. Open Home tab.
  3. Click Change Case (Aa).
  4. Select the required case.
Shortcut: Shift + F3 cycles through available case options in many Word desktop versions.

10. Text Effects and Typography

Text Effects can add visual styling to selected text.

Depending on your Word version, options may include:

  • Text Outline
  • Text Shadow
  • Reflection
  • Glow

These options can be accessed through the Text Effects and Typography button in the Font group.

Design Tip: Use effects carefully. Too many decorative styles can make a document difficult to read.

11. Clear All Formatting

Clear All Formatting removes direct formatting from selected text and returns it to the document's default text appearance.

Steps

  1. Select formatted text.
  2. Open the Home tab.
  3. Click Clear All Formatting (the A with an eraser).

This is useful when text has too many unwanted formatting changes.

12. Practical Activity

Create the following content in Microsoft Word:

MY COMPUTER SKILLS

I am learning Microsoft Word.

It helps me create professional documents.

Formatting makes documents more attractive and readable.

Apply These Changes

  1. Make the main heading Bold.
  2. Set the heading size to 20.
  3. Change the heading colour to dark blue.
  4. Underline the words "Microsoft Word".
  5. Make the final sentence Italic.
  6. Highlight the word "professional".
  7. Save your document.
Learning Goal: You should be able to apply common font formatting options independently.
