Lesson 15 of 25 | Text Boxes, WordArt and SmartArt

🎯 Learning Objectives

Learn how to use visual text elements and diagrams to make Word documents more attractive and informative.

  • Insert and format text boxes.
  • Create decorative text using WordArt.
  • Understand SmartArt graphics.
  • Create process and hierarchy diagrams.
  • Arrange visual elements in a document.

1. What is a Text Box?

A text box is a separate container in which you can type and position text anywhere on a document page.

Uses of Text Boxes

  • Highlight important information.
  • Create side notes or quotations.
  • Design flyers and invitations.
  • Display contact information separately.

How to Insert a Text Box

  1. Open the Insert tab.
  2. Click Text Box.
  3. Choose a built-in design or Draw Text Box.
  4. Click and drag to draw the box if needed.
  5. Type your text inside it.

2. Formatting Text Boxes

After selecting a text box, use the Shape Format tab to customize it.

  • Shape Fill: Changes the background colour.
  • Shape Outline: Changes the border.
  • Shape Effects: Adds shadow and other effects.
  • Text Direction: Changes text orientation.
  • Position: Controls where the box appears.
  • Wrap Text: Controls how surrounding text flows.
Tip: Keep text boxes aligned and use consistent colours for professional documents.

3. What is WordArt?

WordArt is a feature used to create decorative and stylized text.

It can make headings, titles and important words stand out.

How to Insert WordArt

  1. Go to the Insert tab.
  2. Click WordArt.
  3. Choose a style from the gallery.
  4. Type your required text.
  5. Select the WordArt object to format it.

4. Formatting WordArt

WordArt can be customized using the Shape Format or WordArt Format tools.

  • Text Fill: Changes the inside colour of letters.
  • Text Outline: Adds an outline to letters.
  • Text Effects: Adds shadow, reflection and glow.
  • Transform: Changes the shape or curve of text.
  • Size: Adjusts the height and width.
Example: Use WordArt for a creative heading such as "WELCOME TO SKILLSAATHI".

5. What is SmartArt?

SmartArt is a visual tool that helps present information through diagrams instead of long paragraphs.

Common SmartArt Categories

  • List: Displays related information.
  • Process: Shows steps in a sequence.
  • Cycle: Shows repeating stages.
  • Hierarchy: Shows organizational relationships.
  • Relationship: Shows connections between ideas.
  • Matrix: Shows how parts relate to a whole.
  • Pyramid: Shows levels or proportions.

6. How to Insert SmartArt

  1. Open the Insert tab.
  2. Click SmartArt.
  3. Select a category.
  4. Choose a suitable layout.
  5. Click OK.
  6. Enter text in the text pane or directly inside the shapes.

Customizing SmartArt

  • Use SmartArt Design to change layouts and colours.
  • Use Add Shape to add more elements.
  • Use Promote and Demote to change hierarchy levels.
  • Use SmartArt Styles to apply visual designs.

7. Practical Activity

Create a document named Visual-Design-Practice.docx.

  1. Insert a text box with your name and a short introduction.
  2. Change its background colour.
  3. Insert WordArt with the title "MY SKILLS".
  4. Insert a SmartArt Process diagram.
  5. Add these steps: Learn, Practice, Improve and Grow.
  6. Customize the colours and layout.
  7. Save your document.
