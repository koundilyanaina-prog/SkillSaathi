Lesson 12: CSS Flexbox

Build flexible one-dimensional layouts with containers and items.

Learning Objectives

  • Create a flex container
  • Control direction, wrapping and alignment
  • Use justify-content and align-items
  • Use gap, flex-grow, flex-shrink and flex-basis

1. Flex container and items

Set display:flex on a parent to create a flex formatting context. Its direct children become flex items. By default, items are laid out in a row.

.container { display: flex; }
.item { padding: 20px; }

2. Direction and wrapping

flex-direction sets row, row-reverse, column or column-reverse. flex-wrap allows items to move onto multiple lines when they do not fit.

.container { display: flex; flex-direction: row; flex-wrap: wrap; }

3. Main-axis alignment

justify-content aligns items along the main axis. Common values include flex-start, center, flex-end, space-between, space-around and space-evenly. The main axis changes when flex-direction changes.

.container { display: flex; justify-content: space-between; }

4. Cross-axis alignment and gap

align-items aligns items along the cross axis. align-content controls spacing between multiple flex lines. gap adds consistent space between items without adding margins to each child.

.container { display: flex; align-items: center; gap: 16px; }

5. Flexible item sizing

flex-grow controls how extra space is distributed. flex-shrink controls how items shrink when space is limited. flex-basis sets an item's initial main size. The flex shorthand combines these values.

.item { flex: 1 1 220px; }
.featured { flex-grow: 2; }
