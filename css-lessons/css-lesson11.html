Lesson 11: Overflow and Visibility

Manage content that extends beyond an element's box.

Learning Objectives

  • Understand visible, hidden, scroll and auto overflow
  • Control horizontal and vertical overflow
  • Use text-overflow and white-space
  • Choose visibility and opacity appropriately

1. What is overflow?

Overflow happens when content is larger than the area available inside an element. The overflow property controls how extra content is displayed outside the element's padding box.

.box { width: 220px; height: 100px; overflow: visible; }

2. Visible and hidden

visible is the default and allows content to extend outside the box. hidden clips extra content and does not provide a user scrollbar. Use hidden carefully so important information is not made inaccessible.

.visible { overflow: visible; }
.clipped { overflow: hidden; }

3. Scroll and auto

scroll provides scrollbars when content overflows. auto lets the browser show scrolling when needed. You can control each axis separately with overflow-x and overflow-y.

.scroll-box { overflow: auto; max-height: 150px; }
.horizontal { overflow-x: auto; overflow-y: hidden; }

4. Text overflow

For a single-line ellipsis, combine white-space: nowrap, overflow: hidden and text-overflow: ellipsis. The element also needs a constrained width for the effect to be visible.

.title {
  width: 220px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

5. Visibility and opacity

visibility:hidden hides an element but preserves its layout space. opacity:0 makes it transparent but does not automatically remove it from keyboard navigation or pointer interaction. If content should not be available, manage its behavior and accessibility as well.

.visually-hidden { visibility: hidden; }
.faded { opacity: 0.4; }
