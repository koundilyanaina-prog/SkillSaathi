Lesson 7: CSS Box Model

Understand how content, padding, borders and margins determine element size.

Learning Objectives

  • Identify the four parts of the box model
  • Understand content-box and border-box
  • Calculate an element's total size
  • Use browser developer tools to inspect boxes

1. The four parts of the box model

Every element is represented as a rectangular box. From the inside outward, it contains content, padding, border and margin. Content holds text or media. Padding creates space around the content inside the border. Border surrounds padding and content. Margin creates space outside the border.

div {
  width: 300px;       /* content width by default */
  padding: 20px;
  border: 5px solid purple;
  margin: 15px;
}

2. Understanding content-box

The default box-sizing value is content-box. With content-box, the declared width applies only to the content. Padding and border are added to the outside width. For example, 300px width + 40px horizontal padding + 10px borders = 350px total border-box width.

/* Default behavior */
.box {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 5px solid purple;
}
/* Total outer width = 350px */

3. Understanding border-box

With border-box, the declared width includes the content, padding and border. This makes layout calculations easier and is a common project-wide setting.

*,
*::before,
*::after {
  box-sizing: border-box;
}
.box {
  width: 300px;
  padding: 20px;
  border: 5px solid purple;
}

4. Margin and padding are different

Padding is inside the border and increases the space between content and border. Margin is outside the border and separates the element from other elements. Background colors generally extend through the content and padding, but not the margin.

.card {
  padding: 24px; /* inner space */
  margin: 20px;  /* outer space */
  border: 2px solid #777;
}

5. Inspecting the box model

Open browser developer tools, inspect an element and look for the box model diagram. It displays content, padding, border and margin. This is useful when an element appears wider, taller or more spaced out than expected.

/* A predictable starting point */
* { box-sizing: border-box; }
.card {
  width: min(100%, 420px);
  padding: 24px;
  margin: 20px auto;
  border: 1px solid #ccc;
}
