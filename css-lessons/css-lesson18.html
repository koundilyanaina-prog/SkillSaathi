Lesson 18: CSS Animations and Keyframes

Learn to create moving and animated elements using CSS.

Learning Objectives

  • Understand CSS animations.
  • Learn @keyframes.
  • Use animation properties.
  • Create simple loading and movement effects.

1. What are CSS Animations?

CSS animations allow elements to change their styles over time without requiring JavaScript.

Animations can run once, repeat, move, rotate or change colors.

2. Understanding @keyframes

The @keyframes rule defines the stages of an animation.

@keyframes example {
    from {
        opacity: 0;
    }
    to {
        opacity: 1;
    }
}

You can also use percentages to define multiple stages.

@keyframes moveBox {
    0% { transform: translateX(0); }
    50% { transform: translateX(100px); }
    100% { transform: translateX(0); }
}

3. Animation Properties

  • animation-name: Name of the keyframes animation.
  • animation-duration: Time taken to complete one cycle.
  • animation-delay: Waiting time before it starts.
  • animation-iteration-count: Number of repetitions.
  • animation-direction: Direction of animation.
  • animation-timing-function: Speed pattern.
  • animation-fill-mode: Styles applied before or after animation.
.box {
    animation-name: moveBox;
    animation-duration: 2s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
}

4. Animation Shorthand

You can combine multiple animation properties into one declaration.

.box {
    animation: moveBox 2s ease-in-out infinite alternate;
}

5. Example: Bouncing Box

@keyframes bounce {
    0%, 100% {
        transform: translateY(0);
    }
    50% {
        transform: translateY(-40px);
    }
}

.box {
    animation: bounce 1s infinite;
}

6. Example: Loading Spinner

@keyframes spin {
    to {
        transform: rotate(360deg);
    }
}

.spinner {
    width: 45px;
    height: 45px;
    border: 5px solid #ddd;
    border-top-color: purple;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}
