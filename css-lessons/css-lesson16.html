Lesson 16: Advanced CSS Selectors

Learn how to select HTML elements precisely using advanced CSS selectors.

Learning Objectives

  • Understand attribute selectors.
  • Learn CSS combinators.
  • Use descendant and child selectors.
  • Understand sibling selectors.
  • Combine selectors for better styling.

1. Introduction to Advanced Selectors

CSS selectors are used to target HTML elements and apply styles to them.

Basic selectors include element, class and ID selectors. Advanced selectors allow us to target elements based on their attributes and relationships with other elements.

They help developers write more accurate and organized CSS.

2. Attribute Selectors

Attribute selectors target HTML elements based on their attributes or attribute values.

Exact Attribute Value

input[type="email"] {
    border: 2px solid purple;
}

This selects input elements whose type is email.

Attribute Exists

input[required] {
    background: #eee;
}

This selects all input elements that have the required attribute.

Attribute Contains a Value

a[href*="example"] {
    color: purple;
}

The *= operator matches an attribute value containing the specified text.

3. Descendant Selector

A descendant selector selects elements located anywhere inside another element.

.card p {
    color: purple;
}

This selects all paragraph elements inside an element with the class card, including nested paragraphs.

4. Child Selector

The child selector uses the greater-than symbol ( > ).

.menu > li {
    list-style: none;
}

It selects only direct child elements, not deeper nested elements.

5. Adjacent Sibling Selector

The adjacent sibling selector uses the plus symbol ( + ).

h2 + p {
    color: violet;
}

It selects the first paragraph immediately following an h2 element, when both share the same parent.

6. General Sibling Selector

The general sibling selector uses the tilde symbol ( ~ ).

h2 ~ p {
    color: pink;
}

It selects all paragraph siblings that appear after the h2 element under the same parent.

7. Combining Selectors

You can combine selectors to target elements more precisely.

.card > p.highlight {
    color: purple;
    font-weight: bold;
}

This selects paragraph elements with the class highlight that are direct children of an element with the class card.

8. Practical Example

/* Attribute selector */
input[type="email"] {
    border: 2px solid purple;
}

/* Descendant selector */
.card p {
    color: #555;
}

/* Direct child selector */
.menu > li {
    list-style: none;
}

/* Adjacent sibling selector */
h2 + p {
    margin-top: 0;
}

/* General sibling selector */
h2 ~ p {
    font-style: italic;
}
