Lesson 17: CSS Transitions and Transforms

Learn how to create smooth effects and change the appearance of elements.

Learning Objectives

  • Understand CSS transitions.
  • Learn transition duration and timing functions.
  • Use rotate, scale, translate and skew.
  • Create interactive hover effects.

1. What are CSS Transitions?

CSS transitions allow property changes to happen smoothly over a specified period instead of changing instantly.

.button {
    background: purple;
    transition: background 0.5s ease;
}

.button:hover {
    background: blue;
}

2. Transition Properties

  • transition-property: Specifies which CSS property changes.
  • transition-duration: Specifies how long the transition takes.
  • transition-timing-function: Controls the speed pattern.
  • transition-delay: Adds a delay before the transition starts.
.box {
    transition-property: transform;
    transition-duration: 0.5s;
    transition-timing-function: ease;
    transition-delay: 0s;
}

3. Transition Timing Functions

transition: all 0.5s ease;
transition: all 0.5s linear;
transition: all 0.5s ease-in;
transition: all 0.5s ease-out;
transition: all 0.5s ease-in-out;

These functions control how an animation accelerates or slows down.

4. CSS Transform

The transform property changes an element's position, size, angle or shape without changing the normal document flow.

Translate

.box:hover {
    transform: translate(20px, 10px);
}

Scale

.box:hover {
    transform: scale(1.2);
}

Rotate

.box:hover {
    transform: rotate(10deg);
}

Skew

.box:hover {
    transform: skew(10deg, 5deg);
}

5. Combining Transitions and Transforms

.card {
    transition: all 0.4s ease;
}

.card:hover {
    transform: translateY(-8px) scale(1.03);
    box-shadow: 0 10px 25px #777;
}

This technique is commonly used for interactive cards and buttons.
