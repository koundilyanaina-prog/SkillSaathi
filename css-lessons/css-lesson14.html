Lesson 14: Width and Height

Learn how to control the size of HTML elements using CSS.

Learning Objectives

  • Understand CSS width and height.
  • Learn fixed and flexible dimensions.
  • Understand min-width and max-width.
  • Create responsive layouts.

1. Introduction to Width and Height

CSS width and height properties control the dimensions of HTML elements.

Width: Controls how wide an element is.

Height: Controls how tall an element is.

.box {
    width: 300px;
    height: 200px;
}

2. Fixed Dimensions

Fixed dimensions use units such as px.

.card {
    width: 300px;
    height: 200px;
}

The element will have a width of 300 pixels and height of 200 pixels.

3. Percentage Width

Percentage dimensions depend on the size of the parent element.

.container {
    width: 80%;
}

This means the container will take 80% of its parent's width.

4. Min-Width and Max-Width

min-width: Sets the minimum allowed width.

max-width: Sets the maximum allowed width.

.box {
    width: 100%;
    max-width: 500px;
    min-height: 150px;
}

These properties are useful for responsive website layouts.

5. Viewport Units

Viewport units are based on the browser window size.

.container {
    width: 100vw;
    min-height: 100vh;
}
  • vw = Viewport Width
  • vh = Viewport Height

6. Practical Example

.card {
    width: 90%;
    max-width: 450px;
    min-height: 180px;
    padding: 20px;
    margin: auto;
}

This creates a flexible card that does not become wider than 450px.
