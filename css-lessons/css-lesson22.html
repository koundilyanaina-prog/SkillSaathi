1. What are CSS Shadows?

CSS shadows add depth and visual emphasis to elements. They can be applied to boxes and text.

2. Box Shadow

The box-shadow property adds a shadow around an element's box.

box-shadow: 5px 5px 10px gray;

Its common values are:

  • Horizontal offset
  • Vertical offset
  • Blur radius
  • Spread radius (optional)
  • Shadow color
.card {
    box-shadow: 0 5px 15px rgba(0,0,0,0.2);
}

3. Text Shadow

The text-shadow property adds a shadow to text.

h1 {
    text-shadow: 2px 3px 5px gray;
}

It can make headings stand out, but excessive shadows can reduce readability.

4. CSS Filters

The filter property applies visual effects to images and other elements.

img {
    filter: grayscale(100%);
}

Common filter functions include:

  • blur(): Adds blur.
  • brightness(): Adjusts brightness.
  • contrast(): Adjusts contrast.
  • grayscale(): Converts colors to grayscale.
  • sepia(): Adds a warm brown tone.
  • saturate(): Adjusts color intensity.
  • invert(): Inverts colors.
  • opacity(): Adjusts transparency.

5. Opacity and Blend Modes

Opacity controls how transparent an element appears. Its value ranges from 0 (fully transparent) to 1 (fully opaque).

.card {
    opacity: 0.7;
}

The mix-blend-mode property controls how an element's content blends with the content behind it.

img {
    mix-blend-mode: multiply;
}
