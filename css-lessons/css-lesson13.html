Lesson 13: CSS Grid

Create two-dimensional layouts using rows, columns and grid areas.

Learning Objectives

  • Create a grid container
  • Define columns and rows
  • Use gap and fractional units
  • Place items with lines and named areas

1. Grid container

Set display:grid on a parent to create a grid formatting context. Direct children become grid items. Grid is especially useful when you need to control rows and columns together.

.grid { display: grid; }

2. Defining columns and rows

grid-template-columns defines column tracks and grid-template-rows defines row tracks. The fr unit distributes available space proportionally. repeat() reduces repeated track definitions.

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: auto auto;
}

3. Gap and responsive columns

gap creates space between grid rows and columns. repeat() with minmax() and auto-fit or auto-fill can create responsive grids that adapt to available width.

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 18px;
}

4. Placing grid items

Grid lines can be used to position an item across specific columns or rows. grid-column and grid-row accept line numbers or span values.

.featured { grid-column: 1 / 3; }
.tall { grid-row: span 2; }

5. Grid template areas

Named grid areas make page structure easier to understand. Define areas on the container and assign each child a matching grid-area name.

.layout {
  display: grid;
  grid-template-areas: "header header" "sidebar main" "footer footer";
  grid-template-columns: 220px 1fr;
  gap: 12px;
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
