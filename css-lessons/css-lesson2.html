Lesson 2: CSS Syntax, Selectors and Comments

Learn how CSS rules are written and how to target HTML elements.

Learning Objectives

  • Understand the structure of a CSS rule
  • Use element, class, ID and universal selectors
  • Combine selectors and target nested elements
  • Write readable CSS comments

1. CSS rule structure

A CSS rule has a selector and a declaration block. The selector chooses the HTML element. Inside braces, each declaration has a property and a value, separated by a colon and ending with a semicolon.

p {
  color: purple;
  font-size: 18px;
}

2. Common selectors

The universal selector (*) targets every element. An element selector targets a tag such as p or h1. A class selector starts with a dot (.) and can be reused on many elements. An ID selector starts with # and should identify one unique element on a page.

* { box-sizing: border-box; }
p { color: #444; }
.card { padding: 20px; }
#main-title { color: purple; }

3. Grouping and relationship selectors

Separate selectors with commas to share declarations. A descendant selector uses a space to target elements inside another element. A child selector (>) targets only direct children. Adjacent sibling (+) selects the next matching sibling.

h1, h2, h3 { font-family: Arial; }
article p { line-height: 1.6; }
nav > a { margin-right: 12px; }
h2 + p { color: teal; }

4. Attribute selectors

Attribute selectors target elements based on an attribute or its value. They are useful for forms and links.

input[type="email"] { border: 2px solid purple; }
a[target="_blank"] { text-decoration: underline; }

5. CSS comments

Comments explain code and are ignored by the browser. Start with /* and end with */. Use comments to label sections or explain unusual choices.

/* Main heading styles */
h1 {
  color: rebeccapurple;
}
/* End of heading styles */
