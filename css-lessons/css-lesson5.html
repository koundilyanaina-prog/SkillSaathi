Lesson 5: Typography

Style text so every page feels clear, readable and professional.

Learning Objectives

  • Choose font families and fallback fonts
  • Control font size, weight and line height
  • Style alignment, decoration and spacing
  • Use web-safe font stacks and readable text

1. Font family

font-family chooses the typeface. Always provide fallback fonts so the browser can use another option if the first font is unavailable. A generic family such as sans-serif should usually appear last.

body {
  font-family: Arial, Helvetica, sans-serif;
}
h1 {
  font-family: Georgia, "Times New Roman", serif;
}

2. Font size, weight and style

font-size controls text size. Use relative units such as rem for scalable typography. font-weight controls thickness (normal, bold or values such as 600). font-style is commonly used for italic text.

h1 { font-size: 2rem; font-weight: 700; }
p { font-size: 1rem; font-style: normal; }
strong { font-weight: 700; }

3. Line height and text alignment

line-height controls the distance between lines. A value around 1.4 to 1.7 is often comfortable for paragraphs. text-align can be left, right, center or justify. Avoid long centered paragraphs because they can be harder to scan.

p {
  line-height: 1.6;
  text-align: left;
}
.hero-title { text-align: center; }

4. Decoration, transform and spacing

text-decoration adds or removes lines such as underlines. text-transform changes letter casing visually. letter-spacing adjusts space between characters; word-spacing adjusts space between words. Use these carefully to keep text readable.

a { text-decoration: none; }
.label { text-transform: uppercase; letter-spacing: 1px; }
h2 { word-spacing: 3px; }

5. Readable typography

Use a clear hierarchy: larger headings, comfortable body text and consistent spacing. Keep paragraph line lengths moderate. Do not use too many font families or tiny text. Make sure links and important text remain distinguishable.

main { max-width: 70ch; margin: auto; }
p { font-size: 1rem; line-height: 1.65; }
h1 { font-size: clamp(2rem, 5vw, 3.5rem); }
