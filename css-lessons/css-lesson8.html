Lesson 8: Margins, Padding and Borders

Control spacing, borders and element edges to create clean layouts.

Learning Objectives

  • Set margin and padding on each side
  • Use shorthand spacing syntax
  • Style border width, style and color
  • Understand border-radius and margin collapsing

1. Setting margin

Margin controls space outside an element's border. You can set margin-top, margin-right, margin-bottom and margin-left separately. The auto value is often used to center a block with a defined or maximum width.

.container {
  max-width: 900px;
  margin-left: auto;
  margin-right: auto;
}
.card { margin-bottom: 24px; }

2. Setting padding

Padding controls the inner space between content and border. Padding can be set for each side or with shorthand. Unlike vertical margins, vertical padding is included inside the element's box and background.

.card {
  padding-top: 20px;
  padding-right: 24px;
  padding-bottom: 20px;
  padding-left: 24px;
}

3. Spacing shorthand

One value applies to all four sides. Two values mean top/bottom then right/left. Three values mean top, horizontal sides, then bottom. Four values go clockwise: top, right, bottom, left.

.one { padding: 16px; }
.two { margin: 10px 20px; }
.three { padding: 10px 18px 24px; }
.four { margin: 8px 12px 16px 20px; }

4. Borders and border radius

A border can be described using width, style and color. Common styles include solid, dashed and dotted. border-radius rounds corners; use a larger radius for pill-shaped buttons or circular elements.

.card {
  border: 2px solid #7c3aed;
  border-radius: 14px;
}
.notice {
  border: 2px dashed #a78bfa;
}
.pill { border-radius: 999px; }

5. Margin collapsing and good spacing

In normal block layout, vertical margins of adjacent blocks can sometimes collapse into one margin instead of adding together. Padding does not collapse. For consistent component spacing, use a spacing scale and layout tools such as flexbox or grid gaps where suitable.

.section { padding: 24px; }
.stack > * + * { margin-top: 16px; }
.row { display: flex; gap: 16px; }
