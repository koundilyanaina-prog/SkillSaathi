Lesson 24: CSS Architecture and Debugging

Learning Objectives

  • Understand CSS architecture.
  • Learn the cascade, specificity and inheritance.
  • Organize stylesheets into sections.
  • Understand reusable CSS patterns.
  • Learn how to debug common CSS problems.

1. What is CSS Architecture?

CSS architecture means organizing CSS code in a structured and maintainable way. It becomes especially important when websites contain many pages and components.

A good structure helps developers find styles, reuse components and make changes safely.

2. Organizing CSS Files

A stylesheet can be divided into meaningful sections.

/* 1. Reset and Base */
/* 2. Variables */
/* 3. Typography */
/* 4. Navigation */
/* 5. Layout */
/* 6. Components */
/* 7. Forms */
/* 8. Responsive Styles */

3. CSS Cascade

The cascade decides which declarations apply when multiple CSS rules compete. It considers origin, importance, cascade layers, specificity and source order.

p {
    color: blue;
}

p {
    color: purple;
}

When both declarations have the same cascade priority and specificity, the later declaration wins.

4. CSS Specificity

Specificity helps determine which selector wins when competing declarations apply.

  • ID selectors have greater specificity than class selectors.
  • Class, attribute and pseudo-class selectors have greater specificity than element selectors.
  • Inline styles generally outrank normal stylesheet declarations.
  • !important changes the cascade priority and should be used sparingly.
p { color: blue; }
.note { color: green; }
#message { color: red; }

5. CSS Inheritance

Some properties pass from a parent element to its children. Text color and font family commonly inherit, while margin and padding do not normally inherit.

body {
    color: purple;
    font-family: Arial;
}

6. Common CSS Debugging Problems

  • Wrong selector: Check whether the selector matches the intended HTML element.
  • Missing semicolon: Check the end of CSS declarations.
  • Specificity conflict: Inspect competing CSS rules.
  • Incorrect file path: Verify the stylesheet link.
  • Layout overflow: Check widths, padding and box-sizing.
  • Unexpected spacing: Inspect margin and padding.

7. Using Browser Developer Tools

Browser Developer Tools help inspect HTML and CSS, test style changes and identify errors.

  • Right-click a webpage and choose Inspect.
  • Use the Elements panel to inspect HTML.
  • Use the Styles panel to view applied CSS.
  • Temporarily change CSS values to test solutions.
  • Check the Console for relevant errors.
