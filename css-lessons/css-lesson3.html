Lesson 3: Adding CSS to HTML

Use inline, internal and external CSS in the right way.

Learning Objectives

  • Understand the three ways to add CSS
  • Know when to use inline and internal CSS
  • Connect an external stylesheet correctly
  • Understand basic cascade and priority

1. Inline CSS

Inline CSS is written inside an HTML element using the style attribute. It affects only that element. It can be useful for a tiny one-off test, but avoid relying on it for a full website because it is difficult to maintain.

<h1 style="color: purple;">Welcome</h1>
<p style="font-size: 18px;">Learning CSS</p>

2. Internal CSS

Internal CSS is written inside a style element in the head section of an HTML file. It is useful for a single-page demonstration or a page that has unique styles.

<!DOCTYPE html>
<html>
<head>
  <style>
    body { background: #f4f4f4; }
    h1 { color: purple; }
  </style>
</head>
<body>
  <h1>Hello CSS</h1>
</body>
</html>

3. External CSS

External CSS is stored in a separate .css file. Link it inside the head using a link element. This is the recommended approach for most multi-page websites because many pages can share one stylesheet.

<!-- In index.html, inside <head> -->
<link rel="stylesheet" href="style.css">

/* In style.css */
body { font-family: Arial, sans-serif; }
h1 { color: purple; }

4. File paths and common mistakes

If index.html and style.css are in the same folder, use href="style.css". If the stylesheet is inside a folder named css, use href="css/style.css". Check spelling, folder names and capitalization. Save both files and refresh the browser.

project/
  index.html
  style.css

<link rel="stylesheet" href="style.css">

5. The cascade in brief

When more than one rule applies, CSS uses the cascade: origin, importance, specificity and source order help decide the winning declaration. Avoid solving every conflict with !important. Prefer clear selectors and a predictable stylesheet.

p { color: navy; }
.note { color: purple; } /* wins for <p class="note"> */
