Lesson 20: CSS Media Queries

Learning Objectives

  • Understand CSS Media Queries.
  • Learn how to apply styles at different screen widths.
  • Understand breakpoints.
  • Learn mobile-first responsive styling.
  • Create layouts for mobile, tablet and desktop.

1. What are Media Queries?

Media Queries are a CSS feature that allows us to apply different styles depending on device or viewport conditions, such as screen width, height and orientation.

They are commonly used to make websites responsive.

@media (max-width: 600px) {
    body {
        background: lightblue;
    }
}

This example applies the styles when the viewport width is 600 pixels or less.

2. Media Query Syntax

@media media-type and (condition) {
    /* CSS rules */
}
  • @media: Starts a media query.
  • screen: Targets screen-based devices.
  • max-width: Applies styles up to a maximum width.
  • min-width: Applies styles from a minimum width upward.

3. Common Breakpoints

Breakpoints are viewport widths where a layout changes to suit the available space. They should be chosen based on the content and design, not only on specific device names.

/* Small screens */
@media (max-width: 600px) { }

/* Medium screens */
@media (min-width: 601px) and
       (max-width: 900px) { }

/* Large screens */
@media (min-width: 901px) { }

4. Mobile-First Design

Mobile-first design means writing the base CSS for smaller screens first, then adding styles for larger screens using min-width media queries.

.card {
    width: 100%;
}

@media (min-width: 768px) {
    .card {
        width: 48%;
    }
}

@media (min-width: 1024px) {
    .card {
        width: 30%;
    }
}

5. Other Media Query Conditions

/* Landscape orientation */
@media (orientation: landscape) {
    body {
        background: #eee;
    }
}

/* Reduced motion preference */
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms;
        transition-duration: 0.01ms;
    }
}

These conditions help adapt a website to user preferences and device orientation.
