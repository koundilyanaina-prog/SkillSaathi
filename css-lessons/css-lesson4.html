Lesson 4: Colors and Backgrounds

Make interfaces attractive with color, gradients and background properties.

Learning Objectives

  • Use named, HEX, RGB and HSL colors
  • Set background colors and images
  • Create linear and radial gradients
  • Control background size, position and repeat

1. CSS color formats

CSS supports named colors such as tomato, HEX values such as #663399, RGB such as rgb(102, 51, 153), and HSL such as hsl(270, 50%, 40%). HEX and RGB are common in design systems. RGBA and HSLA also allow transparency.

h1 { color: #663399; }
p { color: rgb(40, 50, 70); }
.card { background: hsl(270, 60%, 95%); }
.overlay { background: rgba(0, 0, 0, 0.5); }

2. Background color and image

Use background-color for a solid fill. Use background-image for an image or gradient. For an image, choose a readable text color and consider a subtle overlay when text sits on top.

body { background-color: #f5f2ff; }
.hero {
  background-image: url("banner.jpg");
  background-size: cover;
  background-position: center;
}

3. Gradients

A linear gradient blends colors along a line. A radial gradient spreads colors outward from a point. Gradients are images in CSS, so they are set with background-image.

.button {
  background: linear-gradient(90deg, #7c3aed, #ec4899);
}
.banner {
  background: radial-gradient(circle, #ddd6fe, #312e81);
}

4. Background controls

background-size controls image dimensions; cover fills the box while preserving the image ratio and may crop it. contain shows the whole image and may leave empty space. background-repeat controls tiling. background-position controls placement.

.hero {
  background-image: url("photo.jpg");
  background-size: cover;
  background-repeat: no-repeat;
  background-position: center;
  min-height: 320px;
}

5. Contrast and accessibility

Text must be easy to read against its background. Avoid placing pale text on pale colors or dark text on dark images. Check contrast, do not communicate meaning with color alone, and provide visible focus styles for interactive elements.

body { color: #202033; background: #fff; }
a:focus-visible { outline: 3px solid #7c3aed; outline-offset: 3px; }
