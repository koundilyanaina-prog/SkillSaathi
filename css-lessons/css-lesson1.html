Lesson 1: Introduction to CSS

Understand Cascading Style Sheets, why CSS is important, how it works with HTML and how to create your first styled web page.

1. What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe how HTML elements should look on a web page.

HTML creates the structure and content of a webpage, while CSS controls its visual appearance.

Simple Definition: CSS is used to style HTML elements by controlling their colors, fonts, sizes, spacing, borders, backgrounds and layouts.

Examples of what CSS can do

  • Change the color of headings and paragraphs.
  • Set font sizes and font styles.
  • Add backgrounds, borders and shadows.
  • Arrange content into rows and columns.
  • Make a website responsive on mobile devices.
  • Create animations and interactive visual effects.

2. HTML vs CSS

HTML and CSS work together, but they have different responsibilities.

HTML = Structure and Content
CSS  = Appearance and Layout

3. How Does CSS Work?

A browser reads the HTML document, applies the CSS rules that match its elements, and displays the styled webpage.

  1. The HTML file contains elements such as headings, paragraphs and images.
  2. The CSS file contains styling rules.
  3. The browser connects the CSS rules to matching HTML elements.
  4. The browser displays the final visual result.
Remember: CSS does not replace HTML. It works with HTML to improve the presentation of a webpage.

4. Basic CSS Syntax

A CSS rule contains a selector and a declaration block.

h1 {
  color: purple;
  font-size: 32px;
}

Understanding the parts

  • Selector: Selects the HTML element to style. Here it is h1.
  • Property: The style feature being changed. Here it is color or font-size.
  • Value: The setting assigned to a property, such as purple or 32px.
  • Declaration: A property and its value together.

Each declaration normally ends with a semicolon. Curly braces contain the declarations.

5. Three Ways to Add CSS

Inline CSS

CSS is written directly inside an HTML element using the style attribute.

<p style="color: blue;">
  Hello Students!
</p>

Internal CSS

CSS is written inside a style element in the HTML document's head.

<head>
  <style>
    p {
      color: green;
    }
  </style>
</head>

External CSS

CSS is stored in a separate file and connected to HTML using a link element.

<head>
  <link rel="stylesheet" href="style.css">
</head>
Professional websites commonly use external CSS because it makes styling easier to maintain and reuse.

6. Advantages of CSS

  • Improves the appearance of websites.
  • Separates content from presentation.
  • Allows consistent styling across multiple pages.
  • Reduces repeated styling code.
  • Supports responsive layouts for different devices.
  • Makes website maintenance easier.

7. Practical Example

Study this complete example of HTML connected with internal CSS.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First CSS Page</title>
  <style>
    body {
      background-color: #eee7ff;
      font-family: Arial, sans-serif;
    }

    h1 {
      color: purple;
      text-align: center;
    }

    p {
      color: #333;
      font-size: 18px;
    }
  </style>
</head>
<body>
  <h1>Welcome to CSS</h1>
  <p>I am learning to style websites.</p>
</body>
</html>
