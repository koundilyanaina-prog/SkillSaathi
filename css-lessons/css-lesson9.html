Lesson 9: CSS Display Property

Control how elements participate in page layout.

Learning Objectives

  • Understand block, inline and inline-block elements
  • Use display: none and visibility concepts correctly
  • Choose flex and grid as modern layout systems

1. Block elements

Block elements normally start on a new line and take the available width. Common examples include div, section, article, p and headings. Width, height, margin and padding can be controlled.

div { display: block; width: 100%; }

2. Inline elements

Inline elements flow within text and take only the space their content needs. Common examples include span, a and strong. Width and height do not normally apply to inline elements in the same way as block elements.

span { display: inline; color: purple; }
a { display: inline; }

3. Inline-block

inline-block elements sit alongside other inline content but can have width, height and box-model dimensions. It is useful for small badges, buttons and compact navigation items.

.badge { display: inline-block; padding: 8px 14px; width: 120px; }

4. Hiding elements

display: none removes an element from layout. visibility: hidden keeps its layout space but makes it invisible. opacity: 0 makes it transparent but it can still occupy space and may remain interactive unless handled separately.

.hidden { display: none; }
.invisible { visibility: hidden; }
.transparent { opacity: 0; }

5. Choosing a layout display

Use flexbox for one-dimensional rows or columns and grid for two-dimensional layouts. These are covered in detail in later lessons. Avoid using display properties as a substitute for semantic HTML.

.row { display: flex; gap: 16px; }
.gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }
