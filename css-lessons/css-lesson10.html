Lesson 10: CSS Position

Place elements precisely with static, relative, absolute, fixed and sticky positioning.

Learning Objectives

  • Understand normal document flow
  • Use relative and absolute positioning
  • Create fixed and sticky elements
  • Understand top, right, bottom, left and z-index

1. Static positioning

static is the default position. Elements appear in normal document flow. The top, right, bottom and left offsets do not move a statically positioned element.

.box { position: static; }

2. Relative positioning

relative keeps the element's original space in the layout, but allows it to be visually shifted using offsets. It also commonly creates a positioning reference for absolutely positioned descendants.

.card { position: relative; top: 10px; left: 8px; }

3. Absolute positioning

An absolutely positioned element is removed from normal flow and positioned relative to its nearest ancestor that establishes a positioning context, often one with position: relative. If none exists, it uses the initial containing block.

.card { position: relative; }
.label { position: absolute; top: 12px; right: 12px; }

4. Fixed and sticky

fixed positions an element relative to the viewport, so it stays in place while scrolling. sticky behaves like normal flow until it reaches a specified scroll threshold, then sticks within its scrolling container.

.help-button { position: fixed; right: 20px; bottom: 20px; }
header { position: sticky; top: 0; }

5. z-index and stacking

z-index controls the stacking order of positioned elements and certain other layout items. A higher value usually appears above a lower one within the same stacking context. Stacking contexts can affect how z-index behaves.

.card { position: relative; z-index: 1; }
.modal { position: fixed; z-index: 100; }
