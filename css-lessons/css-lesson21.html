1. What are CSS Variables?

CSS variables are reusable values stored in custom properties. They allow developers to define a value once and use it in multiple places.

They are useful for colors, spacing, font sizes, borders and other repeated values.

:root {
    --main-color: purple;
}

h1 {
    color: var(--main-color);
}

2. Declaring Variables with :root

The :root pseudo-class selects the document's root element. Variables declared there are available throughout the document unless overridden.

:root {
    --primary: #a78bfa;
    --background: #11111b;
    --spacing: 20px;
}

3. Using the var() Function

The var() function reads the value stored in a custom property.

button {
    background: var(--primary);
    padding: var(--spacing);
}

A fallback value can also be provided:

color: var(--text-color, black);

4. Local CSS Variables

Variables can also be declared inside a selector. Their scope is limited to that element and its descendants.

.card {
    --card-color: lavender;
    background: var(--card-color);
}

5. Advantages of CSS Variables

  • Easy theme changes.
  • Less repeated code.
  • Consistent design values.
  • Simple maintenance.
  • Reusable colors and spacing.
