Lesson 6: CSS Units

Understand the units that control size, spacing and responsive layouts.

Learning Objectives

  • Differentiate absolute and relative units
  • Use px, %, em and rem appropriately
  • Understand viewport units vw and vh
  • Choose units for flexible layouts

1. Absolute units: px

The pixel (px) is a fixed CSS length unit. It is useful for fine details such as thin borders and small icons. However, using fixed pixel sizes for every part of a page can make layouts less flexible on different screens.

.card {
  border: 1px solid #999;
  padding: 20px;
  border-radius: 8px;
}

2. Percentages (%)

A percentage is usually calculated in relation to a containing element. It is useful for fluid widths. For example, width: 50% makes an element half as wide as its containing block.

.container { width: 90%; margin: auto; }
.column { width: 50%; }

3. em and rem

em is relative to the font size of the element's context; for many properties it is based on the element's own computed font size. rem is relative to the root html font size. rem is often easier to manage consistently across a project.

html { font-size: 16px; }
h1 { font-size: 2rem; } /* 32px when root is 16px */
.button { padding: 0.75em 1.2em; }

4. Viewport units: vw and vh

1vw is one percent of the viewport width and 1vh is one percent of the viewport height. These units can help create layouts that respond to the visible screen. Use them thoughtfully, especially for text, so content does not become too small or too large.

.hero {
  min-height: 70vh;
  padding: 5vw;
}
.hero-title { font-size: 5vw; }

5. Choosing the right unit

Use rem for much of your typography and spacing system, percentages or flexible layout tools for fluid widths, and px for small precise details. Combine units with max-width and min-height to prevent content from becoming awkward on very large or small screens.

.page {
  width: 90%;
  max-width: 1100px;
  margin-inline: auto;
}
p { font-size: 1rem; line-height: 1.6; }
