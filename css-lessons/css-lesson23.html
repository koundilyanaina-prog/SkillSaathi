Lesson 23: Forms and Navigation Styling

Learning Objectives

  • Style HTML forms using CSS.
  • Customize input fields and text areas.
  • Design attractive buttons.
  • Create navigation menus.
  • Use hover, focus and active states.

1. Styling HTML Forms

Forms collect information from users. CSS makes form elements visually clear, consistent and easy to use.

input {
    width: 100%;
    padding: 12px;
    border: 1px solid #ccc;
    border-radius: 6px;
}

2. Styling Input Fields

Input fields can be styled using background, padding, border, font size and border radius.

input:focus {
    outline: none;
    border-color: purple;
    box-shadow: 0 0 5px #a78bfa;
}

Always keep a visible focus indicator so keyboard users can identify the active field.

3. Styling Buttons

button {
    background: purple;
    color: white;
    padding: 12px 20px;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

button:hover {
    background: indigo;
}

Use hover and focus states to make buttons easier to understand and operate.

4. Navigation Styling

Navigation menus help users move between different pages or sections of a website.

nav {
    display: flex;
    gap: 20px;
    background: #222;
    padding: 15px;
}

nav a {
    color: white;
    text-decoration: none;
}

5. Navigation Hover and Active States

nav a:hover {
    color: lavender;
}

nav a:focus-visible {
    outline: 2px solid purple;
    outline-offset: 4px;
}

The focus-visible state helps keyboard users see which navigation link is selected.
