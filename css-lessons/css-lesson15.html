Lesson 15: Pseudo-Classes and Pseudo-Elements

Learn how to style element states and specific parts of elements.

Learning Objectives

  • Understand pseudo-classes.
  • Use hover and focus states.
  • Understand pseudo-elements.
  • Create interactive visual effects.

1. What are Pseudo-Classes?

A pseudo-class is used to style an element when it is in a particular state.

For example, when a user moves the mouse over a button, we can change its background color.

button:hover {
    background: purple;
}

2. Common Pseudo-Classes

:hover

Applies styles when the mouse pointer is over an element.

button:hover {
    background: #6d28d9;
}

:focus

Applies styles when an input or other focusable element is selected.

input:focus {
    outline: 2px solid violet;
}

:first-child

Selects the first child element of its parent.

li:first-child {
    color: violet;
}

:nth-child()

Selects a child based on its position.

li:nth-child(2) {
    color: pink;
}

3. What are Pseudo-Elements?

Pseudo-elements allow us to style a specific part of an element or add generated decorative content.

Modern CSS uses double colons (::) for pseudo-elements.

::before

h2::before {
    content: "★ ";
}

::after

h2::after {
    content: " ✦";
}

::first-letter

p::first-letter {
    font-size: 30px;
    color: purple;
}

::selection

::selection {
    background: purple;
    color: white;
}

4. Difference Between Pseudo-Class and Pseudo-Element

Pseudo-Class: Selects an element based on its state or position.

Example: :hover, :focus, :first-child

Pseudo-Element: Styles a specific part of an element or creates generated content.

Example: ::before, ::after, ::first-letter

5. Practical Example

.demo-button:hover {
    background: #35245f;
    transform: translateY(-3px);
}

.note::before {
    content: "★ ";
    color: purple;
}
