📘 Part 1: HTML Links

An HTML link allows users to move from one webpage to another or open another online resource. Links make websites connected and easy to navigate.

1. Understanding the <a> Tag

The anchor tag, written as <a>, creates a clickable link. It usually contains an href attribute and link text. 

<a href="https://example.com">Visit Example</a>
  • <a> creates the link.
  • href specifies the link destination.
  • Visit Example is the clickable text.
  • </a> closes the anchor element.

2. External and Internal Links

External link: Opens a page on another website.

<a href="https://www.wikipedia.org">Visit Wikipedia</a>

Internal link: Opens another page in your own website.

<a href="lesson.html">Go to Lesson 1</a>

The file lesson.html must exist at the specified location for the internal link to work.

3. Opening a Link in a New Tab

<a href="https://example.com"
   target="_blank"
   rel="noopener noreferrer">
  Visit Example
</a>

target="_blank" requests that the link open in a new browsing context, usually a new tab. rel="noopener noreferrer" adds privacy and security protection for that new context.

4. Common Mistakes

  • Forgetting the href attribute.
  • Misspelling the destination URL.
  • Forgetting the closing </a> tag.
  • Using a filename that does not exist.

🖼️ Part 2: HTML Images

Images make a webpage more attractive and help explain ideas visually. In HTML, the <img> tag is used to display an image.

1. Your First Image

<img
  src="https://placehold.co/500x250/172554/ffffff?text=Welcome+to+SkillSaathi"
  alt="Welcome to SkillSaathi"
  width="500"
>

src: Specifies the image location.

alt: Describes the image for accessibility and when the image cannot load.

width: Sets the displayed image width in pixels when given a number.

2. See an Image Example

Here is a sample learning image. Your own code can display a different image.

3. How to Use Your Own Image

Download an image you are allowed to use and place it inside an images folder in your project. 

<img src="images/my-photo.jpg" alt="A beautiful landscape">

The folder name, filename and file extension must match the actual file. For example, .jpg and .png are different extensions.

4. Common Mistakes

  • Using the wrong image path or filename.
  • Forgetting the src attribute.
  • Leaving out meaningful alt text.
  • Using a very large image without controlling its display size.

Learning tip: The image URL must point to an image. If the URL is unavailable or the internet is disconnected, the image may not appear.
