📘 Part 1: Introduction to HTML Forms

HTML forms are used to collect information from website visitors. For example, login forms, registration forms and contact forms.

1. Understanding the form Tag

The <form> element creates a form that can contain different input fields. 

<form>
  <label>Your Name:</label>
  <input type="text">
  <button type="submit">Submit</button>
</form>

2. The action and method Attributes

<form action="/submit" method="post">
  ...
</form>
  • action: Specifies where form data is sent.
  • method: Specifies how form data is submitted.
  • GET: Sends form data as URL parameters.
  • POST: Sends form data in the request body.

A real form needs a server-side endpoint to receive and process submitted information.

⌨️ Part 2: Input Types

The input element allows users to enter different kinds of information. Its type attribute controls the kind of input.

1. Text Input

<input type="text" placeholder="Enter your name">

Used to collect names and other short text.

2. Email Input

<input type="email" placeholder="Enter your email">

Used to collect an email address.

3. Password Input

<input type="password" placeholder="Enter password">

Hides the characters entered by the user on screen.

4. Number Input

<input type="number" min="1" max="100">

Allows users to enter a numeric value.

5. Radio Buttons

<input type="radio" name="course" value="HTML">
HTML

<input type="radio" name="course" value="CSS">
CSS

Radio buttons allow users to select one option from a group when the options share the same name.

6. Checkboxes

<input type="checkbox" name="skill" value="HTML">
HTML

<input type="checkbox" name="skill" value="CSS">
CSS

Checkboxes allow users to select multiple options.

📋 Part 3: Dropdowns, Textarea and Labels

1. Dropdown List

<label for="city">Choose a city:</label>

<select id="city" name="city">
  <option value="ranchi">Ranchi</option>
  <option value="delhi">Delhi</option>
  <option value="patna">Patna</option>
</select>

A dropdown list lets users choose from available options.

2. Textarea

<textarea rows="4" cols="30"
placeholder="Write your message"></textarea>

Textarea is used to collect longer messages or descriptions.

3. Labels

<label for="name">Full Name:</label>
<input type="text" id="name" name="name">

A label describes an input field. Connecting the label's for attribute to the input's id improves accessibility.

4. Required Fields

<input type="email" required>

The required attribute asks the browser to check that the field has been filled in before submitting the form.

🚀 Part 4: Build a Registration Form

Now let's combine what we have learned and create a simple student registration form. 

<form>

  <label for="studentName">Full Name:</label>
  <input type="text" id="studentName"
  name="studentName" required>

  <label for="studentEmail">Email:</label>
  <input type="email" id="studentEmail"
  name="studentEmail" required>

  <label for="studentPassword">Password:</label>
  <input type="password" id="studentPassword"
  name="studentPassword" required>

  <button type="submit">Register</button>

</form>

Common Mistakes

  • Forgetting to connect labels with input IDs.
  • Using the wrong input type.
  • Forgetting the name attribute when submitting form data.
  • Using different names for radio buttons in the same group.
  • Forgetting to close the form element.
